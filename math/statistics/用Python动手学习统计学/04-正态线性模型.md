## 5.1 正态线性模型：给 OLS 装上一把"假设之钥"

### 直觉：线性模型 + 正态误差 = 可推断的模型

第4章的线性模型写成：

$$y_i=\beta_0+\beta_1x_i+\varepsilon_i$$

而**正态线性模型**在此基础上加了一句话：

$$\varepsilon_i\sim\mathcal N(0,\sigma^2),\quad \varepsilon_i\perp\!\!\!\perp\varepsilon_j\ (i\ne j)$$

这句话看似平淡，却是分水岭。在英文教材 _Economics of Regression_ 中被强调为："Normality allows precise distributional characterizations and sharp inferences"——**正态性赋予了精确的推断能力**。

### 第一性原理洞见

为什么非要"正态"？三个深层理由：

1. **OLS 估计量与最大似然估计（MLE）等价**：在正态误差假设下，最小化残差平方和 = 最大化对数似然函数。这意味着 OLS 不仅"直观上好用"，更是"统计上最优"的——它是充分统计量的函数。
2. **系数估计的分布可精确写出**：$\hat\beta\sim\mathcal N\!\left(\beta,\sigma^2(X^\top X)^{-1}\right)$，由此 $t$ 检验、$F$ 检验、置信区间全部有了理论依据。
3. **预测区间不再是近似**：给定新 $x_0$，预测值的分布是 $t$ 分布，可以给出精确的预测区间。

> 💡 我的理解：正态线性模型 = 线性模型 + 一个"让推断成立的承诺"。这个承诺不是无条件的——它必须被数据检验（这就是本章后面所有诊断图的意义）。

### 工业视角

工业预测模型（如电商销量预测、制造业良率预测）往往不满足严格正态性。但正态线性模型的价值在于它提供了**基线（baseline）**——

- 它是 GLM（广义线性模型）的特例（第6章会展开）
- 它是机器学习中许多模型的对照基准
- 它的诊断流程是所有回归类模型的"通用语言"

正如 _Linear Models with Python_ 指出：线性回归是"all regression methods 的 fundamental starting point"——**正态线性模型就是这个起点的理论内核**。

### 四个核心假设一览

|假设|数学表达式|违反后果|
|---|---|---|
|线性|$\mathbb E[Y\mid X]=X\beta$|系数有偏、拟合严重不足|
|独立性|$\varepsilon_i\perp\!\!\!\perp\varepsilon_j\ (i\ne j)$|标准误低估、$p$ 值失真|
|同方差|$\operatorname{Var}(\varepsilon_i)=\sigma^2$|标准误无效、检验失真|
|正态性|$\varepsilon_i\sim\mathcal N(0,\sigma^2)$|小样本下推断失效|

> ⚠️ 关键认知：**前三个假设影响"估计的一致性"，第四个假设主要影响"小样本推断的精确性"**。大样本下，中心极限定理让正态性假设可以放宽——但前三个仍然必须成立。

## 5.2 一元正态线性模型：从啤酒销量说起

### 直觉：一个解释变量的最小完备模型

原书选用"温度 → 啤酒销量"的数据集，这是理解正态线性模型的**最佳切入点**——只有一个解释变量，所有概念都能可视化。

模型形式：

$$y_i=\beta_0+\beta_1\,\text{temperature}_i+\varepsilon_i,\quad \varepsilon_i\sim\mathcal N(0,\sigma^2)$$

### 洞见：一元模型是"理解多元模型的显微镜"

很多人急于跳到多元回归，但一元模型有三个不可替代的价值：

1. **可视化的力量**：散点图 + 回归直线 + 残差图，所有假设都能"看见"
2. **系数的直觉**：$\beta_1$ 就是“温度每升高 $1$ 度，啤酒销量平均增加多少”
3. **诊断的全套流程**：在一元模型上学到的诊断方法，原封不动迁移到多元模型

### Python 实现（原书代码还原）

```
import pandas as pd
import statsmodels.formula.api as smf
import seaborn as sns
import matplotlib.pyplot as plt

# 读入啤酒数据
beer = pd.read_csv("5-1-1-beer.csv")
print(beer.head())
#    beer  temperature
# 0  45.3         20.5
# 1  59.3         25.0
# ...

# 绘制联合分布
sns.jointplot(x="temperature", y="beer", data=beer, color='black')

# 拟合一元正态线性模型
lm_model = smf.ols(formula="beer ~ temperature", data=beer).fit()

# 查看完整诊断报告
print(lm_model.summary())
```

### 工业案例：温度-销量关系的业务价值

在快消行业，温度-啤酒销量模型是**供应链备货的核心输入**：

- 便利店连锁根据天气预报调整每日配送量
- brewery 根据季节性温度预测调整生产计划
- 物流公司提前调度冷链运输资源

但业务方最常问的不是“$\beta_1$ 是多少”，而是**“明天 $30$ 度时，销量会在什么区间？”**——这正是正态线性模型相比第4章纯 OLS 的核心增值。

## 5.3 模型拟合与 summary 输出解读

### 直觉：summary() 是模型的"体检报告"

`lm_model.summary()` 输出大量信息，按英文诊断框架可归为四类：

**第一类：整体拟合优度**

- R-squared: 0.807（温度解释了啤酒销量 80.7% 的变异）
- Adj. R-squared: 0.787
- F-statistic: 40.96, Prob(F): 1.29e-10 → **模型整体极显著**

**第二类：系数估计与推断**

```
coef    std err    t      P>|t|   [0.025   0.975]
const         29.630      2.847    10.41   0.000   23.938   35.322
temperature    0.755      0.118     6.40   0.000    0.518    0.992
```

- 截距 29.63：温度为0度时的基准销量（理论值）
- 斜率 0.755：温度每升1度，销量平均增加 0.755 单位
- 两个系数的 p 值均 < 0.001 → 极显著

**第三类：残差分布诊断**

- Omnibus: 4.495, Prob(Omnibus): 0.106 → **残差正态性 OK**
- Jarque-Bera: 3.368, Prob(JB): 0.186 → 偏度+峰度联合检验通过
- Durbin-Watson: 1.422 → 自相关检验（横截面数据通常不关注）
- Skew: 0.786, Kurtosis: 3.230 → 轻微右偏，但可接受

**第四类：数值稳定性**

- Cond. No. 3.00e+03 → 条件数较大，提示可能存在数值问题（但一元模型通常无碍）

### 洞见：summary 不是终点，而是"行动清单"

我的理解是，读 summary 的正确姿势是**带着问题读**：

|你看到的现象|隐含的问题|下一步行动|
|---|---|---|
|R² 很低|遗漏重要变量|考虑多元回归或非线性变换|
|系数 p 值不显著|变量无解释力 / 共线性|检查 VIF，考虑剔除|
|Omnibus p < 0.05|残差非正态|考虑变换或因变量 GLM|
|Durbin-Watson 远离2|残差自相关|时间序列模型或稳健标准误|
|Cond. No. 很大|多重共线性 / 尺度问题|标准化特征或使用正则化|

> 💡 工业建模铁律：**summary 输出的每一个数字，都是在问你"下一步该怎么办"**。忽略任何一个报警信号，模型上线后都会以某种方式"报复"你。

## 5.4 残差诊断：假设检验的可视化

### 直觉：四张图胜过千言万语

statsmodels 官方文档明确指出：线性回归的结果依赖于统计假设成立，"the results are only correct if our assumptions hold"。诊断就是验证这些假设的系统工程。

按英文主流诊断框架，核心诊断流程包括：

**1. Residuals vs Fitted（残差 vs 拟合值）**

```
plt.scatter(lm_model.fittedvalues, lm_model.resid)
plt.axhline(y=0, color='r', linestyle='--')
```

判读：

- **随机散点**​ → 线性假设 OK ✅
- **U 形 / 倒 U 形**​ → 非线性，需要多项式项 ⚠️
- **漏斗形**​ → 异方差，需要加权最小二乘或稳健标准误 ⚠️

**2. Normal Q-Q Plot（正态分位图）**

```
sm.qqplot(lm_model.resid, line='s')
```

判读：

- 点大致落在45度线上 → 残差正态 ✅
- 两端偏离 → 厚尾或非正态，小样本下推断不可靠 ⚠️

**3. Scale-Location Plot（尺度-位置图）**

```
import numpy as np
plt.scatter(lm_model.fittedvalues, 
           np.sqrt(np.abs(lm_model.get_influence().resid_studentized_external)))
```

专门检测异方差性的增强版散点图。

**4. Residuals vs Leverage（残差 vs 杠杆率）**

用 Cook's Distance 识别强影响点：

```
influence = lm_model.get_influence()
cooks_d = influence.cooks_distance[0]
# Cook's D > 4/n 视为强影响点
threshold = 4 / len(beer)
influential = np.where(cooks_d > threshold)[0]
```

### 洞见：诊断图的本质是"假设的逆推"

我的理解：**每张诊断图都是在问"如果假设成立，我应该看到什么？"**

- 如果线性成立 → 残差应该是关于0对称的随机云
- 如果同方差成立 → 残差散点应该是等宽的带状
- 如果正态成立 → Q-Q 点应该贴着对角线

**一旦出现模式，模式本身就是下一个模型的提示**：

- U 形残差 → 加 x2 项
- 漏斗形残差 → 对因变量取 log
- 厚尾残差 → 改用稳健回归或 GLM

### 工业案例：啤酒销量的诊断实战

在原书啤酒数据中跑诊断，可能会发现：

- **高温区残差方差更大**​ → 异方差（高温天销量波动天然更大）
- 对策：对因变量取 log 变换，或用稳健标准误

这种诊断在工业中直接关系到**预测区间的可靠性**——如果无视异方差，给业务方的预测区间会系统性偏窄，导致缺货或积压。

## 5.5 假设检验与补救措施

### 直觉：当假设被破坏时，我们有哪些工具？

statsmodels 提供了完整的诊断检验套件：

**正态性检验**

```
from statsmodels.stats.stochastic import jarque_bera
jb_stat, jb_p, skew, kurt = jarque_bera(lm_model.resid)
```

**异方差检验（Breusch-Pagan）**

```
from statsmodels.stats.diagnostic import het_breuschpagan
bp_stat, bp_p, f_stat, fp_p = het_breuschpagan(lm_model.resid, lm_model.model.exog)
# p < 0.05 → 存在异方差
```

**自相关检验（Durbin-Watson）**

```
from statsmodels.stats.stiptools import durbin_watson
dw = durbin_watson(lm_model.resid)
# dw ≈ 2 → 无自相关
```

### 补救工具箱

|问题|补救措施|Python 实现|
|---|---|---|
|非线性|变量变换 / 多项式项|`beer ~ temperature + I(temperature**2)`|
|异方差|稳健标准误 / WLS|`model.get_robustcov_results()`|
|非正态|因变量变换（log/sqrt）|`np.log(beer) ~ temperature`|
|强影响点|剔除 / 稳健回归|`sm.RLM(...)`|
|共线性|剔除变量 / 正则化|VIF 检测|

### 工业视角：稳健标准误的威力

在工业数据中，异方差几乎是常态。statsmodels 的**三明治标准误（sandwich estimator）**是工业级解决方案：

```
# 使用 HC3 稳健标准误
robust_model = lm_model.get_robustcov_results(cov_type='HC3')
print(robust_model.summary())
```

这在金融风控、广告效果归因等场景中几乎是默认操作——因为它让推断在异方差下依然有效，**无需对数据进行任何变换**。

## 5.6 预测与推断：正态线性模型的真正价值

### 直觉：预测区间 vs 置信区间

正态线性模型最强大的地方在于能给出两种区间：

**1. 置信区间（Confidence Interval）**：针对均值 $\mathbb E[Y\mid X=x_0]$

$$\hat y_0\pm t_{\alpha/2,n-p-1}\,\hat\sigma\sqrt{x_0^\top(X^\top X)^{-1}x_0}$$

**2. 预测区间（Prediction Interval）**：针对单个新观测 $Y_0$

$$\hat y_0\pm t_{\alpha/2,n-p-1}\,\hat\sigma\sqrt{1+x_0^\top(X^\top X)^{-1}x_0}$$

差异在于预测区间多了一个"1"——它承认**单个观测的不可预测性**。

### Python 实现

```
# 构造新数据
new_data = pd.DataFrame({'temperature': [30]})

# 点预测
point_pred = lm_model.predict(new_data)

# 预测区间（默认95%）
pred_summary = lm_model.get_prediction(new_data).summary_frame(alpha=0.05)
print(pred_summary)
#         mean     mean_se  mean_ci_lower  mean_ci_upper  obs_ci_lower  obs_ci_upper
# 0  52.229...   ...        ...            ...            45.123...     59.335...
```

### 洞见：预测区间才是业务方真正需要的

我的理解是，工业预测的核心矛盾是：

> **业务方想要确定性，但统计学只能给概率。**

正态线性模型通过预测区间优雅地解决了这个矛盾——它告诉业务方：

- "明天气温30度时，啤酒销量**预计**​ 52 千杯"
- "但实际销量有95%概率落在 **45 到 59 千杯**​ 之间"

这种"点估计 + 区间估计"的双层输出，是工业决策的科学基础。库存策略、产能规划、风险准备金——全都依赖预测区间而非单点预测。

### 工业案例：啤酒销量的库存决策

假设某便利店连锁使用此模型做每日补货：

- 点预测：52 千杯
- 95% 预测区间：[45, 59] 千杯
- 安全库存策略：按预测区间上限 59 千杯备货 → 满足 97.5% 的需求场景
- 期望缺货率：2.5%

如果改用"忽略预测区间、只按点预测备货"的策略，实际缺货率会远高于 2.5%——因为**忽略了个体波动**。

## 5.7 正态线性模型在工业中的定位

### 全局视角：它是统计建模的"母语"

纵观工业数据科学实践，正态线性模型占据着一个微妙而重要的位置：

1. **它是 GLM 的特例**：当连接函数是恒等函数、误差是正态分布时，GLM 退化为正态线性模型——第6章会展开
2. **它是机器学习的基线**：任何复杂模型（随机森林、XGBoost、神经网络）都应该先和线性回归对比，否则无法证明"复杂性是值得的"
3. **它是因果推断的载体**：在 A/B 测试、双重差分（DID）、回归断点设计（RDD）中，正态线性模型是核心工具

### 第一性原理总结

回到本章的核心命题——**为什么需要"正态"线性模型，而不只是线性模型？**

我的洞见是：

> **线性模型解决"预测"问题，正态线性模型解决"推断"问题。**
> 
> 前者问：“$\hat y$ 是多少？”
> 
> 后者问：“我们对 $\hat y$ 有多确信？$\beta_1$ 是真的非零，还是偶然？”
> 
> 工业界长期重预测轻推断，但**当模型用于决策（定价、投放、政策评估）时，推断比预测更重要**——因为你必须为决策的后果负责。

### 工业最佳实践清单

基于英文文献和工业经验，正态线性模型的完整工作流应该是：

```
1. 拟合 OLS 模型
2. 检查整体显著性（F 检验）
3. 检查系数显著性（t 检验）
4. 绘制四张诊断图：
   - Residuals vs Fitted → 线性 & 同方差
   - Q-Q Plot → 正态性
   - Scale-Location → 同方差（增强）
   - Residuals vs Leverage → 强影响点
5. 运行正式检验：
   - Breusch-Pagan → 异方差
   - Jarque-Bera → 正态性
   - VIF → 多重共线性
   - Cook's Distance → 强影响点
6. 根据诊断结果采取补救措施
7. 给出点预测 + 预测区间
8. 模型文档化与监控方案
```

> ⚠️ **没有经过步骤 4-5 的模型，不准上线**。这是工业统计建模的铁律。
