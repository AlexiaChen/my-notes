## 引子：为什么偏偏是现在？

如果你活跃于中文互联网，这两年大概都感受过一个越来越响的趋势——**怀念明朝的帖子越来越多，"清朝毁了华夏"的话术越来越精致，连"1840才是一切问题的起点"这套学了十几年的教科书框架，也开始被越来越多普通人本能地质疑。**

表面上这是在吵历史。但真正值得追问的是：**为什么是现在？为什么偏偏是明清易代这个三百八十二年前的节点，成了今天最热闹的意识形态摩擦面？**

答案不在1644年，在2025年。

本文不做站队。我们来做的是：**把这场混战拆开、归类、把事实钉死、把情绪标注、把结构性矛盾摊在桌上**

## 一、三层结构：绝大多数口水战，是因为把这三件事搅成了一锅粥

要把问题看清，第一步永远是**分类**。明清之争本质上不是一场争论，而是**三场完全不同性质的争论在舆论场上互相污染**：

### 第一层：学术层 —— 可验证的经验研究问题

比如：

- **"闭关锁国"到底是不是一个成立的标签**​ 中国历史研究院课题组在《历史研究》2022年第3期的专题论文中明确指出："'闭关锁国'不是中国古代既有概念，也不是西方对中国的固有认知，而是晚清中日语言嫁接产生的历史名词，不是对明清时期对外政策的客观描述。"明清面对西方殖民狂潮，采取的是 **"自主限关"** ——有限制，但远非完全封闭。广州十三行体系下中英贸易额持续增长，耶稣会士长期在华活动，《几何原本》被译介进来——但这些"有条件开放"恰恰缺乏**战略性技术吸收机制**。
- **大分流（Great Divergence）**：加州学派彭慕兰等人的核心贡献是证明——直到18世纪，中国江南的关键经济指标与英国差距没那么夸张，真正的分流是19世纪初才拉开，且英国靠煤炭地理优势和殖民地资源转移拉出"高水平均衡陷阱"。但这不等于"清朝没问题"——学界同样确认，差距在制度层面（产权保护、代议制传统、科学建制化）**1700年之前已存在**，清朝的"自主限关"造成的**消极防御和漠视西方先进科技**，确实为被动挨打埋下伏笔。
- **清朝统治结构的特殊性**：军机处+密折制度把君主专制推到历代之最、文字狱的思想压制、八旗特权与满汉隔离——这些是**权力结构的政治选择**，跟族裔无关，跟"谁来坐龙椅"有关。
    
这一层**有真伪、有证据、有可复核的方法**。你可以用史料和数据辩论，吵完了两边都能进步。

### 第二层：民间/情绪层 —— 现实焦虑的历史投射

这才是"越来越多人"的真正引擎：

> 人们在当下面对外部压力（对美、对日的外交困境）、内部困顿（阶层固化、房价、焦虑感），本能地回溯一个问题——**"曾经我们天下第一，是从哪一步开始掉队的？该怪谁？"**

而"明粉叙事"恰好提供了一个**极低认知成本的爽文答案**：

> 明朝万国来朝 → 满清入关毁了一切 → 如果不是辫子，我们今天就是世界老大

自媒体精确投喂这个情绪——把《永乐大典》说成"光刻机送给西方"、把裹小脚说成"清朝发明的"、把雍正密折制度等同于特务统治。这些内容在被反复证伪后仍在传播，**因为它们服务的是情绪而非求真**。

这一层的本质是：**人们需要的不是历史答案，是一个"我们本可以不这么惨"的安慰性解释**​  它跟第一层的关系，就像快餐跟营养的关系——吃得爽，但别拿它当正餐。

### 第三层：叙事/政治层 —— 国体叙述的工程学

2025年12月，浙江省委宣传部官方公众号"浙江宣传"发文《警惕"1644史观"带乱了节奏》；[中国社会科学网同步刊发长篇批驳]([【理响中国】戳破历史虚像 树立正确中华民族历史观-中国社会科学网](https://www.cssn.cn/skgz/bwyc/202512/t20251226_5963306.shtml))。核心逻辑链非常清楚：

| 命题        | 官方需要                         | 1644史观威胁什么                            |
| --------- | ---------------------------- | ------------------------------------- |
| 清朝是正统中国王朝 | 多民族国家法理链的根基（疆域、新疆、西藏、内蒙古、东北） | 把清变成"外来殖民政权"→等于把境内一个朝代踢出"中国"→直接瓦解叙事地基 |
| 历史是连续的    | 中华民族共同体意识                    | "文明中断论"=断裂叙事→暗示今天的统一是可疑的              |
| 鸦片战争框架    | 反帝叙事的锚点                      | 把所有落后归咎于1644→等于取消帝国主义的责任份额            |

中国社科院研究员鱼宏亮直言："'1644史观'本身是生造的概念，源于网络空间的情绪宣泄"。但"浙江宣传"也承认它并非凭空而来——雏形可追溯至民国初期的汉民族主义。

**所以官方紧张，不是因为有人在骂清朝（清朝当然该骂），而是因为骂法一旦越线变成"清非中国"，整个多民族国家的法理叙事就会从根基处被撬动**​ 正如"浙江宣传"所言：这种论调"与境外某些旨在解构中国历史连续性的叙事形成了呼应，为那些试图否定中国统一多民族国家历史合法性的论述提供口实"。

## 二、直面硬事实：扬州十日、嘉定三屠——以及"明朝有没有干过？"

**这一节不能绕，也不该绕。**

### 事实层面

扬州十日（《扬州十日记》）、嘉定三屠（《嘉定乙酉纪事》）、江阴八十一日——**屠城事实本身没有争议**。三方史料交叉印证（私人笔记、地方志人口骤降记录、耶稣会士卫匡国等的独立见证），清军在征服江南过程中将屠城作为**威慑性军事政策**使用，这是学术共识。

但数字要诚实：**"八十万"是孤证，超出城市承载力**，学界估实际死亡数在**数万级**。嘉定三屠合计也是**数万**量级。

而让这些事件在历史上分量格外刺眼的，是**剃发令**——"留头不留发"——把文化认同变成了生死线。这是**军事征服 + 文化强制**的双重暴力，不是普通的攻城报复。

### 明朝有没有对应的？

有，但要做区分，不能拿"方孝孺诛十族"来充数——那是**精英政治清洗**（杀八百余人，朱棣的瓜蔓抄让村里为墟），不是屠城平民。

真实对照：

- **明末军阀劫掠**：高杰、刘泽清部从徐州到扬州一路烧杀，**"杀人则积尸盈野、污淫则辱及幼女"**，《明季南略》载"郊外之民何啻百万"遭殃——这是明军在自己国土上干的
- **元末明初屠城**：常遇春攻城时的屠城记录、傅友德/蓝玉征云南的平民伤亡——但那是**开国战争**语境
- **张献忠在四川**：几十万平民死于大西军之手——但他不是"明朝"，是反明势力
    
### 真正有意义的比较

| 维度    | 清初屠城                                               | 明朝暴行                     |
| ----- | -------------------------------------------------- | ------------------------ |
| 对象    | **城市平民**无差别杀戮                                      | 主要是精英清洗（靖难）/末期军阀化劫掠/开国战争 |
| 是否系统化 | 征服阶段的**有意识威慑工具**​ + 剃发令文化强制绑定                      | 无"剃发令"级别的配套文化灭绝工程        |
| 关键结论  | **中国古代屠城不是清朝发明的**（春秋就有），但清朝的特殊性在于把屠城纳入"征服-同化"的系统工程 | 明朝也血债累累，但结构位置不同          |

**记住谁的刀都不意味着原谅另一把刀**​ 理性态度是：**承认屠城事实 → 承认清朝征服过程的残暴性 → 承认明朝也不干净 → 但拒绝把事实塞进"满清是外来殖民政权所以一切罪恶之源"的跳跃叙事。**

## 三、二十四史为什么没有清史？——以及那部3200万字的书为什么卡死了

### 先校正一个误解

"二十四史没有清史"**不是清朝故意不把自己写进去**。"二十四史"是乾隆钦定的清单（从《史记》到《明史》），传统规矩是**后朝修前朝史**——所以清朝修了《明史》，没问题。

**真正的问题在后面：清亡1912年 → 民国该修《清史》→ 没修成 → 新中国接手 → 2002年大工程启动 → 2018年3200万字送审稿上交 → 卡死到现在，20多年了，还没出。**

### 《清史稿》为什么不算

民国1914年设清史馆，赵尔巽主持，1927年刊印《清史稿》。但：

- 编纂者是**清朝遗老**，书中称"今上""大清"，对辛亥革命用语含讥讽
- 南京国民政府1929年直接**列为禁书**
- 赵尔巽自己说："此急救之章，非视为成书"
    
**它不是被"排除"因为政治迫害——它在学术上就是一个未定稿本，立场屁股坐歪了，新政权看了当然不认。**

### 2002年重启的《清史》纂修工程——为什么写完出不来？

时间表：

- **2002年**：中宣部下辖，戴逸领衔，2000+学者参与
- **2012年底**：95%稿件到位
- **2016年**：初稿完成
- **2018年9月**：106册、3200万字送审稿**上报中央**
- **2019年**：预计半年审完 → 没审完
- **2023年**：央视报道"审读工作初步完成"——但没出版
- **2024年1月**：戴逸去世，**书还没出**
- **2025年3月**：社科院成立**清史研究中心**，明确承接这部"近20年未通过审查的《清史》"
#### 卡住的真正原因 = **四条绳索往不同方向拉**

```
① 疆域法理 ← 清朝奠定现代中国版图 ──→ ② 多民族叙事
        ↑                                      ↓
  清初屠城/剃发令                  （不能写太重→洗白？ 不能写太轻→分裂？）
        ↑                                      ↓
③ 革命叙事（辛亥=驱逐鞑虏）←→④ 今天"五十六族一家"（不可分裂）
```

具体来说：

1. **你必须把清朝写成正统中国王朝**（否则新疆、西藏、内蒙古、东北的"自古就是中国"法理链断了——这是**生死线**），但扬州十日、剃发令是抹不掉的事实，写轻了被骂洗白，写重了跟"正统"叙事拧着
2. **太平天国**是农民起义还是造成江南残破的动乱？**李鸿章**是卖国贼还是裱糊匠？**袁世凯**怎么定性？每一个人物评价都是雷区
3. **"新清史"阴影**：美国学派强调清朝"内亚帝国"属性，国内定性为有"政治目的"、解构中国多民族叙事——所以任何暗示"清朝有满制特殊性/不完全汉化"的表述都会被揪住
4. 据透露的审读意见方向包括：**"过于强调西方列强影响，不够突出清朝是大一统国家"**
    
> **这不是某个领导拍桌子说"不许出真话"的简单压制。这是一个更深层的困境：清朝恰好是所有当代中国核心叙事的交汇点——领土合法性、民族关系、革命传统、近代屈辱的责任分配——全压在一部断代史上。它必须完美。但完美不可能。**

所以那部稿子就一直在"审"。

而这也解释了为什么民间"1644史观"让官方这么紧张——**不是因为有人在翻旧账，而是因为一旦清史的正统叙述出现裂缝，整座大厦的承重墙就露出来了**​ 他们必须堵，但也正因为必须堵，反而证明了：**那具尸体上面还站着太多活人需要它摆出某个姿势。**

## 五、认知模型


### 🔧 模型一：**三层切片法**（The Three-Layer Slice）

> 任何看起来"吵成一团"的公共话题，先别跟着吵，问：**这是哪一层的争论？**

| 层              | 检验标准                   | 处理方式                         |
| -------------- | ---------------------- | ---------------------------- |
| **L1 事实/学术层**​ | 有证据、可复核、可证伪            | 找原始材料，看数据，跟踪学界共识的变动前沿        |
| **L2 情绪/身份层**​ | 人们用历史给自己贴标签、找替罪羊、求安慰   | 标注它、理解它、但不把它当真理——它是风向标，不是答案  |
| **L3 权力/叙事层**​ | 有人"必须让这件事呈现某种样子"否则地基会塌 | 识别哪根柱子在受力——你就不容易被表面的"学术讨论"带偏 |

**明清之争之所以无解，就是因为99%的参与者在同一句话里混用了三层**​ 一个人用L2的情绪在发言，另一个人用L3的权力在反驳，第三个人用L1的事实在围观——**三者永远对不上频率。**

> **操作口诀：遇到大混战 → 先切片 → 再决定你要参与哪一层 → 别用L2情绪去打L1事实仗，也别用L1事实去回答L3的结构性恐惧。**

---

### 🔧 模型二：**结构性张力诊断**（Structural Tension Diagnosis）

> 当一件事"明明写完了但出不来""明明有结论但吵了二十年"——别急着骂"有人捂盖子"，先画**受力图**。

清史的例子完美示范了这个方法：

```
A ──→ 需要宣称 ←── B
│                      │
清朝 = 正统中国      清朝有屠城+剃发+专制
│                      │
C ──→ 需要平衡 ←──── D
│                      │
辛亥"驱除鞑虏"       今天"五十六族一家"
```

**四个力往不同方向拉，中间的结就是《清史》

这不是阴谋，这是**结构性悖论**——系统的要求彼此矛盾，任何单一解法都会在某条线上"不正确"。

**你在生活中遇到同类现象时（公司战略文件卡住、家族矛盾说不清、社会议题两头不讨好）——先画受力图，不要急着找坏人。很多"卡住"不是某人作恶，是系统让他坐在一个不可能位置。**

---

### 🔧 模型三：**情绪溯源法**（Follow the Emotion Home）

> 当你看到一个历史话题突然爆火——**别先问"这说法正确吗"，先问"这回答了人们什么当下的不安？"**

"1644史观"的引爆点不是有人发现了新史料，而是：

- 近代屈辱记忆从未被消化 → 需要一个更"解气"的解释
- 当下国际困境（对美、对日）→ 回溯"我们从哪一步跌落的"
- 内部焦虑（阶层、房价、前景）→ 需要一个"我们本可以"的平行宇宙
    
**规律：当一个社会对当下有充分的方向感和掌控感，它就不需要去历史里找替罪羊。反之，历史就会被反复征用为情绪容器。**

> 操作口诀：**每次你觉得"怎么这么多人突然开始吵X话题"——把X减去一百年，看它在替今天的什么痛点代言。**

---

### 🔧 模型四：**可证伪锚定**（Falsifiability Anchoring）

不管争论多热闹，你个人只押注在**能被史料推翻的东西**上：

- ✅ "清朝军机处强化了君主专制"——可证伪，有大量档案支撑
- ✅ "闭关锁国是过度简化的标签"——可证伪，学界已在修正
- ✅ "扬州十日发生了无差别平民屠杀"——可证伪，三方记录交叉印证
- ❌ "如果不是满清，中国就自发长出工业革命"——**不可证伪**，反事实无限循环，是爽文不是分析
- ❌ "满清是外来殖民政权所以一切=完了"——**不可证伪**，把所有复杂因果压成一个标签，是情绪闭环
    
> **你不需要在所有问题上表态。你只需要守住一条线：我只跟能被证据改变结论的命题绑定。其余的——看戏就好。**
