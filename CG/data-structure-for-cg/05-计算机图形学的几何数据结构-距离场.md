
# 读书笔记：Chapter 5 - Distance Fields

**核心主题：从“离散的几何图元”到“连续的标量场”，用函数定义形态**

## 一、全局视角：为什么需要距离场？

回顾前四章，我们一直在处理**离散的、显式的**几何表示：

- **第一至四章**：四叉树、BSP、BVH。这些结构存储的是点、线、三角形或包围盒。它们回答的问题是：“这个点在哪里？”或者“这两个物体相交吗？”
- **局限性**：这些结构难以回答“物体表面距离我还有多远？”这类连续性问题。要进行平滑变形、软体碰撞或高质量阴影渲染，我们需要一种**连续的几何描述**。
    
**距离场（Distance Field，DF）**，更精确地说**有向距离场（Signed Distance Field，SDF）**，正是为此而生。它将几何从“一堆三角形”转变为一个**函数**​ f(p)：

- 若 p 在物体内部，f(p)<0
- 若 p 在物体表面，f(p)=0
- 若 p 在物体外部，f(p)>0
    
**本章在全书的定位**：

如果说前四章讲的是 **“如何组织数据以加速查询”**，那么本章讲的是 **“如何重新定义数据本身”**。距离场不仅是一种数据结构，更是一种**几何语义**。它是现代实时渲染（尤其是SDF渲染）和物理模拟的基石。

## 二、逐节逻辑梳理

### 1. 距离场的计算和表示 (Computation and Representation)

将几何表示为场，首先面临两个问题：如何计算？如何存储？

#### 1.1 传播方法 (Propagation Methods)

**适用场景**：从已有的离散几何（如三角网格、二值图像）生成距离场。

**原理**：类似于流体从源头发散填充空间。经典算法是 **Danielsson 距离变换**​ 或 **八向距离变换**。

1. 初始化：将物体表面像素/体素标记为0，其余标记为无穷大。
2. 前向扫描：从左上到右下，每个像素取其邻域最小值加一。
3. 反向扫描：从右下到左上，重复上述过程。
    
    **为什么重要**：这是**离线预处理**的标准手段。在游戏开发中，我们常将复杂模型预计算为低分辨率的SDF体素网格，用于运行时快速查询。这也是**Level Set Methods（水平集方法）**的核心，广泛用于流体模拟和火焰蔓延效果。
    
#### 1.2 距离函数的投影 (Projection of Distance Functions)

**适用场景**：直接用数学函数定义几何（如球体 x2+y2+z2​−r）。

**核心概念**：**隐式曲面（Implicit Surface）**。我们不需要存储一个网格，只需要存储函数 f(x,y,z)。

**投影（Closest Point Projection）**：对于任意一点 p，找到表面上最近的点 q。距离就是 ∥p−q∥。

**为什么重要**：这是**程序化生成（Procedural Generation）** 的灵魂。像 _Shadertoy_ 或 _Signed Distance Functions (SDFs)_ 这样的技术，直接用代码写函数。它避免了庞大的网格数据，且数学定义的曲面具有无限细节（Infinite Detail），放大后依然平滑。

### 2. 距离场的应用 (Applications)

#### 2.1 渐变变形 (Gradient-Based Deformation)

**核心原理**：利用距离场的**梯度（Gradient）**。梯度 ∇f 指向距离增加最快的方向（即法线方向）。

**应用逻辑**：

- **推拉（Offsetting）**：要膨胀或收缩物体，只需改变等值面：新表面 f(p)=d（d为正数膨胀，为负数收缩）。
- **平滑变形**：利用梯度进行插值。例如，让一个球体沿着另一个复杂物体的表面滑动，只需不断查询当前位置的SDF值和梯度，即可获得法线方向进行反弹或吸附。

    **为什么比传统网格变形强**：
    
    传统网格变形（如顶点混合）容易导致网格塌陷或穿插。基于SDF的变形是**体积上的操作**，保证了拓扑的正确性。在**柔体动力学**中，SDF用于计算穿透深度（Penetration Depth），从而施加正确的排斥力。
    
#### 2.2 造型 (Modeling / Constructive Solid Geometry revisited)

**核心原理**：**距离场运算**。这是SDF最迷人的地方——**CSG（构造实体几何）变得极其简单**。

回想第三章用BSP树做布尔运算，需要对多边形进行切割，极其复杂。而在SDF中：

- **并集 (Union)**：min(fA​(p),fB​(p)) —— 谁离得近（距离小）听谁的。
- **交集 (Intersection)**：max(fA​(p),fB​(p)) —— 必须同时在两个物体内部（距离都为负）。
- **差集 (Subtraction)**：max(fA​(p),−fB​(p)) —— 减去B等价于加上B的反体（取负）。
- **光滑融合 (Smooth Union)**：使用指数平滑函数代替 min，如 smin(a,b)=−ln(e−ka+e−kb)/k。这让两个物体融合时没有硬边，产生类似液体的效果。
    
**实际应用**：

- **影视特效**：电影中的液态金属、生物形变（如《终结者》）。
- **游戏引擎**：Unity 的 HDRP 和 Unreal Engine 的 Shader 中常用SDF进行特效建模。
- **字体渲染**：Valve 的经典论文利用SDF在低端硬件上渲染高清字体，这是SDF在工业界最早的大规模应用之一。

```
    ↓ 数据：连续的标量场 (Scalar Field)
    ↓ 优势：平滑、解析、无限细节
```

**深度关联分析**：

1. **与 BVH 的关系（查询加速）**：
    
    虽然SDF本身是函数，但在实际渲染（光线步进/Ray Marching）中，我们需要加速结构。
    
    - **BVH 包裹 SDF**：我们可以将SDF的包围盒放入BVH中。当光线追踪时，先用BVH排除无关区域，在命中的叶节点内再进行SDF的光线步进。这是**离线渲染器（如Blender Cycles）** 常用的混合策略。
    - **SDF 辅助 BVH**：在计算BVH的 SAH（表面积启发式）时，如果能预知图元的近似体积或形状，SDF可以提供比AABB更精确的估计。
        
    
2. **与 BSP/CSG 的关系（几何构造）**：
    
    第三章我们用BSP树做CSG，那是**多边形级别的布尔运算**，会产生大量的新顶点和切片。
    
    本章我们用SDF做CSG，那是**函数级别的组合**，不产生任何新数据，只是改变了查询时的计算逻辑。这是**声明式（Declarative）** 与**命令式（Imperative）** 的区别。
    
3. **与纹理合成（第二章）的关系**：
    
    第二章提到纹理合成。SDF可以被视为一种**特殊的纹理**——一张存储着几何信息的纹理。GPU可以非常高效地采样SDF纹理，从而实现实时的体积效果或表面特效。
    

**贯穿始终的"Why"**：

1. **为什么要算距离场**​ 为了获得**几何的上下文信息**。三角形只告诉你“边界在哪”，SDF告诉你“你离边界有多远，往哪走能到达边界”。这对于物理模拟（碰撞响应）和渲染（软阴影、环境光遮蔽）至关重要。
    
2. **为什么SDF适合变形**​ 因为它是基于**场**的。场的变化是连续的，不像网格那样受拓扑结构限制。你可以轻易地让一个SDF定义的球体穿过一个SDF定义的墙壁，并在穿过过程中实时计算碰撞反馈，而无需担心网格撕裂。
    
3. **为什么SDF是未来的趋势**​ 因为**GPU 并行计算**。计算一个像素的SDF值是一个独立的任务，非常适合GPU的大规模并行架构。这就是现代光线追踪（Path Tracing）和实时SDF渲染（Sphere Tracing）能够在GPU上高效运行的原因。

## 四、实际工程中的挑战与权衡

尽管SDF很美，但在工程中需要注意以下几点：

1. **存储成本**：高精度的SDF体素网格（Voxel Grid）消耗巨大内存。通常使用**稀疏体素八叉树（SVO）** 来存储SDF，只存储表面附近的体素。
    
2. **计算精度**：对于复杂的多边形网格，计算准确的SDF（特别是内部距离）非常耗时。通常使用**有向距离场（SDF）**而非无符号距离场（UDF），但这要求网格必须是水密的（Watertight）。
    
3. **梯度计算**：数值计算的梯度（差分法）有时会有噪声，解析梯度更准确但难以获取。在Shader编程中，通常使用 `dFdx`, `dFdy` 或手动差分来获取梯度。
