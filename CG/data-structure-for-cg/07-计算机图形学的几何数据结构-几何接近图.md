
# 读书笔记：Chapter 7 - Geometric Proximity Graphs

**核心主题：用"图"重新定义邻近——从欧氏距离到拓扑距离的跃迁**

## 一、全局视角：为什么需要接近图？

回顾前六章，我们已经积累了丰富的空间工具：

- **第一至四章**：四叉树、BSP、BVH——空间加速结构
- **第五章**：距离场——连续标量场表示
- **第六章**：Voronoi 图——空间归属的几何划分，以及对偶的 Delaunay 三角剖分

本章的**几何接近图（Proximity Graph）**是一个微妙但深刻的补充。它的核心思想是：

> 给定点集 P，在两个点之间连边当且仅当它们满足某种"邻近准则" P。

形式上，接近图是一个图 G=(V,E)，其中 V 是点集，E 中的边 (u,v) 存在当且仅当 u 和 v 满足定义的邻近性质 。

**本章在全书的定位**：

```
前六章：空间"在哪里" → 距离场"有多远" → Voronoi"归谁所有"
    ↓ 缺了什么？
第七章：邻近关系"如何连接"
```

**为什么这个视角至关重要**​ 因为在很多图形学问题中，**欧氏距离会误导我们**。考虑一个带有空腔的 3D 点云：两个点欧氏距离很近，但在曲面上却相距甚远（中间隔着空腔）。如果用欧氏距离做核函数权重，空腔对面的点会影响当前位置的曲面定义，产生严重伪影 。

接近图的天才之处在于：**它用图上的最短路径近似曲面上的测地距离**，从而让"邻近"服从曲面的拓扑结构，而非欧氏空间的直线距离 。

## 二、逐节深度解读

### 1. 一个很小的接近图集合 (A Small Set of Proximity Graphs)

#### 1.1 初步定义

**邻近准则（Neighborhood Criterion）**：决定两个点是否连边的几何谓词。不同的准则产生不同类型的接近图 。

**关键认识**：接近图不是一个具体的数据结构，而是**一类数据结构的总称**——通过调整邻近准则 P，我们可以得到不同密度、不同性质的图。

#### 1.2 一些接近图定义

经典谱系（按边密度从小到大排列） ：

|图类型|邻近准则|特性|
|---|---|---|
|**NNG**（最近邻图）|v 是 u 的最近邻|有向图，最稀疏|
|**MST**（最小生成树）|EMST 的边|无环连通|
|**RNG**（相对邻域图）|不存在点 w 使得 d(u,w)<d(u,v) 且 d(v,w)<d(u,v)|无环，保持形状骨架|
|**GG**（Gabriel 图）|以 uv 为直径的球内无其他点|Delaunay 的子图|
|**DG**（Delaunay 图）|三角剖分的边，空圆性质|平面图，连通性最强|

**层级包含关系**（这是本章最重要的数学事实）：

NNG⊆MST⊆RNG⊆GG⊆DG

这个层级告诉我们：**Delaunay 图是最"慷慨"的邻近图**——它包含其他所有图作为子图。反过来，RNG 和 GG 是 DG 的稀疏化版本，保留了 DG 的核心拓扑但边更少 。

**Order-k 推广**：k-NNG、k-RNG、k-GG、k-DG 将"0 阶邻近"推广为"k 阶邻近"，同样满足层级 k−NNG⊆k−RNG⊆k−GG⊆k−DG 。

#### 1.3 包含属性 (Inclusion Properties)

**为什么层级关系重要？**

- **理论价值**：证明了不同接近图之间的蕴含关系
- **工程价值**：如果你需要稀疏图，选 RNG；如果需要连通性保证，选 DG；中间的 GG 是很好的折衷
- **算法设计**：许多基于 DG 的算法可以自然地下放到其子图，获得性能提升
#### 1.4 构造算法

- **朴素构造**：O(n2) 时间，检查所有点对
- **基于 Voronoi/Delaunay**：先计算 Delaunay 三角剖分 O(nlogn)，然后从中提取子图
- **随机化与剪枝**：现代方法通过随机采样和剪枝达到接近线性的构造时间
- **动态维护**：支持插入/删除，摊销 O(logn)

### 2. 分类 (Classification)

#### 2.1 问题描述

**核心任务**：给定点云，如何自动确定其内在类别或结构？

**为什么接近图适合分类？**​ 因为接近图捕获了点集的**拓扑指纹**——不同形状的点云会产生结构迥异的接近图。例如：

- 聚类状点云 → 接近图呈现多个连通分量
- 流形上的点云 → 接近图近似流形的拓扑
- 均匀采样 → 接近图边数适中且分布均匀
    
#### 2.2 编辑和简化集合 (Editing and Simplifying Sets)

**图简化技术**：

- **边剪枝**：移除"过长"的边（相对于局部密度）
- **节点合并**：将密集子图的代表节点保留，其他节点融入
- **k-NNG 调整**：通过改变 k 控制图的密度
    
这些操作在保持拓扑特性的同时降低计算成本，是处理大规模点云的关键。

#### 2.3 用于编辑的接近图

**交互式编辑**：在 CAD 或 3D 建模中，设计师需要实时编辑点云。接近图提供了：

- **局部操作**：编辑一个区域只影响该区域的图结构
- **拓扑保持**：编辑过程中自动维持流形性质
- **实时反馈**：图的局部更新 O(logn)

#### 2.4 清除训练集合 (Cleaning Training Sets)

**离群点去除**：基于接近图的连通性分析：

- 孤立节点（度数为 0 或 1）→ 可能为噪声
- 小型连通分量 → 可能为异常簇
- **RNG 的特殊价值**：RNG 是参数无关的（"auto-adjusted"），能够自然暴露数据中的离群结构

### 3. 由点云定义的表面 (Point Cloud Defined Surfaces)

这是本章**最激动人心的应用**，也是 Klein & Zachmann 在 SIGGRAPH 2004 的突破性工作 。

#### 3.1 隐式曲面建模

**传统 MLS（移动最小二乘）的问题**：

f(x)=n(x)⋅(x−a(x))

其中 a(x) 是加权平均位置，n(x) 是 MLS 法线。

**伪影根源**：权重函数 θ(d)=e−d2/h2 基于**欧氏距离**​ d=∥x−p∥。

这会导致两类严重伪影 ：

1. **空腔穿透**：当 x 位于空腔附近时，空腔对面的点对 a(x) 有很大权重，将零点集拉向空腔外侧
2. **带宽失配**：固定带宽 h 不适应局部采样密度
    
#### 3.2 欧几里得内核的局限

**核心洞察**：欧氏距离 d(x,p) 小，并不意味着曲面上的测地距离 dS​(x,p) 小。这两个距离的差异正是伪影的根源 。

#### 3.3 测地距离近似 (Geodesic Distance Approximation)

**解决方案**：用接近图上的最短路径近似测地距离。

**算法流程**：

1. 构建点云的接近图（如 DG 或 SIG）
2. 对于查询点 x，找到最近邻 p∗
3. 在图上计算 p∗ 到所有点的最短路径距离 d(p∗,p)
4. 定义 x 到 p 的距离为：dgeo​(x,p)=minn∈{p1∗​,p2∗​}​(d(n,p)+∥x−p^​∥)，其中 p^​ 是 x 在 p∗ 邻接边上的投影
    
**为什么这有效**​ 因为图上的最短路径自然绕开空腔，服从曲面的拓扑结构。

#### 3.4 自动带宽计算 (Automatic Bandwidth Computation)

**关键技巧**：接近图提供了**局部采样密度**的估计。

利用 k-最近邻的距离，可以自动计算局部带宽：

h(p)∝∥p−pk​∥

其中 pk​ 是 p 的第 k 个最近邻。

**价值**：无需手动调参，自适应不同采样密度的点云 。

#### 3.5 自动边界检测 (Automatic Boundary Detection)

**原理**：边界点具有明显的图结构特征：

- 度数较低
- 局部密度梯度大
- 在 SIG 中，影响球半径异常
    
通过接近图的局部性质，可以**自动识别点云的边界**，无需额外标注 。

#### 3.6 函数复杂度评估

**理论复杂度**（3D 均匀采样点云）：

- 构建 DG 或 SIG：O(n)
- 计算 CPSP（Close-Pairs Shortest-Paths）矩阵：O(n)
- 评估 f(x)：O(log3n) 时间找到最近邻 + O(1) 查表
    
**关键结论**：新的基于测地距离的核函数，**渐进复杂度与欧氏核函数同阶**，但实验表明 f(x) 的计算速度与之前一样快，同时伪影显著减少 。

### 4. 点云之间的交叉检测 (Intersection Detection Between Point Clouds)

这是接近图的另一杀手级应用——Zachmann 在点云碰撞检测上的开创性工作 。

#### 4.1 根划界 (Root Bracketing)

**问题**：给定两个点云 A 和 B，找到公共点 x 使得 fA​(x)=fB​(x)=0。

**随机化根划界算法**：

1. 在 A 上随机采样 O(alna+c⋅a) 个点（a 是期望的划界密度）
2. 对于每个采样点 pi​，在其邻域内找 pj​ 使得 fB​(pi​) 和 fB​(pj​) 异号
3. 这样的点对 (pi​,pj​) 构成了一个"根括号"——保证交点存在于它们之间
    
**为什么用随机化**​ 穷举所有点对是 O(n2)，随机化采样在概率意义上以高置信度找到所有交点 。

#### 4.2 邻居大小 (Neighbor Size)

**r-SIG 的引入**：原始 SIG 定义为两点 pi​,pj​ 相连当且仅当 ∥pi​−pj​∥≤di​+dj​（di​ 是到最近邻的距离）。

**问题**：噪声点云中会出现大量孤立"迷你簇"。

**解决方案**：使用 **r-SIG**，计算到第 r-最近邻的距离而非最近邻。经验最佳值 r=3 或 r=4 。

**为什么 r-SIG 更好**​ 增加 r 会增加边的数量，防止图断裂成过多连通分量，从而保证根划界算法的完整性。

#### 4.3 完成划界

**完整流程**：

1. 构建 r-SIG 图
2. 随机化采样产生根括号
3. 每个根括号对应一个潜在的交点区域
    
#### 4.4 插值搜索 (Interpolation Search)

**核心算法**：对于每个根括号 (pi​,pj​)：

1. 在接近图上找到 pi​ 到 pj​ 的最短路径
2. 沿路径使用**插值搜索**找到 ∣f^​(p^​)∣=min 的点 p^​
3. 插值搜索利用 f 沿路径的单调性，达到 O(loglogN) 的理论复杂度
    
**为什么是插值搜索**​ 假设 f 沿路径 pi​pj​​ 是单调的，插值搜索可以利用函数值的信息直接"跳跃"到零点附近，比二分搜索更快。

#### 4.5 带边界的模型

**挑战**：边界区域的点云采样不完整，传统的 CPSP 计算会失效。

**解决方案**：

- 在边界附近增加采样密度
- 使用特殊的边界处理核函数
- 通过接近图的度数分析识别边界点，进行特殊处理
    
#### 4.6 精确的交点

**细化步骤**（可选）：

1. 在近似交点 p^​ 周围采样半径为 r 的球体
2. 球内采样 s=⌈3​⋅r/ε⌉3 个点
3. 使用随机化细化迭代逼近精确交点
    
**精度控制**：ε 控制最终精度，用户可根据应用需求指定。

#### 4.7 运行时间

**理论复杂度**：O(loglogN)（假设 f(x) 沿路径单调且点云均匀采样）

**实验结果**（来自 Zachmann 的 VR 2005 教程）：

|距离（相对包围盒大小）|RST（旧方法）|iSearch（新方法）|
|---|---|---|
|0.0|2.5|2.0|
|0.5|10.0|2.0|
|1.0|3.0|2.0|
|2.0|19.0|2.0|

**关键发现**：传统方法（RST）的运行时间随查询距离剧烈波动，而新的插值搜索方法**稳定保持在 2.0 左右**，展现了卓越的性能稳定性 。

## 三、章节脉络与全书连接

本章是全书逻辑演进的关键一环：

```
第一章：四叉树/八叉树 → 空间栅格细分
    ↓ 从规则栅格到数据驱动
第二章：kd树/范围树 → 轴对齐查询索引
    ↓ 融入"层次包围"思想
第三章：BSP 树 → 超平面分割空间
    ↓ 放弃"平面分割空间"，改为"分组包围对象"
第四章：BVH → 对象分组与嵌套包围
    ↓ 从离散对象到连续场
第五章：距离场 → 连续标量场表示
    ↓ 最近点归属的显式表达
第六章：Voronoi 图/Delaunay → 空间归属划分与三角剖分
    ↓ 从"欧氏邻近"到"拓扑邻近"
第七章：几何接近图 → 拓扑驱动的邻近关系
```

**与前六章的深度连接**：

1. **与第六章 Delaunay 的直接继承**：
    
    - Delaunay 图是接近图谱系的"顶端"——最稠密、连通性最强
    - RNG、GG 是 DG 的稀疏化版本
    - 本章的核心创新：利用 DG 和其他接近图（如 SIG）的**图结构**而非单纯的几何划分
        
2. **与第五章距离场的深度融合**：
    
    - 距离场存储点到表面的距离
    - 接近图提供计算"拓扑距离"的工具
    - **两者结合**：基于接近图最短路径的测地距离场，既连续又拓扑正确
        
3. **与第四章 BVH 的互补**：
    
    - BVH 通过空间排除加速碰撞检测
    - 接近图通过拓扑邻近加速碰撞检测
    - **混合使用**：BVH 做 broad-phase，接近图做 narrow-phase 的拓扑分析
        
4. **与第二章 kd 树的协同**：
    
    - kd 树用于快速最近邻查询（找到 p∗）
    - 接近图用于在 p∗ 的基础上传播距离信息
    - **协同工作流程**：O(log3n) 找到最近邻 + O(1) 图查询
        
**贯穿始终的"Why"**：

1. **为什么需要接近图？**​ 因为欧氏距离在很多图形学问题中会误导——它穿越空腔、忽略拓扑。接近图用图上的最短路径近似测地距离，从根本上解决了这个问题。
2. **为什么是 Delaunay 图？**​ 因为它是包含所有其他接近图的最稠密平面图，连通性最有保证。但它的"长边"可能穿越空腔，所以需要剪枝或改用 SIG。
3. **为什么自动带宽和边界检测重要？**​ 因为真实点云采样密度不均，手工调参不现实。接近图提供的局部密度估计使算法完全自动化。
4. **为什么插值搜索能达到 O(loglogN)？**​ 因为它利用了 f(x) 沿路径的单调性，通过函数值的大小直接"预测"零点的位置，而非盲目二分。

## 四、实际工程中的应用延展

**现代图形学中的接近图应用**：

1. **点云渲染**（Point-Based Rendering）：
    
    - 基于接近图的隐式曲面定义，实现了高质量的 MLS 曲面渲染
    - 自动带宽适应不同采样密度，无需艺术家手动调整
        
2. **点云碰撞检测**：
    
    - 工业级应用：机器人路径规划、虚拟装配、医疗手术模拟
    - 实时性能：interpolation search 方法稳定在 2.0 的相对运行时间
        
3. **3D 重建与 SLAM**：
    
    - 持久性点特征直方图（PFH）依赖 k-NNG 的局部邻域
    - 接近图提供的拓扑结构提高了特征描述的鲁棒性
        
4. **几何处理**：
    
    - 网格去噪、孔洞修复、特征保留简化
    - 基于 RNG 的形状骨架提取
        
5. **机器学习与数据挖掘**：
    
    - 近似最近邻搜索（ANN）的现代图索引方法（如 HNSW）本质上是可导航的接近图
    - 无监督表示学习、异常检测
        
> 💡 **关键工程洞察**：
> 
> 1. **DG vs SIG 的权衡**：DG 连通性好但可能穿越空腔；SIG 拓扑正确但需要 r-SIG 扩展来保证连通性。实践中常两者结合使用。
> 2. **r 值的选择**：r-SIG 中 r=3 或 r=4 是经验最佳值，过小会导致图碎片化，过大则失去局部性。
> 3. **CPSP 矩阵的妙用**：预计算 close-pairs shortest-paths 矩阵，将 O(N) 空间换 O(1) 查询时间，是实时应用的关键。
> 4. **随机化的重要性**：根划界的随机化采样在理论和实践中都被证明是高效的——以高概率找到所有交点，且运行时间稳定。

## 五、总结：接近图在全书中地位的升华

第七章是全书的一个**范式转换**——从前六章的"几何结构"转向"拓扑结构"：

**全书逻辑主线的最终演进**：

```
空间细分（QTree/Octree）
    → 查询索引（kd/Range Tree）
    → 平面分割（BSP）
    → 对象分组（BVH）
    → 连续场表示（SDF）
    → 空间归属划分（Voronoi/Delaunay）
    → 拓扑邻近图（Proximity Graphs）
```

接近图的深刻性在于：它揭示了**"邻近"这个概念如何依赖于我们对空间的认知方式**。欧氏邻近是平直空间的直觉，但曲面上的拓扑邻近才是图形学的真实需求。通过 Delaunay 图、Gabriel 图、RNG、SIG 等不同层级的接近图，我们获得了**从稠密到稀疏、从欧氏到拓扑**的完整频谱工具。

**为什么这一章是现代点云处理的基石？**

因为点云已经成为 3D 数据采集的标准格式（激光雷达、深度相机、摄影测量）。理解接近图，意味着理解：

- 如何从噪声点云重建高质量曲面
- 如何自适应不同采样密度
- 如何自动检测边界
- 如何实现实时点云碰撞检测
    
Klein & Zachmann 的工作 表明：**接近图不是理论玩具，而是能够产生"artifact-free、fast、automatic"的工业级解决方案的实用工具**。
