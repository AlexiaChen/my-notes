

# 《算法》（Sedgewick & Wayne）第4章 · 图 —— 读书笔记

> **开篇锚点（第一性原理）**：图是"关系"的通用数学模型——任何"对象 + 对象之间的某种联系"都能建模为图。本章的全部算法，本质上是在回答几个根本问题：**能不能到达（可达性）？怎么走过去（路径/遍历）？如何把图"拆成互不干扰的块"（连通分量/拓扑排序/强连通）？在所有连接方案中哪条最省钱（最小生成树）？从一个点到其余各点怎么走最近（最短路径）？**​ 每一步，都是把"关系"用合适的数据结构表示，再用"遍历 + 贪心/松弛"从局部推到全局最优。

---

## 一、4.1 无向图 —— 图的"第一公民"与两种遍历

### 1.1 术语与表示（4.1.1–4.1.2）

图 G=(V,E)：V 个顶点、E 条边；无向边 (v,w) 双向连通；**当两个顶点间存在路径，则称它们连通**；极大连通子图叫**连通分量**；含 V−1 条边且连通的图是**树**；E≈V、局部连接为主的图是**稀疏图**（实际中最常见）。

**邻接表表示（核心）**：用顶点数 V 的数组，每个元素是一条链表/背包，存该顶点的所有邻接点。**洞见 ①：邻接表是"空间与时间的折中"——空间 O(V+E)（稀疏图极省），判断"v-w 是否相邻"需遍历 v 的邻接表 O(degree(v))，而遍历全图 O(V+E)。**​ 相较邻接矩阵 O(V²)（稠密图/快速判边有利），邻接表是绝大多数图算法的默认起点，也是"表示决定算法效率"的又一范例。

### 1.2 深度优先搜索 DFS（4.1.3–4.1.4）："一条路走到黑"

DFS 递归地：标记当前顶点为已访问 → 对其每个未访问的邻接点递归 DFS。**关键不变量：DFS 标记一个顶点时，它到起点的路径上所有顶点都已被标记（路径即递归栈）。**

- **命题**：DFS 访问与起点连通的所有顶点，且每条边只被检查两次，时间 O(V+E)。
    
- **寻找路径（4.1.4）**：维护 `edgeTo[v]`=DFS 树中 v 的父结点，回溯 `edgeTo` 即得从起点到 v 的路径（可存为栈）。
    

**洞见 ②：DFS 的本质是"递归 = 栈"，它天然在探索"一条完整路径"——适合回答"是否存在路径/环/连通性"，但找到的路径未必最短。**​ 把 DFS 想象成"走进迷宫、沿墙摸索到底再回溯"——它覆盖全图，却不顾路径长短。

### 1.3 广度优先搜索 BFS（4.1.5）："一圈一圈向外荡"

BFS 用**队列**：把起点入队并标记 → 循环出队一个顶点，将其所有未访问邻接点入队并标记。**关键不变量：队列中顶点到起点的距离非递减；BFS 按距起点的层数（圈）逐层扩展。**

- **命题**：BFS 找到的是从起点到所有可达顶点的**最短路径（边数最少）**，时间 O(V+E)。
    

**洞见 ③：DFS 用栈（递归）→ 深挖路径；BFS 用队列 → 逐层扩散。两者时间同为 O(V+E)，差异在"探索顺序"而非"快慢"。**​ 这是一个极深刻的对称——**同一个图、同一套邻接表，仅把"栈"换成"队列"，就从"找任意路径"变成"找最短路径"。**​ 后续最短路径（Dijkstra）正是 BFS 思想在"带权图"上的贪心推广。

### 1.4 连通分量（4.1.6）与符号图（4.1.7）

- **连通分量**：每次对一个未标记顶点启动 DFS，这一次 DFS 覆盖的所有顶点构成一个连通分量；用 `id[v]` 记录 v 所属分量编号，`count` 记分量数。**`connected(v,w)` 即 `id[v]==id[w]`。**​ 一次全图扫描 O(V+E) 即可算出所有分量。
    
- **符号图**：顶点是字符串（如航班城市、社交网络用户名），用 `SymbolGraph` 维护"名称↔整数索引"的两个符号表（`name→index` / `index→name`），把字符串图转换为整数索引图交给算法处理。
    

**洞见 ④：符号图揭示了"图算法与具体应用解耦"的工程模式——算法只处理整数索引图，名称映射由外层封装。**​ 这正是第3章符号表（键值关联）在图论中的直接应用，也解释了为什么"航班路线/社交关系"能用同一套 Graph/DFS/BFS 代码处理。

### 1.5 总结（4.1.8）

无向图的四项核心能力：**遍历（DFS/BFS）、路径查找、连通性判定、连通分量划分**——它们都建立在"邻接表 + 标记数组 + 栈或队列"这一极小工具集上。**洞见 ⑤：图算法的威力来自"局部操作推全局性质"——只需看每个顶点的邻居，就能回答"全图是否连通""两点是否可达"这类全局问题。**

## 二、4.2 有向图 —— 当"关系"有了方向

### 2.1 术语与数据类型（4.2.1–4.2.2）

有向边 v→w 是单向的；v 的**出度**=离开 v 的边数，**入度**=进入 v 的边数；**有向路径/环**沿方向走。**邻接表表示不变**，仅建边时只加单向邻接。

### 2.2 有向可达性（4.2.3）

从给定起点集合（多源）出发的 DFS/BFS，标记所有可达顶点。**命题**：处理有向图所需时间正比于 V+E。**洞见 ⑥：有向图的"可达性"是 DFS/BFS 的直接推广——方向只影响邻接表的遍历方向，核心算法框架与无向图一致。**​ 这再次印证"好表示让算法可复用"。

### 2.3 环与有向无环图 DAG（4.2.4）

**判定有向图是否含环（DFS 三色标记法）**：顶点分三种状态——未访问(白)、正在递归栈中(灰)、已完全处理完(黑)。DFS 中若从当前顶点出发走到一个**灰色顶点**，则发现一条回边 ⇒ 存在有向环；若只遇到白色/黑色，则无环。

- **命题**：有向图含环 ⇔ DFS 发现回边指向"仍在递归栈中"的顶点，判定可在 O(V+E) 完成。
    
- **拓扑排序**：DAG 的顶点排序，使所有有向边 v→w 满足 v 排在 w 之前。**算法**：DFS 后按"完成时间递减"输出（即 DFS 结束时的逆后序）；或"入度为 0 的顶点反复入队出队"（Kahn 算法）。
    

**洞见 ⑦：拓扑排序是"依赖关系求解"的万能工具——编译器的编译顺序、课程先修、任务调度、软件包依赖，只要能建模成 DAG，拓扑排序就给出合法的执行顺序。**​ 它也是"图结构蕴含可计算性信息"的典型：有环 ⇒ 存在循环依赖 ⇒ 无法拓扑排序（编译报错/任务死锁）。

### 2.4 强连通性（4.2.5）—— 有向图最"漂亮"的结果

有向图中，若 v↔w 互相可达，则称 v、w **强连通**；强连通分量（SCC）是极大强连通子图。**Kosaraju 算法（两遍 DFS，极优雅）**：

1. 对原图 G 跑 DFS，按"完成时间"压栈（得到逆后序）；
    
2. 将栈中顶点依次弹出，对每个未访问顶点在**转置图 Gᴿ（所有边反向）**上跑 DFS，一次 DFS 覆盖的顶点构成一个 SCC。
    

- **命题**：Kosaraju 算法在 O(V+E) 时间内正确计算所有强连通分量。
    

**洞见 ⑧（本章最值得品味的洞见）：Kosaraju 的正确性直觉极其优美——"在 G 中最后完成的顶点，属于 Gᴿ 中'源分量'（出度为 0 的 SCC）"。**​ 两遍 DFS + 一次转置，就把"有向图的强连通结构"彻底拆解。**这告诉我们：一个看似复杂的问题（强连通），换一个"反向图 + 完成时间顺序"的视角，就能用已有工具（DFS）干净解决。**​ 这种"用视角转换化解复杂度"的思路，是算法设计的高级艺术。

### 2.5 总结（4.2.6）

有向图在"无向图工具集"上新增三大能力：**可达性（多源 DFS/BFS）、环检测与拓扑排序（三色 DFS/逆后序）、强连通分量（Kosaraju 两遍 DFS）**。**洞见 ⑨：方向让图的表达力更强（建模依赖/流程），也带来"强连通"这类无向图没有的新结构——理解有向图，关键是把"无向的连通"推广为"有向的可达/强连通"两种不同粒度的连通概念。**

## 三、4.3 最小生成树 MST —— 用"切分性质"保证最优

### 3.1 原理与数据类型（4.3.1–4.3.3）

**生成树**：含图所有 V 个顶点、V−1 条边的无环连通子图；**最小生成树**：边权之和最小的生成树（假设边权互异时唯一）。**核心定理——切分性质（Cut Property）**：把顶点集任意划分为两个非空集合（一个"切分"），**横跨该切分的最小权边，必属于某个 MST**。这是所有 MST 算法的正确性根基。

**洞见 ⑩：切分性质是"贪心选择的安全性证明"——它告诉我们，每一步选"横跨已连通部分与未连通部分的最小边"永远不会错。**​ 理解这一条，Prim 与 Kruskal 就不再是"两个要背的算法"，而是"切分性质的两个实例化"。

### 3.2 Prim 算法（4.3.4–4.3.5）："从已长成的树向外贪心"

Prim 维护一个顶点集合（已加入 MST 的树），反复：从"连接树内顶点与树外顶点"的边中选**权重最小者**，将其树外端点加入树。**命题**：Prim 算法（配合堆/优先队列）在 O(E log V) 时间内找到 MST。

**即时实现（4.3.5，工程优化）**：不把"连接树内某顶点到 v 的所有边"都入队，而是对每个树外顶点 v 只记录"目前已知从树到 v 的最小边权 `distTo[v]` 及对应边 `edgeTo[v]`"，用**索引优先队列（IndexMinPQ）**​ 维护。每次从 PQ 取出最小 `distTo` 的顶点加入树，再用该顶点出发的边更新邻居的 `distTo`/PQ。**洞见 ⑪：即时 Prim 是"每个顶点只在 PQ 中占一个条目、用更优边权 lazy 更新"——这正是 Dijkstra 最短路径算法的"孪生兄弟"（把"边权"换成"路径总长"）。**​ 这个同构关系，是贯穿 4.3–4.4 的一条暗线。

### 3.3 Kruskal 算法（4.3.6）："按权排序、逐边合并、避环"

Kruskal：把所有边按权升序排序，依次考察每条边——若它连接的两个顶点**当前不在同一个连通分量**（用 **union-find / 第1章 1.5 的并查集**​ 判断），则加入 MST 并合并两分量；否则丢弃（会形成环）。**命题**：Kruskal 算法在 O(E log E) = O(E log V) 时间内找到 MST。

**洞见 ⑫：Kruskal 与 Prim 是 MST 的"对偶"实现——Prim 在"顶点域"贪心（逐点扩树），Kruskal 在"边域"贪心（逐边合并分量），二者都由切分性质保证正确性。**​ 而 Kruskal 直接依赖第1章的 union-find——**这是全书"前面学的工具在后面被复用"的最佳例证之一**：并查集从"动态连通性"一路走到"MST 的环检测"，能力一以贯之。

### 3.4 展望（4.3.7）

MST 对**通信网络、电缆布线、道路规划、聚类**等"用最小总成本把点全部连通"的问题是直接模型。**洞见 ⑬：MST 是"全局最优可由局部贪心逐步构造"的典范——每一步只依赖切分性质这一局部判据，最终却得到全局最优。**​ 这种"局部→全局"的构造性，是贪心算法最有魅力的地方。

## 四、4.4 最短路径 —— 从"无权 BFS"到"带权松弛"

### 4.1 性质与数据结构（4.4.1–4.4.2）

最短路径问题：给定带权有向图（边权可正可负）和起点 s，求 s 到各顶点的最短路径树。**核心操作——松弛（relaxation）**：对一条边 v→w（权 `weight(v,w)`），若 `distTo[w] > distTo[v] + weight(v,w)`，则更新 `distTo[w] = distTo[v] + weight(v,w)`、`edgeTo[w] = v`。**松弛是"用经过 v 的路径尝试改进 w 的当前最短距离估计"——它是所有最短路径算法的原子操作。**

### 4.2 理论基础（4.4.3）

- **最优子结构**：最短路径的子路径仍是最短路径（故可用"边松弛"逐步构造）。
    
- **无负环假设**：若存在从 s 可达的负权环，则最短路径无下界（可绕环无限次减重），问题无解；算法需能检测负环。
    

### 4.3 Dijkstra 算法（4.4.4）："非负权下的 Prim 孪生"

Dijkstra = Prim 的"权值语义替换"：维护起点 s 到各顶点的距离估计 `distTo`，每次从"尚未确定最终最短距离的顶点"中，选出 `distTo` 最小者（用 IndexMinPQ），对其确定最短距离，再用它出发的边**松弛**所有邻居。**命题**：在**边权非负**时，Dijkstra 算法在 O(E log V) 时间内正确求出 s 到所有可达顶点的最短路径。

**洞见 ⑭：Dijkstra 与 Prim（即时版）代码结构几乎相同——唯一区别是 PQ 的"键"：Prim 用 `distTo[v]`=树到 v 的最小边权，Dijkstra 用 `distTo[v]`=s 到 v 的当前最短路径总长。**​ 这个"孪生同构"极其深刻：**MST 是"每次选离树最近的点加入"，SSSP（非负权）是"每次选离起点最近的点确定"——二者共享"按距离贪心选点 + 用选定点更新邻居"的框架。**​ 记住这对孪生，两个算法一起记住。

### 4.4 无环加权有向图的最短/最长路径（4.4.5）

**DAG 的优势**：DAG 中可按**拓扑排序**依次处理顶点——按拓扑序逐个取出顶点，对其出发的边逐一松弛。**命题**：对 DAG，该算法在 O(V+E) 时间内求出所有最短路径；若将边权取负，则得到**最长路径**（关键路径）。

**洞见 ⑮：DAG + 拓扑排序把最短/最长路径降到线性 O(V+E)，且能处理负权（只要无环，负权不构成问题）。**​ 这使其成为"任务调度/关键路径/PERT 图"的首选——**最长路径 = 项目最短完成时间**（关键路径上任何任务延迟都拖慢整体）。**再一次看到：图的结构特性（无环）直接决定算法能达到的复杂度下界。**

### 4.5 一般加权有向图（4.4.6）：Bellman-Ford

当图含**负权边但无负环**时，Dijkstra 失效（已确定的顶点可能因负权边被后续更短路径推翻）。**Bellman-Ford**：对所有边反复松弛 V−1 轮（每轮遍历全部边），第 V 轮若仍能松弛则说明存在从 s 可达的负环。**时间 O(V·E)**，可检测负环。

**洞见 ⑯：Bellman-Ford 是"用 V−1 轮全局松弛逐步传播最短距离"——它比 Dijkstra 慢，但是唯一能正确处理负权（并检测负环）的单源最短路径算法**​ 这给出清晰的选型判据：**非负权 → Dijkstra（快）；含负权/需检测负环 → Bellman-Ford（慢但正确）**​  二者互补，覆盖了所有单源场景。

### 4.6 展望（4.4.7）

最短路径是**路由协议（OSPF/IS-IS 用 Dijkstra）、地图导航、网络延迟优化、套利检测（负环=无风险套利机会）**​ 的核心。

**洞见 ⑰：从 BFS（无权→边数最短）到 Dijkstra（非负权→距离最短）到 Bellman-Ford（负权/负环检测），是一条"权值模型逐步放宽"的演进链——每放宽一次权值假设，就要付出相应的性能代价，但换来更强的建模能力。**

## 五、全章脉络图（章节间的"第一性原理"联系）

```
4.1 无向图
   │  邻接表表示 + DFS(栈/递归→任意路径,连通性) + BFS(队列→最短路径)
   │  → 连通分量(多源DFS) + 符号图(名称↔索引, 用第3章符号表)
   ▼
4.2 有向图
   │  方向 → 出/入度; 可达性(DFS/BFS推广)
   │  → 环检测(三色DFS) + 拓扑排序(DAG逆后序) → 依赖求解
   │  → 强连通Kosaraju(两遍DFS+转置) → "视角转换化解复杂度"
   ▼
4.3 最小生成树 MST
   │  切分性质(贪心安全) → Prim(顶点域贪心, 配IndexMinPQ)
   │                       → Kruskal(边域贪心, 用第1章union-find避环)
   │  Prim ↔ Dijkstra 孪生(权值语义不同)
   ▼
4.4 最短路径
      • 松弛(原子操作) + 最优子结构
      • Dijkstra: 非负权, O(ElogV), 与Prim孪生
      • DAG+拓扑排序: O(V+E), 可负权, 最长路径=关键路径
      • Bellman-Ford: 含负权/负环检测, O(VE)
      • 演进链: BFS → Dijkstra → Bellman-Ford (权值假设逐步放宽)
```

**一句话总结全章**：第4章是一部 **"从关系到最优"的图算法全景**——先用 DFS/BFS 两种遍历回答"能不能到/怎么走"（无向→连通性，有向→可达性/拓扑/强连通），再用"切分性质+贪心"解决"全点连通的最小代价"（MST：Prim/Kruskal），最后用"松弛+按距离贪心/按拓扑序/多轮传播"解决"一点到其余各点的最近距离"（Dijkstra/Bellman-Ford）。贯穿始终的第一性原理是：**用合适的数据结构（邻接表/队列/堆/并查集/索引优先队列）把"局部操作"组织起来，由局部最优/不变式逐步推到全局最优**​ 而 Prim↔Dijkstra 的孪生同构、Kruskal 对 union-find 的复用，则是"算法思想在不同问题间迁移复用"的最美注脚。
