
第7章是整本书的"统计心脏"——前6章建立了贝叶斯定式、WFST 解码图、神经网络架构和特征提取流水线，这一章要回答一个最具体的问题：**"声学模型"这个 P(X|W) 到底怎么建？**​ 答案是 HMM。这一章最厉害的地方，是它把"语音的时序特性"和"音素的上下文依赖"用一套严谨的概率框架统一了起来，并且——尽管 2020 年本书出版时端到端已经开始崛起——HMM 声学模型的思想（状态、对齐、转移、发射概率）**至今仍以 RNN-T、CTC、Chain 模型等形式延续在工业系统中**。

## 7.1　音響モデルの単位（声学建模单元）

**书中视角**：声学模型需要选择合适的"建模单元"——太大（词）数据稀疏，太小（音节/音素）数据充足但增加搜索空间。

**第一性原理**：建模单元的选择本质是在"数据效率"和"搜索复杂度"之间找平衡。

```
单元粒度          优点                    缺点              工业使用
─────────────────────────────────────────────────────────────
词级 (Word)       直观，音素间无歧义       数据稀疏，OOV 灾难   小词汇量系统
音素 (Phoneme)    数据充足，~50 个类       协同发音未建模       基线系统
三音素 (Triphone) 建模协同发音             数量爆炸(~数千)       主流 HMM 系统
Senone            三音素状态绑定后的聚类     DNN 输出层单元       DNN-HMM
字符/BPE          端到端友好                序列长，对齐难       端到端 ASR
```

**关键概念：协同发音（Co-articulation）**

同一个音素 /n/，在 "ten" 和 "nail" 中听起来不一样——因为嘴唇、舌头在发下一个音时已经开始预备。这就是"上下文相关"的物理动机。

**三音素（Triphone）模型**：把音素连同其左右邻居一起建模，例如：

```
"cat": k-a-t
  triphone "k" → (-,k,a)  左边是词边界
  triphone "a" → (k,a,t)
  triphone "t" → (a,t,-)  右边是词边界
```

RWTH 系统的做法是：每个三音素用 HMM 建模，通常分为开始、中间、结束三个部分，每个部分用一对相同状态 (BB, MM, EE) 表示 。

**状态绑定（State Tying）**——解决三音素数量爆炸的关键：

```
原始三音素数：~50 音素 → ~50³ = 125,000 个三音素
每个三音素 3 状态 → 375,000 个状态
GMM 参数无法可靠估计！

解决方案：决策树状态绑定
  相似的三音素状态共享同一个 GMM
  绑定后状态数降到几千到几万（称为 senone）
  DNN 的输出层就是这些 senone 的后验概率
```

> 💡 **洞见**：建模单元的选择揭示了 ASR 的一个根本矛盾——**"语言学自然的单元"（音素）和"声学可分的单元"（三音素/senone）之间的差距，必须由数据来填补**。三音素 + 状态绑定是统计时代的解决方案；到了端到端时代，这个矛盾被"字符 + CTC/RNN-T 自动对齐"绕过了——但绕过的代价是**需要大量数据**。这就是为什么低资源语言/领域，HMM 混合系统至今仍是首选 。

**工业现状**：

- Kaldi 的标准 recipe：monophone → tri1（三音素+决策树绑定）→ tri2（LDA+MLLT）→ tri3（SAT+fMLLR）→ chain（TDNN+LF-MMI）
- 每个阶段都在解决不同阶段的问题：monophone 建基线，tri1 引入协同发音，tri2 做特征空间变换，tri3 做说话人自适应，chain 用神经网络+序列判别训练

## 7.2　隠れマルコフモデルとは（什么是隐马尔可夫模型）

**书中视角**：HMM 是一种统计模型，用隐含状态序列生成可观测的声学特征。

**HMM 的五元组定义**：

λ=(S,O,A,B,π)

- **S**：状态集（音素或子词单元，如中文声母/韵母）
- **O**：观测集（输入的特征向量）
- **A**：转移矩阵，aij​=P(qt+1​=j∣qt​=i)
- **B**：发射概率，bj​(ot​)=P(ot​∣qt​=j)，通常用 GMM 建模
- **π**：初始状态分布

**为什么语音识别必须用 HMM？**​ 三个核心原因 ：

```
1. 时序结构：语音是时序信号，HMM 的状态序列天然建模时序
2. 变长时长：自转移循环让每个音素可以持续任意多帧
3. 概率性：语音的变异性用概率分布建模，而非硬规则
```

**语音 HMM 的典型拓扑——左-右模型（Left-to-Right）**：

```
音素 /a/ 的 HMM（3 状态）：

   状态1(开始)    状态2(中间)    状态3(结束)
   ┌───┐         ┌───┐         ┌───┐
   │ S1│──┐      │ S2│──┐      │ S3│
   └───┘  │      └───┘  │      └───┘
     │    │        │    │        │
     │    ▼        │    ▼        │
     │  ┌───┐      │  ┌───┐      │
     │  │ S1│      │  │ S2│      │
     │  └───┘      │  └───┘      │
     │             │             │
     └────────────►└────────────►│
                                  ▼
                                (退出)
   
   转移矩阵：
   S1 → S1 (自循环): 0.6
   S1 → S2 (前进):   0.4
   S2 → S2:          0.6
   S2 → S3:          0.4
   S3 → S3:          0.7
   S3 → 退出:        0.3
```

**词 "cup" 的 HMM = 拼接其音素 HMM**：

```
c    u    p
─── ─── ───
●─●─●─●─●─●─●─●─●─●
 3态  3态  3态 = 9 态
```

**HMM 的三个基本问题**​ ：

```
问题 1（评估/Evaluation）：
   给定模型 λ 和观测序列 X，计算 P(X|λ)
   解法：前向算法（Forward Algorithm）
   复杂度：O(N²T)，N=状态数，T=时间步

问题 2（解码/Decoding）：
   给定模型 λ 和观测序列 X，求最可能的状态序列 Q*
   解法：Viterbi 算法
   复杂度：O(N²T)

问题 3（学习/Training）：
   给定观测序列 X，调整 λ 使 P(X|λ) 最大
   解法：Baum-Welch 算法（EM 的特例）
```

> 💡 **洞见**：HMM 之所以在 ASR 中统治 30 年，是因为它**完美契合了语音的三个本质特性**——时序性（状态序列）、变长时长（自转移）、概率变异（发射概率分布）。任何其他模型要想替代 HMM，必须在这三个维度上都至少打平。RNN-T 做到了（用 RNN 建模时序，用 blank 符号建模变长对齐，用 softmax 建模概率变异）；CTC 也做到了（用神经网络+blank 替代 HMM 的对齐作用）。**HMM 不是被证伪了，而是被"吸收"进了端到端模型**。

## 7.3　隠れマルコフモデルの確率計算（HMM 的概率计算）

这一节是 HMM 的数学核心——前向算法（Forward Algorithm）。

**问题**：给定 HMM λ 和观测序列 X={x1​,x2​,...,xT​}，计算 P(X∣λ)。

朴素方法：枚举所有状态序列 Q={q1​,q2​,...,qT​}，计算 P(X,Q∣λ) 然后求和。复杂度 O(NT)——完全不可行。

**前向算法（动态规划）**：

定义前向概率 αt​(i)：

αt​(i)=P(x1​,x2​,...,xt​,qt​=i∣λ)

**递推公式**：

```
初始化：
   α₁(i) = πᵢ · bᵢ(x₁)        对所有状态 i

归纳：
   α₍ₜ₊₁₎(j) = [Σᵢ αₜ(i) · aᵢⱼ] · bⱼ(xₜ₊₁)

终止：
   P(X|λ) = Σᵢ α_T(i)
```

**前向算法的网格可视化**：

```
状态\时间  t=1    t=2    t=3    ...    t=T
   S1      α₁(1)  α₂(1)  α₃(1)         α_T(1)
   S2      α₁(2)  α₂(2)  α₃(2)         α_T(2)
   ...
   SN      α₁(N)  α₂(N)  α₃(N)         α_T(N)
   
   每个格子的 αₜ(i) = 从左上所有格子转移来的概率和 × 发射概率
   复杂度从 O(N^T) 降到 O(N²T)
```

**后向算法（Backward Algorithm）**——与前向对称：

定义后向概率 βt​(i)：

βt​(i)=P(xt+1​,xt+2​,...,xT​∣qt​=i,λ)

βt​(i)=j∑​aij​⋅bj​(xt+1​)⋅βt+1​(j)

**前后向结合 → 状态占用概率**：

γt​(i)=P(qt​=i∣X,λ)=∑j​αt​(j)βt​(j)αt​(i)βt​(i)​

γt​(i) 就是在时刻 t 处于状态 i 的后验概率——这是下一节 Baum-Welch 算法的核心。

> 💡 **洞见**：前向-后向算法是**动态规划在概率图模型上的典范应用**。它的深刻之处在于：αt​(i) 和 βt​(i) 分别从左和右两个方向"扫描"序列，然后把信息在时刻 t "汇合"。这种双向信息传递的思想，直接启发了后来的**双向 LSTM**（从左和右两个方向读序列）和 **Transformer 的自注意力**（每个位置直接汇聚全局信息）。**现代深度学习中的"双向性"，在 HMM 里早有雏形**。

**工业实现要点**：

- 数值下溢问题：概率连乘导致浮点数下溢 → 用对数域计算（log-domain）或用缩放因子（scaling factors）
- Kaldi 中的实现：用 log-likelihood 而非 probability，所有乘法变加法

## 7.4　状態系列の推定（状态序列的估计）

这一节讲 Viterbi 算法——解码阶段的核心。

**问题**：给定 HMM λ 和观测序列 X，求最可能的隐状态序列 Q∗=argmaxQ​P(Q∣X,λ)。

**Viterbi 算法（动态规划）**：

定义 Vt​(j) 为"时刻 t 到达状态 j 的最优路径概率"，ψt​(j) 为回溯指针。

```
初始化：
   V₁(i) = πᵢ · bᵢ(x₁)
   ψ₁(i) = 0

递推：
   Vₜ(j) = maxᵢ [Vₜ₋₁(i) · aᵢⱼ] · bⱼ(xₜ)
   ψₜ(j) = argmaxᵢ [Vₜ₋₁(i) · aᵢⱼ]

终止：
   P* = maxᵢ V_T(i)
   q*_T = argmaxᵢ V_T(i)

回溯：
   q*_t = ψₜ₊₁(q*_ₜ₊₁)   从 t=T-1 回溯到 t=1
```

**Viterbi 网格可视化**：

```
状态\时间  t=1    t=2    t=3    t=4
   S1      ●──●──●──●──●
           │ ＼│ ＼│ ＼│
   S2      ●──●──●──●──●
          ＼│  ＼│  ＼│  ＼│
   S3      ●──●──●──●──●
           │ ＼│  ＼│  ＼│
   S4      ●──●──●──●──●
   
   实线 = 最优路径（Viterbi path）
   虚线 = 被剪枝的路径
   
   最佳路径: S1→S1→S2→S3→S4
   对应音素序列: (sil)→k→a→t→(sil)
```

**Viterbi 与 WFST 的关系**（呼应第4章）：

```
Viterbi 算法 = Tropical 半环下的 WFST 最短路径
   Viterbi 的 max ⊕ = Tropical 的 min
   Viterbi 的 × ⊗ = Tropical 的 +
   
这就是为什么第4章说：
   "Viterbi 解码只是 WFST 在 Tropical 半环下的特例"
```

**工业现实**：

- 纯 Viterbi 在大规模词汇 ASR 中不够用（搜索空间太大）
- 实际用 **Beam Search Viterbi**：只保留每个时刻概率最高的前 K 个路径
- 或者在 WFST 框架中用 **Beam Pruning**​ 搜索 HCLG 图

> ⚠️ **重要提醒**：Viterbi 找的是"最优状态序列"，但在 ASR 中我们最终要的是"最优词序列"。这两者通过 WFST 的 HCLG 图桥接——Viterbi 在 HCLG 上跑，图的输出就是词序列。所以 Viterbi 不是直接输出文字，而是在编译后的解码图上搜索 。

## 7.5　パラメータの学習（参数学习）

这一节是 HMM 训练的精髓——Baum-Welch 算法（EM 算法的 HMM 特化版）。

**问题**：给定观测序列 X，调整 HMM 参数 λ = (A, B, π) 使 P(X|λ) 最大化。

**Baum-Welch 算法的 E-M 迭代**：

**E-step**：用当前参数计算状态占用概率

γt​(i)=P(qt​=i∣X,λ)=P(X∣λ)αt​(i)βt​(i)​

ξt​(i,j)=P(qt​=i,qt+1​=j∣X,λ)=P(X∣λ)αt​(i)aij​bj​(xt+1​)βt+1​(j)​

**M-step**：更新参数

πinew​=γ1​(i)

aijnew​=∑t=1T−1​γt​(i)∑t=1T−1​ξt​(i,j)​

bjnew​(x)=∑t=1T​γt​(j)∑t:xt​=x​γt​(j)​(离散观测)

对于 GMM 发射概率，M-step 还要用 EM 更新每个高斯的权重、均值、方差 ：

```
嵌套 EM：
   外层 EM：HMM 的 Baum-Welch
   内层 EM：GMM 的参数更新
```

**训练流程（Kaldi 标准 recipe）**​ ：

```
Step 1: Flat-start monophone GMM-HMM
   - 随机初始化或启发式初始化
   - 用当前模型做 forced alignment（强制对齐）
   - 用对齐作为"真值"更新 GMM 参数
   - 迭代直到收敛

Step 2: 三音素 GMM-HMM (tri1)
   - 用 monophone 模型的对齐作为起点
   - 构建三音素 HMM
   - 决策树状态绑定
   - Baum-Welch 训练

Step 3: LDA+MLLT (tri2)
   - 特征空间变换
   - 进一步提升区分度

Step 4: SAT+fMLLR (tri3)
   - 说话人自适应训练
   - 特征空间极大似然线性回归

Step 5: DNN-HMM 或 Chain 模型
   - 用 GMM-HMM 的对齐作为 DNN 的训练目标
   - 交叉熵训练 DNN
   - 序列判别训练（MMI/sMBR/LF-MMI）
```

**关键洞察**：Baum-Welch 是**无监督对齐**——它从"只有语音和转录文本"中，自动推断出"哪一帧对应哪个音素状态"。这种能力在端到端时代之前是 ASR 训练的核心。

> 💡 **洞见**：Baum-Welch 的 E-M 迭代揭示了一个深刻的机器学习原理——**"对齐"是潜变量，我们不能直接观测它，但我们可以通过迭代推断它、然后用它更新模型**。这个思想在端到端时代以另一种形式重生：
> 
> - CTC 的 forward-backward 算法，本质上就是 Baum-Welch 在神经网络的版本
> - RNN-T 的 recursion 算法，同理
> 
> **HMM 训练的"对齐-更新"迭代，是序列建模的通用范式**，只不过端到端模型用神经网络替代了 GMM，用梯度下降替代了 Baum-Welch 的参数更新 。

**工业数据**：

- GMM-HMM 训练通常需要 100+ 次 EM 迭代
- 每次迭代包含：forward-backward 计算 + 参数更新
- 在 Switchboard 300 小时数据上，GMM-HMM 训练需要数天
- DNN-HMM 训练：先用 GMM-HMM 做对齐，然后 DNN 用交叉熵训练，更快收敛

## 7.6　高度な音響モデル（高级声学模型）

这一节是从传统 GMM-HMM 跨入现代 DNN-HMM 的桥梁。

**突破一：GMM → DNN 的替换**

```
GMM-HMM 声学模型：
   输入: MFCC 特征
   发射概率: bⱼ(x) = Σₘ wₘ 𝒩(x; μₘ, Σₘ)   ← 生成式
   训练: Baum-Welch (MLE)
   
DNN-HMM 混合系统：
   输入: MFCC 或 Log-Mel 特征 (+ 上下文拼接)
   输出: P(sⱼ|x)  ← 判别式后验概率
   训练: 交叉熵 (+ 序列判别训练)
```

**关键差异**​ ：

```
GMM 提供: P(x|sⱼ)              ← 似然
DNN 提供: P(sⱼ|x)              ← 后验

Viterbi 解码需要: P(x|sⱼ)
通过贝叶斯规则转换:
   P(x|sⱼ) = P(sⱼ|x) · P(x) / P(sⱼ)
           ∝ P(sⱼ|x) / P(sⱼ)    (P(x) 与状态无关，可忽略)
```

这就是 DNN-HMM 混合系统的"魔法"——**DNN 输出后验，通过一个简单的除法转换成 HMM 需要的似然，其余解码图完全不变**​ 。

**突破二：上下文拼接（Frame Splicing）**

```
DNN 输入不仅是当前帧，而是拼接前后若干帧：

   帧 t-4  帧 t-3  帧 t-2  帧 t-1  帧 t  帧 t+1  帧 t+2  帧 t+3  帧 t+4
      └──────────┴──────┴──────────┘
            9 帧 × 特征维数 = 输入向量
                      ↓
                     DNN
                      ↓
              P(sⱼ | 这 9 帧的上下文)
```

这相当于在 DNN 中显式建模时序上下文，弥补了纯前馈网络无记忆的缺陷 。

**突破三：TDNN（Time-Delay Neural Network）**

```
1D 卷积在时间维度滑动
每个卷积核共享权重
等价于"可学习的帧拼接"
```

TDNN 是 Kaldi 中 chain 模型的核心组件 。

**突破四：Chain 模型（LF-MMI）**

```
Kaldi 的现代标准：
   TDNN 作为声学模型
   LF-MMI (Lattice-Free Maximum Mutual Information) 作为训练准则
   降低输出帧率（30ms 一帧而非 10ms）
   
   结果：相比传统 DNN-HMM，WER 相对降低约 5%，
   且解码速度更快
```

**突破五：说话人自适应**

```
i-vectors：将说话人特性压缩成一个低维向量
   附加到 DNN 输入特征上
   → 说话人自适应训练 (SAT)
   
x-vectors：用 DNN 提取说话人嵌入
   更强大的说话人表征
```

**工业现状全景**​ ：

```
架构              声学模型        训练准则          帧率      相对 WER
─────────────────────────────────────────────────────────────────
GMM-HMM tri3     GMM             MLE              10ms      基线
DNN-HMM          DNN              CE + sMBR        10ms      -20~30%
TDNN-HMM         TDNN             CE + sMBR        10ms      -25~35%
Chain (LF-MMI)   TDNN             LF-MMI           30ms      -30~40%
RNN-T            神经网络         CTC-like loss    流式      与 Chain 竞争
Conformer        Transformer      CTC + Attention  流式/离线  当前 SOTA
```

> 💡 **洞见**：DNN-HMM hybrid 的本质是**"老框架，新大脑"**——HMM 提供时序结构和对齐机制，DNN 提供强大的判别能力。这种混合架构在工业界至今仍有强大生命力，原因有三 ：
> 
> 1. **高噪声/远场场景**：混合系统比端到端更鲁棒
> 2. **定制化需求**：发音词典和语言模型可以独立定制（如医疗、法律领域）
> 3. **Kaldi 生态**：WFST 解码、i-vector/x-vector 自适应、chain 模型等都是成熟的工程方案
> 
> PyTorch-Kaldi 工具包的研究表明：**混合系统在处理噪声和远距离说话场景时，仍然比端到端模型更有竞争力**​ 。这不是"旧技术苟延残喘"，而是"最适合特定约束的技术"。

**PyTorch-Kaldi 的洞见**​ ：

```
Kaldi 负责：特征提取、对齐、WFST 解码（"耳朵和嘴"）
PyTorch 负责：声学建模（"大脑"）

这种分工让研究者可以快速实验新的神经网络架构，
同时复用 Kaldi 成熟的工程基础设施
```

## 7.7　まとめ（总结）

第7章的真正价值，是让你看清声学模型从"统计时代"到"深度学习时代"的完整演进：

```
时代          声学模型              发射概率           训练准则
──────────────────────────────────────────────────────────
1980-2010    GMM-HMM               GMM               MLE (Baum-Welch)
2010-2012    DNN-HMM                DNN (后验)         CE + 贝叶斯转换
2012-2015    DNN-HMM hybrid        DNN               CE + sMBR/MMI
2015-2018    TDNN-HMM              TDNN               CE + sMBR
2018-现在    Chain (LF-MMI)        TDNN               LF-MMI
2014-现在    端到端 (CTC/RNN-T)    神经网络            CTC / RNN-T loss
```

**第一性原理提炼**：

> 声学模型的演进，本质是在回答一个问题：**"如何最有效地建模 P(声学特征序列 | 词序列)？"**
> 
> - **GMM-HMM**​ 的答案是：用状态序列建模时序，用 GMM 建模发射概率，用 Baum-Welch 无监督学习对齐
> - **DNN-HMM**​ 的答案是：保留 HMM 的时序框架，但用 DNN 替代 GMM 提供判别式的发射概率
> - **Chain 模型**​ 的答案是：用 TDNN 替代 DNN，用 LF-MMI 替代 CE，用 30ms 帧率替代 10ms 帧率
> - **端到端模型**​ 的答案是：彻底绕过 HMM，用神经网络直接学 P(词序列 | 声学特征)
> 
> 每一次演进，都是在**保持部分原有框架的同时，用更强的组件替换薄弱环节**。这是工程演进的典型模式——不是推倒重来，而是渐进式替换。

**跨章节联系**（读这一章最该建立的认知地图）：

```
第1章 贝叶斯定式：
   └─ P(X|W) 由声学模型负责 → 本章主题

第2章 语音性质：
   ├─ 2.2 源-滤波器 → 音素作为建模单元的物理基础
   └─ 2.3 短时平稳 → HMM 状态内平稳假设

第3章 统计模式识别：
   ├─ 3.3 生成模型 MLE → GMM-HMM + Baum-Welch
   └─ 3.4 判别模型 → DNN-HMM + CE/MMI

第4章 WFST：
   └─ H（HMM 状态 → 三音素映射）→ 本章的 HMM 是 H 的具体形式

第5章 神经网络：
   ├─ 5.2 DNN → DNN-HMM 的"大脑"
   ├─ 5.4 RNN/LSTM → 可替代 DNN 作为 HMM 的发射概率估计器
   └─ 5.5 Transformer → 端到端声学模型

第6章 特征提取：
   └─ MFCC/Log-Mel 是 HMM 状态观测的输入

第7章（本章）：
   └─ 声学模型的完整统计框架

第8章（下一章）：
   └─ P(W) 由语言模型负责，与本章的 P(X|W) 在解码时结合
```

> ⚠️ **重要提醒**：本书 2020 年出版时，DNN-HMM hybrid 是工业主流，端到端刚起步。读这一章时，你需要用 2026 年的视角补充：
> 
> 1. **Chain 模型（LF-MMI + TDNN）在 Kaldi 中已成为 GMM-HMM 的替代者**，WER 相对降低 30-40%
> 2. **RNN-T 在流式场景中表现出色**，Google Assistant、YouTube 字幕都在用
> 3. **端到端模型 + WFST 语言模型融合**是常见的工业部署模式
> 4. **自监督预训练（wav2vec 2.0）**​ 让声学模型可以从大量无标注数据中学习
> 5. **HMM 的思想遗产**（状态、对齐、转移）在 RNN-T 的 blank 机制和 CTC 的重复字符机制中得到延续
> 
> 但 **GMM-HMM 远未退休**——在低资源语言、小词汇量命令词识别、嵌入式设备中，GMM-HMM 因其**数据效率高、计算成本低、可解释性强**而仍是首选 。理解 GMM-HMM 的数学，是理解所有现代声学模型的基础。

## 贯穿全书的思维锚点

把前7章连起来看，逻辑链已经完全闭环：

```
第1章：ASR 是贝叶斯逆问题 → W* = argmax P(X|W)P(W)
   ↓
第2章：语音的物理/生理/感知性质
   ↓
第3章：统计模式识别（生成 vs 判别）
   ↓
第4章：WFST（把 P(X|W)P(W) 编译成可搜索的图）
   ↓
第5章：神经网络（用可微计算图逼近映射）
   ↓
第6章：特征提取（波形 → MFCC/Log-Mel）
   ↓
第7章：声学模型（HMM/GMM/DNN 建模 P(X|W)）
   ↓
第8章：语言模型（建模 P(W)）—— 下一章
```

**第一性原理提炼**：

> ASR 声学模型的演进史，是一部**"用更强的函数逼近器，替换 HMM 中的薄弱环节"**的历史：
> 
> |HMM 组件|传统实现|现代替代|
> |---|---|---|
> |状态序列|左-右 HMM 拓扑|保留（但 RNN-T 用 blank 隐式建模）|
> |发射概率|GMM|DNN / TDNN / Conformer|
> |训练准则|MLE (Baum-Welch)|CE → sMBR → LF-MMI|
> |对齐机制|Baum-Welch 无监督对齐|CTC / RNN-T 可微分对齐|
> |帧率|10ms|30ms（Chain）或可变（端到端）|
> 
> **但 HMM 的核心思想——"用时序状态机建模语音"——从未被真正抛弃**。端到端模型中的 CTC blank、RNN-T 的空转移、Transformer 的位置编码，都是在用不同的方式重新实现"时序状态机"的功能。

下一章（第8章 语言模型）将讲述 P(W) 的建模——它与本章的 P(X|W) 在解码时通过 WFST 组合，共同决定最终的识别结果。读第8章时，请时刻记住：

**声学模型和语言模型是贝叶斯公式的两个因子，它们必须在解码时"握手"——而握手的场所，就是第4章讲的 WFST 解码图 HCLG。**
