# 第7章 神经网络与深度学习

## 本章的第一性原理

神经网络不是神秘的大脑模拟，而是一组可组合的参数化函数：

$$
f_\theta(x)=f^{(L)}_\theta(\cdots f^{(2)}_\theta(f^{(1)}_\theta(x))).
$$

每层先做线性变换，再做非线性变换；训练就是用损失函数衡量最终输出，再用链式法则把误差信号传回每个参数。

## 7.1 神经元模型

### 7.1.1 神经细胞

生物神经元接受许多输入，整合后在达到一定条件时产生输出。机器学习借用了“加权输入—输出”的抽象，但人工神经元的价值不在于生物学逼真，而在于它是一个简单、可微、可组合的计算单元。

### 7.1.2 神经元模型

一个人工神经元可以写为

$$
a=\sum_i w_i x_i+b=\boldsymbol w^T\boldsymbol x+b,
\qquad z=\phi(a).
$$

其中 $w$ 是权重、$b$ 是偏置、$\phi$ 是激活函数。若 $\phi$ 是恒等函数，神经元就是线性回归；若是 sigmoid，就是二分类逻辑回归的一部分。

## 7.2 神经网络模型

### 7.2.1 二层前馈神经网络

以一层隐藏层为例：

$$
\boldsymbol a=W\boldsymbol x+\boldsymbol b,
\quad
\boldsymbol z=\phi(\boldsymbol a),
\quad
\hat{\boldsymbol y}=V\boldsymbol z+\boldsymbol c.
$$

“二层”通常指有两组可训练权重；输入层不计为有参数的层。信息只从输入流向输出，没有回到过去的反馈连接，因此称为前馈网络。

### 7.2.2 二层前馈神经网络的实现

```python
def forward(x, W, b, V, c, activation=np.tanh):
    a = x @ W.T + b
    z = activation(a)
    y_hat = z @ V.T + c
    return y_hat, (x, a, z)
```

如果批量输入 `x.shape == (n, d)`，则 `W.shape == (h, d)`、`b.shape == (h,)`、`V.shape == (o, h)`，输出是 `(n, o)`。形状就是网络结构的可执行说明。

### 7.2.3 数值导数法

对任意参数 $\theta$，中心差分近似导数：

$$
\frac{\partial E}{\partial\theta}
\approx \frac{E(\theta+\epsilon)-E(\theta-\epsilon)}{2\epsilon}.
$$

数值导数非常慢，但适合验证反向传播是否写对。实践中可在小模型、少量数据上比较解析梯度和数值梯度，检查相对误差。

```python
def numerical_gradient(loss, theta, eps=1e-5):
    grad = np.zeros_like(theta)
    for i in range(theta.size):
        old = theta[i]
        theta[i] = old + eps
        plus = loss(theta)
        theta[i] = old - eps
        minus = loss(theta)
        theta[i] = old
        grad[i] = (plus - minus) / (2 * eps)
    return grad
```

### 7.2.4 通过数值导数法应用梯度法

```python
for step in range(100):
    grad = numerical_gradient(loss, theta)
    theta -= learning_rate * grad
```

这段循环直接体现梯度下降，但每个参数都要额外计算两次损失，参数多时成本是灾难性的。它的真正价值是建立“梯度不是魔法”的基准实现。

### 7.2.5 误差反向传播法

反向传播不是另一种损失，也不是一种网络结构，而是高效计算复合函数梯度的算法。前向时保存中间值；反向时从损失开始，沿计算图反方向应用链式法则，并复用已经保存的值。

```text
forward:  x → a → z → y_hat → E
backward:      ∂E/∂a ← ∂E/∂z ← ∂E/∂y_hat ← ∂E
```

### 7.2.6 求 $\partial E/\partial v_{kj}$

设输出层是线性层，平方误差

$$
E=\frac12\sum_k(\hat y_k-y_k)^2,
\qquad
\hat y_k=\sum_j v_{kj}z_j+c_k.
$$

由链式法则：

$$
\frac{\partial E}{\partial v_{kj}}
=(\hat y_k-y_k)z_j.
$$

它很直观：输出误差越大、隐藏单元激活越强，这条连接的权重更新越大。

### 7.2.7 求 $\partial E/\partial w_{ji}$

隐藏层参数会经过输出层和激活函数：

$$
\frac{\partial E}{\partial w_{ji}}
=\sum_k(\hat y_k-y_k)v_{kj}\phi'(a_j)x_i.
$$

这里的求和表示一个隐藏单元对多个输出的影响会合并。反向传播先计算输出层误差信号，再把它乘上连接权重和激活函数导数，最后乘输入。

### 7.2.8 误差反向传播法的实现

以批量矩阵形式写：

```python
def backward(x, y, params, cache):
    W, b, V, c = params
    x, a, z = cache
    y_hat = z @ V.T + c
    delta_out = (y_hat - y) / len(x)       # dE/dy_hat
    dV = delta_out.T @ z
    dc = delta_out.sum(axis=0)
    delta_hidden = (delta_out @ V) * (1 - np.tanh(a) ** 2)
    dW = delta_hidden.T @ x
    db = delta_hidden.sum(axis=0)
    return dW, db, dV, dc
```

实际代码应把激活值和导数写得更清楚，并用数值梯度测试。反向传播的工程难点包括形状、广播、参数初始化、数值稳定和训练内存，而不是链式法则本身。

### 7.2.9 学习后的神经元的特性

训练后，隐藏单元可能对某个输入方向、局部模式或组合特征产生较强响应。不能简单把每个神经元解释成一个人类概念：神经元之间可以分布式协作，单个权重也不等于因果关系。

有用的观察方法包括：画激活分布、检查输入扰动前后的输出、可视化权重或用特征归因方法分析错误样本。不要只看权重大小就宣称“特征重要”。

## 7.3 使用 Keras 实现神经网络模型

### 7.3.1 二层前馈神经网络

```python
import keras
from keras import layers

model = keras.Sequential([
    keras.Input(shape=(2,)),
    layers.Dense(16, activation="tanh"),
    layers.Dense(1),
])
```

这段模型与前面的数学式一一对应：第一层完成 $W x+b$ 与激活，第二层输出线性预测。分类任务可把最后一层改为 `Dense(1, activation="sigmoid")` 或 `Dense(K, activation="softmax")`，并匹配对应损失。

### 7.3.2 Keras 的使用流程

```python
model.compile(
    optimizer=keras.optimizers.SGD(learning_rate=0.05),
    loss="mse",
    metrics=["mae"],
)
history = model.fit(
    X_train, y_train,
    validation_data=(X_val, y_val),
    epochs=100,
    batch_size=32,
    verbose=0,
)
test_metrics = model.evaluate(X_test, y_test, verbose=0)
```

Keras 的流程是：定义结构 → `compile` 指定优化器/损失/指标 → `fit` 训练 → `evaluate` 评估 → `predict` 推理 → 保存模型。`validation_data` 只用于开发阶段，不应把测试集反复当验证集使用。

## 为什么非线性是必要的

若每层只有线性变换：

$$
W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2),
$$

多层仍可合并成一层线性模型，无法表示 XOR 等非线性关系。激活函数让网络获得弯曲决策边界和分层表示；第 8 章会比较 sigmoid、ReLU 与卷积结构。

## 工业视角：网络架构是资源与风险的选择

层数和宽度增加会提高表达能力，也会增加参数、训练时间、过拟合风险和线上延迟。上线模型要同时记录：输入预处理、模型结构、参数量、权重、阈值、硬件、推理批大小和回滚版本。
