# 第6章 有监督学习：分类

## 本章的第一性原理

分类的核心不是把标签换成整数，而是从输入估计事件发生的概率，再根据业务代价做决策。模型输出概率，阈值才输出类别：

```text
特征 x → 分数 z → 概率 p(y|x) → 阈值/排序/人工复核 → 决策
```

这解释了为什么分类需要 sigmoid/softmax、最大似然和交叉熵，而不是直接对 0/1 标签使用普通回归。

## 6.1 一维输入的二元分类

### 6.1.1 问题设置

每个样本只有一个输入 $x$，标签 $y\in\{0,1\}$。目标是学习 $p(y=1|x)$。

```python
x = np.array([-2., -1., 0., 1., 2.])
y = np.array([0, 0, 0, 1, 1])
```

先画散点和类别分布，确认类别是否大致可分、是否有重叠和类别不平衡。标签的数字只是编码，不代表类别之间存在“距离 1”。

### 6.1.2 使用概率表示类别分类

模型先产生一个实数分数 $z=wx+b$，再通过 sigmoid 转成概率：

$$
p(y=1|x)=\sigma(z)=\frac1{1+e^{-z}}.
$$

```python
def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))
```

概率比硬标签更有信息：`0.51` 和 `0.99` 都预测为 1，但风险和人工复核优先级完全不同。

### 6.1.3 最大似然估计

把每个标签看成 Bernoulli 随机变量：

$$
p(y_i|x_i)=p_i^{y_i}(1-p_i)^{1-y_i}.
$$

独立样本的似然是各项乘积，最大似然就是选择让观察到的标签最可能的参数。为避免乘积下溢，取对数：

$$
\ell(\theta)=\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)].
$$

最大化对数似然等价于最小化负对数似然。

### 6.1.4 逻辑回归模型

逻辑回归的“回归”指对数几率是线性的：

$$
\log\frac{p}{1-p}=wx+b.
$$

决策边界在一维中是一个阈值点 $wx+b=0$。在二维中，它会变成一条直线；因此逻辑回归的概率曲线是非线性的，但决策边界仍是线性的。

### 6.1.5 交叉熵误差

二分类交叉熵为

$$
J=-\frac1n\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)].
$$

若模型对正确类别给出很小概率，损失会很大；这正是分类所需要的惩罚。与 sigmoid 配套实现时应使用稳定的 `logaddexp` 或框架内置 loss，避免先算概率再遇到 `log(0)`。

```python
def binary_cross_entropy(y, p, eps=1e-7):
    p = np.clip(p, eps, 1 - eps)
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))
```

### 6.1.6 学习法则的推导

令 $p_i=\sigma(x_i^T\theta)$，交叉熵对参数的梯度会简化为：

$$
\nabla_\theta J=\frac1nX^T(p-y).
$$

这个简洁结果来自 sigmoid 导数与交叉熵导数的抵消。它和第 5 章线性回归的梯度结构非常相似：都是“误差 × 输入”的批量加权和，只是误差的定义不同。

### 6.1.7 通过梯度法求解

```python
def fit_logistic(X, y, lr=0.1, steps=2000):
    Xb = np.c_[np.ones(len(X)), X]
    theta = np.zeros(Xb.shape[1])
    for _ in range(steps):
        p = sigmoid(Xb @ theta)
        grad = Xb.T @ (p - y) / len(y)
        theta -= lr * grad
    return theta
```

逻辑回归通常没有像普通最小二乘那样简单的闭式解，因此用梯度法、Newton 法或库中的优化器。训练时要监控损失、梯度和概率是否饱和。

## 6.2 二维输入的二元分类

### 6.2.1 问题设置

输入变成 $x=(x_1,x_2)$，标签仍为 0/1。二维散点图能直接展示类别重叠和线性可分性：

```python
plt.scatter(X[y == 0, 0], X[y == 0, 1], label="class 0")
plt.scatter(X[y == 1, 0], X[y == 1, 1], label="class 1")
plt.legend()
```

### 6.2.2 逻辑回归模型

$$
p(y=1|x)=\sigma(w_1x_1+w_2x_2+b).
$$

当 $p=0.5$ 时，决策边界满足 $w_1x_1+w_2x_2+b=0$。画出网格概率图：

```python
xx0, xx1 = np.meshgrid(
    np.linspace(X[:, 0].min(), X[:, 0].max(), 200),
    np.linspace(X[:, 1].min(), X[:, 1].max(), 200),
)
grid = np.c_[xx0.ravel(), xx1.ravel()]
p = sigmoid(np.c_[np.ones(len(grid)), grid] @ theta)
P = p.reshape(xx0.shape)
plt.contourf(xx0, xx1, P, levels=20, alpha=0.5)
```

如果边界呈弯曲结构，优先考虑特征变换、基函数或更强的模型，而不是盲目提高迭代次数。

## 6.3 二维输入的三元分类

### 6.3.1 三元分类逻辑回归模型

对 $K=3$ 个互斥类别，模型为每类产生一个分数 $a_k=w_k^Tx+b_k$，再用 softmax：

$$
p_k=\frac{e^{a_k}}{\sum_{j=1}^{K}e^{a_j}}.
$$

每个样本的概率向量和为 1。决策边界由两个类别分数相等的区域组成，通常是线性片段。

### 6.3.2 交叉熵误差

若标签用 one-hot 向量 $t=(t_1,\ldots,t_K)$ 表示，交叉熵为

$$
J=-\frac1n\sum_i\sum_{k=1}^{K}t_{ik}\log p_{ik}.
$$

one-hot 标签只有正确类别位置为 1，因此每个样本本质上是在惩罚正确类别的负对数概率。实现时优先使用框架提供的 logits 版本 loss，以获得数值稳定性。

### 6.3.3 通过梯度法求解

```python
def softmax(a):
    a = a - np.max(a, axis=1, keepdims=True)
    e = np.exp(a)
    return e / e.sum(axis=1, keepdims=True)

def fit_softmax(X, y_onehot, lr=0.1, steps=1000):
    Xb = np.c_[np.ones(len(X)), X]
    W = np.zeros((Xb.shape[1], y_onehot.shape[1]))
    for _ in range(steps):
        P = softmax(Xb @ W)
        grad = Xb.T @ (P - y_onehot) / len(X)
        W -= lr * grad
    return W
```

梯度结构仍是 `输入.T @ (预测概率 - 目标)`。这就是第 7 章神经网络输出层的基础：前面增加隐藏层，输出层的概率与损失仍然相同。

## 概率、阈值与业务代价

分类器输出的是概率估计，业务系统输出的是决策。阈值不一定是 0.5：

- 欺诈漏掉一次的代价很高，可能降低阈值以多拦截，再交给人工复核；
- 广告点击预测更关注排序和收益，不一定只看准确率；
- 医疗筛查要同时报告敏感度、特异度和校准，不应只看最高概率类别。

常用指标包括混淆矩阵、precision、recall、F1、ROC-AUC、PR-AUC 和 log loss。类别极不平衡时，准确率尤其容易制造虚假安全感。

## 工业应用：分类是“概率 + 决策策略”

风控、垃圾邮件、设备故障、客户流失和质量检测都需要区分模型层与策略层。模型负责估计风险，策略层负责阈值、额度、人工审核、告警去重和回滚。把两层混在一个标签里，往往导致线上难以解释和调整。
