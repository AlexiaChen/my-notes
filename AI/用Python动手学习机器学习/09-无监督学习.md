# 第9章 无监督学习

## 本章的第一性原理

没有标签时，模型不能问“答案是什么”，只能问“什么样的结构能更简洁地解释数据”。因此聚类结果不是自然界自动贴好的真相，而是某个距离、概率模型和目标函数下的解释。

```text
无标签数据 → 表示/距离或概率假设 → 潜在分配 → 参数更新 → 结构解释与业务验证
```

## 9.1 二维输入数据

二维数据适合直接画出来，帮助理解“中心”“距离”“椭圆密度”和“边界”：

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
X = np.r_[
    rng.normal([0, 0], [0.8, 0.4], size=(100, 2)),
    rng.normal([3, 2], [0.6, 1.0], size=(100, 2)),
]
plt.scatter(X[:, 0], X[:, 1], s=12)
plt.axis("equal")
plt.show()
```

先看数据的尺度、离群点、密度和相关性。若第一列范围是 0 到 1、第二列范围是 0 到 10000，欧氏距离会几乎只由第二列决定；标准化和距离选择是建模的一部分。

## 9.2 K-means 算法

### 9.2.1 K-means 算法的概要

K-means 选择 $K$ 个中心 $\mu_k$，让每个点归属于最近中心，并最小化簇内平方距离：

$$
J(R,\mu)=\sum_{n=1}^{N}\sum_{k=1}^{K}R_{nk}
\|x_n-\mu_k\|_2^2,
$$

其中 $R_{nk}\in\{0,1\}$ 且每行只有一个 1。它假设“相似”可以用欧氏距离表达，簇大致是球状或凸的。

算法反复做两步：

1. 固定中心，给样本分配最近中心；
2. 固定分配，把每个中心更新为簇内均值。

### 9.2.2 步骤0：准备变量与初始化

```python
K = 2
N = len(X)
rng = np.random.default_rng(0)
mu = X[rng.choice(N, K, replace=False)].copy()
R = np.zeros((N, K), dtype=int)
```

初始化决定可能落入哪个局部最优。现代实现常用 k-means++，让初始中心尽量分散；也可以多次随机运行，选失真度最小的结果。

### 9.2.3 步骤1：更新 $R$

对每个样本计算到各中心的距离：

$$
R_{nk}=1\quad\text{if }k=\arg\min_j\|x_n-\mu_j\|^2.
$$

```python
dist2 = ((X[:, None, :] - mu[None, :, :]) ** 2).sum(axis=2)
labels = dist2.argmin(axis=1)
R[:] = 0
R[np.arange(N), labels] = 1
```

这一步是硬分配：每个点只属于一个簇。它对边界附近的点没有不确定性表达。

### 9.2.4 步骤2：更新 $\mu$

令第 $k$ 个簇的样本数为 $N_k=\sum_nR_{nk}$，则

$$
\mu_k=\frac{\sum_nR_{nk}x_n}{N_k}.
$$

```python
for k in range(K):
    members = X[labels == k]
    if len(members) > 0:
        mu[k] = members.mean(axis=0)
```

空簇必须特殊处理，例如重新选择一个离其他中心较远的样本。更新均值会让当前簇内平方距离不增加；交替进行直到标签或中心基本不变。

### 9.2.5 失真度量

```python
inertia = np.sum((X - mu[labels]) ** 2)
```

失真度是簇内平方距离之和，也叫 inertia。它随 $K$ 增大通常会下降，因此不能单独用“越小越好”选择 $K$。可结合肘部图、silhouette、稳定性和业务可解释性。

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

Xs = StandardScaler().fit_transform(X)
km = KMeans(n_clusters=2, n_init="auto", random_state=0).fit(Xs)
print(km.labels_, km.cluster_centers_, km.inertia_)
```

## 9.3 混合高斯模型

### 9.3.1 基于概率的聚类

K-means 给出硬标签；概率聚类给每个点一个属于各簇的概率。这样能表达边界不确定性，也能表达“这个点可能来自多个工况”。概率模型还可以进行密度估计和异常评分。

### 9.3.2 混合高斯模型

混合高斯假设数据由 $K$ 个高斯成分生成：

$$
p(x)=\sum_{k=1}^{K}\pi_k\mathcal N(x|\mu_k,\Sigma_k),
\qquad
\pi_k\ge0,\quad\sum_k\pi_k=1.
$$

每个成分有权重 $\pi_k$、均值 $\mu_k$ 和协方差 $\Sigma_k$。协方差让簇可以是椭圆、具有方向和不同宽度，比 K-means 的球状假设更灵活。

```python
from sklearn.mixture import GaussianMixture

gmm = GaussianMixture(n_components=2, covariance_type="full", random_state=0)
gmm.fit(X)
labels = gmm.predict(X)
responsibility = gmm.predict_proba(X)
log_density = gmm.score_samples(X)
```

### 9.3.3 EM 算法的概要

隐藏变量是“样本由哪个高斯成分生成”。直接同时求分配和参数很难，于是 EM 交替进行：

- **E 步**：固定参数，计算每个样本属于各成分的责任度 $\gamma_{nk}$；
- **M 步**：固定责任度，用加权样本更新 $\pi_k,\mu_k,\Sigma_k$。

每轮通常不降低观测数据的对数似然，但只能保证收敛到局部最优，不保证全局最优。

### 9.3.4 步骤0：准备变量与初始化

```python
N, D = X.shape
K = 2
pi = np.ones(K) / K
mu = X[rng.choice(N, K, replace=False)].copy()
Sigma = np.array([np.cov(X.T) + 1e-6 * np.eye(D) for _ in range(K)])
gamma = np.ones((N, K)) / K
```

协方差矩阵必须保持对称、半正定且数值可逆；实际实现常加入很小的正则项，避免某个成分塌缩到单个点导致协方差奇异。

### 9.3.5 步骤1（步骤 E）：更新 $\gamma$

责任度是后验概率：

$$
\gamma_{nk}=p(z_n=k|x_n)=
\frac{\pi_k\mathcal N(x_n|\mu_k,\Sigma_k)}
{\sum_j\pi_j\mathcal N(x_n|\mu_j,\Sigma_j)}.
$$

它回答“在当前模型下，这个点更像哪个成分”。与 K-means 的 0/1 分配相比，责任度保留了不确定性。

### 9.3.6 步骤2（步骤 M）：更新 $\pi、\mu$ 和 $\Sigma$

令 $N_k=\sum_n\gamma_{nk}$：

$$
\pi_k=\frac{N_k}{N},
\qquad
\mu_k=\frac1{N_k}\sum_n\gamma_{nk}x_n,
$$

$$
\Sigma_k=\frac1{N_k}\sum_n\gamma_{nk}
(x_n-\mu_k)(x_n-\mu_k)^T.
$$

这就是加权均值与加权协方差。E 步告诉 M 步“每个点应贡献多少”，M 步再重新拟合各个高斯。

### 9.3.7 似然

观测数据的对数似然为

$$
\ell=\sum_n\log\left(\sum_k\pi_k
\mathcal N(x_n|\mu_k,\Sigma_k)\right).
$$

```python
print(gmm.lower_bound_, gmm.bic(X), gmm.aic(X))
```

用 BIC/AIC、交叉验证、稳定性和业务解释选择成分数。成分数越多，似然通常越容易提高，但模型可能把噪声或单个异常点当成一个高斯。

## K-means 与混合高斯的关系

二者都在寻找潜在分组，但假设不同：

| 维度 | K-means | 混合高斯 |
|---|---|---|
| 分配 | 硬分配 | 概率分配 |
| 簇形状 | 近似球状、相近尺度 | 可用协方差表达椭圆与方向 |
| 目标 | 簇内平方距离 | 数据对数似然 |
| 输出 | 标签、中心 | 标签、责任度、密度 |
| 风险 | 对尺度、离群点、K 敏感 | 对初始化、协方差奇异、成分数敏感 |

不要把聚类编号当成真实类别名；运行两次后编号交换并不代表模型改变。业务验证要看每簇的特征画像、行为差异和后续决策价值。

## 工业应用：没有标签时如何负责地使用聚类

- 客户分群：先标准化特征，按行为画像解释簇，而不是直接把簇号当营销标签；
- 设备工况：按传感器模式分簇，再由专家确认哪些簇对应正常/异常；
- 质量检测：用密度或距离发现新模式，但要用人工复核建立可靠标签；
- 日志/文本：距离应在合适的嵌入空间定义，原始高维欧氏距离可能没有意义。

聚类的最终评估不只是 silhouette。还应问：簇在时间上是否稳定？新数据能否归属？业务动作是否因分群而改善？
