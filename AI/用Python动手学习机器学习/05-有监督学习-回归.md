# 第5章 有监督学习：回归

## 本章的第一性原理

回归不是“画一条最像的线”，而是：在给定特征的前提下，用一个可解释的函数估计连续目标，并明确预测误差的代价。线性回归之所以重要，是因为它把后续深度学习的骨架暴露得很清楚：

```text
输入 X → 模型 Xw+b → 误差 y_hat-y → 损失 → 梯度/解析解 → 新数据预测
```

## 5.1 一维输入的直线模型

### 5.1.1 直线模型

给定一个输入 $x$，最简单的模型是

$$
y=wx+b.
$$

$w$ 表示输入增加一单位时预测值的变化，$b$ 是截距。这里“线性”指对参数线性，不代表真实世界一定是直线。

```python
def predict(x, w, b):
    return w * x + b
```

### 5.1.2 平方误差函数

对 $n$ 个样本，常用均方误差或带 $1/2$ 的平方损失：

$$
J(w,b)=\frac{1}{2n}\sum_{i=1}^{n}
\left(wx_i+b-y_i\right)^2.
$$

平方有两个效果：把正负误差变成非负，并对大误差施加更大惩罚。它隐含了一个统计解释：若噪声近似独立同分布的高斯噪声，最小化平方误差等价于最大化似然。

```python
def squared_error(y_hat, y):
    return 0.5 * np.mean((y_hat - y) ** 2)
```

### 5.1.3 求参数（梯度法）

对参数求导：

$$
\frac{\partial J}{\partial w}=\frac1n\sum_i(wx_i+b-y_i)x_i,
\quad
\frac{\partial J}{\partial b}=\frac1n\sum_i(wx_i+b-y_i).
$$

梯度下降更新：

$$
w\leftarrow w-\eta\frac{\partial J}{\partial w},
\qquad
b\leftarrow b-\eta\frac{\partial J}{\partial b}.
$$

```python
def fit_line_gd(x, y, lr=0.01, steps=2000):
    w, b = 0.0, 0.0
    for _ in range(steps):
        err = w * x + b - y
        dw = np.mean(err * x)
        db = np.mean(err)
        w -= lr * dw
        b -= lr * db
    return w, b
```

学习率太小会慢，太大会振荡甚至发散。特征尺度差异很大时，先标准化通常能让损失面更圆，梯度下降更容易走。

### 5.1.4 直线模型参数的解析解

把偏置并入设计矩阵 $X_b=[\boldsymbol{1},\boldsymbol{x}]$，则

$$
J(\boldsymbol{w})=\frac{1}{2n}\|X_b\boldsymbol{w}-\boldsymbol{y}\|_2^2.
$$

令梯度为零得到正规方程：

$$
\boldsymbol{w}^*=(X_b^TX_b)^{-1}X_b^T\boldsymbol{y}.
$$

理论式帮助理解，工程实现应避免显式求逆：

```python
Xb = np.c_[np.ones(len(x)), x]
wb, *_ = np.linalg.lstsq(Xb, y, rcond=None)
b, w = wb
```

解析解一次求出最优参数，适合特征维度不太大且目标函数确实是线性最小二乘的情况；梯度法更容易扩展到大数据、在线训练和非线性模型。

## 5.2 二维输入的平面模型

### 5.2.1 数据的表示方法

每个样本有两个特征：

$$
\boldsymbol{x}_i=(x_{i1},x_{i2})^T,
\qquad
X\in\mathbb R^{n\times2}.
$$

```python
X = np.array([[1.2, 10.0], [2.0, 12.0], [3.1, 9.0]])
y = np.array([20.0, 25.0, 27.0])
assert X.shape == (len(y), 2)
```

行是样本、列是特征的约定要一直保持，否则模型可能运行但解释全部颠倒。

### 5.2.2 平面模型

二维输入的线性模型是平面：

$$
\hat y=w_1x_1+w_2x_2+b.
$$

批量代码：

```python
def predict_plane(X, w, b):
    return X @ w + b
```

三个参数构成一个方向：$w$ 指向预测增长最快的特征组合，$b$ 移动整个平面。可视化时可以画散点和拟合平面，也可以画残差。

### 5.2.3 平面模型参数的解析解

设计矩阵加上偏置列：

```python
Xb = np.c_[np.ones(len(X)), X]
wb, *_ = np.linalg.lstsq(Xb, y, rcond=None)
y_hat = Xb @ wb
```

正规方程的思想仍然不变，只是参数从 2 个增加到 3 个。特征高度相关时，$X^TX$ 会接近奇异，参数可能不稳定，即使预测误差暂时不大。

## 5.3 D 维线性回归模型

### 5.3.1 D 维线性回归模型

$$
\hat{\boldsymbol y}=X\boldsymbol w+b\boldsymbol 1,
\quad X\in\mathbb R^{n\times D}.
$$

如果把偏置列并入 $X_b$，模型统一为 $\hat y=X_b\theta$。这一步把“直线/平面”提升为任意维度的超平面。

### 5.3.2 参数的解析解

$$
\theta^*=(X_b^TX_b)^{-1}X_b^Ty.
$$

实际工程：

```python
theta, residuals, rank, singular_values = np.linalg.lstsq(Xb, y, rcond=None)
```

`rank` 和奇异值可以帮助发现特征冗余。需要大量预测时，还应考虑训练/推理的矩阵成本和稀疏表示。

### 5.3.3 扩展到不通过原点的平面

“通过原点”意味着 $b=0$，这是一种很强的先验：所有特征为 0 时目标必须为 0。多数业务不满足这个假设，因此通常加入偏置列：

```python
Xb = np.c_[np.ones(X.shape[0]), X]
```

是否加入偏置不是代码习惯，而是对数据生成过程的建模选择。若特征已中心化，偏置的含义会改变，但不一定应删除。

## 5.4 线性基底函数模型

线性模型可以对参数保持线性，同时对输入做非线性变换：

$$
\hat y=\sum_{j=1}^{M}w_j\phi_j(x).
$$

例如多项式基底 `1, x, x**2, x**3`：

```python
def polynomial_features(x, degree):
    return np.column_stack([x ** k for k in range(degree + 1)])
```

关键洞见：**非线性不一定要来自复杂模型，也可以来自特征空间的改变**。第 7 章的神经网络则把这种表示变换也交给模型学习。

## 5.5 过拟合问题

基函数数量增加后，模型可以更贴合训练数据，但可能把噪声也当成规律。典型现象是训练误差下降，验证误差先下降后上升。

```python
degrees = range(1, 12)
train_errors, val_errors = [], []
```

过拟合有两种来源：模型表达能力过强，或训练数据不能代表未来。解决方法包括减少复杂度、增加数据、正则化、交叉验证、早停和更合理的特征。正则化的本质是把“拟合数据”和“保持模型简单”放到同一个目标里：

$$
J_{reg}=J+\lambda\|w\|_2^2.
$$

不要把训练误差最低等同于模型最好；真正目标是泛化误差。

## 5.6 新模型的生成

模型不是从算法菜单中凭感觉挑一个，而是从失败现象提出改动：

| 观察 | 可能的模型改动 |
|---|---|
| 直线有系统性弯曲残差 | 加入基函数或变换特征 |
| 某些区域误差明显更大 | 检查异方差、分组建模或加权损失 |
| 训练和验证都差 | 增加信息、改进特征或提高模型容量 |
| 训练好、验证差 | 减少复杂度、正则化或增加数据 |
| 参数不稳定但预测还行 | 检查共线性、标准化和正则化 |

这是一种可迁移的创新方法：不是“发明一个新算法”，而是让模型结构响应数据中可观察的错误。

## 5.7 模型的选择

模型选择必须只使用训练/验证信息，测试集留到最后。常见指标：

- MAE：每个错误的平均绝对大小，较不容易被极端值支配；
- MSE：大误差惩罚更重，适合对大偏差特别敏感的任务；
- RMSE：和目标同单位，更便于沟通；
- $R^2$：相对基准方差的解释比例，但不能替代业务指标。

随机样本可用交叉验证；时间序列则应按时间切分，不能让未来信息进入过去。选择模型时同时看误差、稳定性、延迟、内存、可解释性和维护成本。

## 5.8 小结

本章得到一套最小监督学习模板：

1. 用矩阵表示样本和特征；
2. 选一个函数族，如直线或基函数展开；
3. 用平方误差定义拟合目标；
4. 用解析解或梯度下降求参数；
5. 用独立验证数据判断泛化；
6. 根据残差和业务代价迭代模型。

## 工业应用：回归是很多系统的“基准模型”

价格、需求量、库存、能耗、设备寿命和风险分数都可以先用线性回归建立基线。基线的价值不是一定最准确，而是提供：可解释系数、速度快的训练、清楚的残差和一个能与复杂模型比较的下限。

上线前还要问：目标是否延迟可获得？预测区间是否需要？极端值会不会造成危险？模型是否被用于它没有见过的外推区域？
