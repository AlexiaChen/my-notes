# 第3章 数据可视化

## 本章的第一性原理

机器学习程序最容易出现的危险状态是：代码没有报错，但含义错了。图形可以暴露单位错误、坐标轴交换、异常点、非线性关系、类别重叠、损失函数的局部极小值和聚类边界。把图看作模型的显微镜，而不是报告里的装饰。

## 3.1 绘制二维图形

### 3.1.1 绘制随机图形

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
x = np.arange(20)
y = rng.normal(size=20)
plt.plot(x, y, "o-")
plt.show()
```

随机图形首先用来验证绘图环境、轴方向和数据长度。固定随机种子方便复现，但不要把一个种子的现象当成统计结论。

### 3.1.2 代码清单的格式

绘图代码建议分成“准备数据、创建画布、绘制、装饰、显示”五步。把数据生成和绘图分开，后续才能用同一份数据比较不同模型。

```python
x = np.linspace(-3, 3, 400)
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(x, np.sin(x))
ax.set_xlabel("x")
ax.set_ylabel("y")
plt.show()
```

### 3.1.3 绘制三次函数 $f(x)=(x-2)x(x+2)$

```python
x = np.linspace(-3, 3, 400)
y = (x - 2) * x * (x + 2)
fig, ax = plt.subplots()
ax.plot(x, y, label=r"$f(x)=(x-2)x(x+2)$")
ax.axhline(0, color="black", linewidth=0.8)
ax.axvline(0, color="black", linewidth=0.8)
ax.legend()
plt.show()
```

画出函数后可以看到零点、上升/下降区间和局部变化。第 4 章的导数会解释为什么曲线的斜率是优化方向的局部信息。

### 3.1.4 确定绘制范围

`np.linspace(start, stop, num)` 的范围不是中性的。只看 `[-3,3]`，你只能对这一段作结论；在业务图表中只展示某个时间窗口，也可能隐藏季节性或数据漂移。

```python
x = np.linspace(-5, 5, 1000)
ax.set_xlim(-5, 5)
```

### 3.1.5 绘制图形

```python
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, y, color="tab:blue", linewidth=2)
```

先画数据，再决定线型、颜色和标记。不要为了“好看”改变可能影响解读的比例或截断轴。

### 3.1.6 装饰图形

```python
ax.set_title("Cubic function")
ax.set_xlabel("input x")
ax.set_ylabel("output f(x)")
ax.grid(alpha=0.25)
ax.legend()
fig.tight_layout()
```

标题、单位、图例、网格和 colorbar 是数据契约的一部分。没有单位的纵轴无法支持工业决策。

#### 误差棒与不确定性

如果结果来自多次实验，不要只画一次曲线；可画均值和标准差，告诉读者模型对随机种子或采样的敏感程度。

### 3.1.7 并列显示多张图形

```python
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].plot(x, y)
axes[0].set_title("model output")
axes[1].plot(x, np.gradient(y, x))
axes[1].set_title("numerical slope")
plt.tight_layout()
```

并列图形适合对照“数据 vs 模型”“训练 vs 验证”“预测 vs 残差”。关键是共享相同的尺度和清晰的标题。

## 3.2 绘制三维图形

对于 $z=f(x_0,x_1)$，一条曲线不够，因为输入有两个自由度。`meshgrid` 把两个轴组合成坐标网格。

### 3.2.1 包含两个变量的函数

```python
x0 = np.linspace(-3, 3, 120)
x1 = np.linspace(-3, 3, 120)
xx0, xx1 = np.meshgrid(x0, x1)
zz = np.sin(xx0) * np.cos(xx1)
print(xx0.shape, xx1.shape, zz.shape)  # 三者应一致
```

每个网格位置 `(i,j)` 都对应一个输入点 `(xx0[i,j], xx1[i,j])` 与一个输出 `zz[i,j]`。形状不一致时，图形即使能画出来也可能语义错位。

### 3.2.2 用颜色表示数值：`pcolor`

```python
fig, ax = plt.subplots(figsize=(5, 4))
im = ax.pcolor(xx0, xx1, zz, shading="auto", cmap="viridis")
fig.colorbar(im, ax=ax, label="f(x0,x1)")
ax.set_xlabel("x0")
ax.set_ylabel("x1")
plt.show()
```

颜色图适合快速查看整体区域、阈值和异常值。必须配 colorbar，否则颜色没有可解释的数值含义。

### 3.2.3 绘制三维图形：`surface`

```python
fig = plt.figure(figsize=(6, 5))
ax = fig.add_subplot(projection="3d")
surf = ax.plot_surface(xx0, xx1, zz, cmap="coolwarm", linewidth=0)
fig.colorbar(surf, ax=ax, shrink=0.6)
ax.set_xlabel("x0")
ax.set_ylabel("x1")
ax.set_zlabel("z")
plt.show()
```

曲面图适合建立“高低”和“坡度”的三维直觉，但会受视角影响；报告中常用等高线补充，避免读者从一个角度误判。

### 3.2.4 绘制等高线：`contour`

```python
fig, ax = plt.subplots(figsize=(5, 4))
cs = ax.contour(xx0, xx1, zz, levels=12)
ax.clabel(cs, inline=True, fontsize=8)
ax.set_aspect("equal")
plt.show()
```

等高线特别适合优化问题：梯度大致垂直于等高线，狭长的谷说明不同方向的曲率差异很大。第 5 章可以把它用于回归损失面，第 9 章可以把它用于高斯密度。

## 工业视角：可视化是模型的观测接口

| 业务问题 | 建议图形 |
|---|---|
| 数据是否漂移 | 训练期/线上期的特征分布、分位数图 |
| 阈值如何选 | ROC/PR 曲线、阈值—成本曲线 |
| 哪些样本最危险 | 按置信度、残差或异常分数排序的散点图 |
| 模型在哪些区域失效 | 特征空间误分类图、残差图 |
| 训练为什么不稳定 | 学习率、损失、梯度范数随步数的曲线 |

没有图的指标容易被误读；没有指标的图容易被凭感觉解读。二者应同时存在。

## 本章练习

1. 画出一个二元函数的 `pcolor`、`surface`、`contour`，解释三者各自隐藏了什么信息。
2. 画一个人为制造过拟合的训练/验证损失曲线，标出最佳停止点。
3. 生成两个二维类别，画散点图并标出错分点。
4. 把一个矩阵转置后重新绘图，观察“看起来没问题”但语义改变的情况。
