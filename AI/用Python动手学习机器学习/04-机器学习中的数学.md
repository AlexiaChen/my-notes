# 第4章 机器学习中的数学

## 本章的第一性原理

机器学习里的数学不是为了证明“自己很专业”，而是为了回答一个工程问题：**参数应该怎样改变，才能让预测更符合目标**。向量和矩阵负责批量表示与变换，导数负责告诉我们改变方向，指数/对数和概率函数负责表达不确定性。

整章可以压缩成一条链：

```text
数据向量 → 线性变换 → 非线性/概率函数 → 损失 → 梯度 → 参数更新
```

## 4.1 向量

### 4.1.1 什么是向量

向量是一串有顺序的数，也可以看作空间中的一个点或方向：

$$
\boldsymbol{x}=(x_1,x_2,\ldots,x_D)^T.
$$

在机器学习中，一个样本是一条特征向量；一批样本叠起来就形成矩阵。向量的“方向”和“长度”比单个数字更能表达对象之间的关系。

### 4.1.2 用 Python 定义向量

```python
import numpy as np
x = np.array([1.0, 2.0, 3.0])
print(x.shape, x.dtype)
```

一维 NumPy 数组的形状是 `(3,)`。这和二维列向量 `(3, 1)` 不同，后者在矩阵乘法和广播中有明确的第二个轴。

### 4.1.3 列向量的表示方法

```python
x_col = np.array([[1.0], [2.0], [3.0]])
print(x_col.shape)  # (3, 1)
```

数学教材默认常把向量写成列向量，因为矩阵乘法 `A @ x` 的形状更明确。工程代码中常见 `(D,)`，但写推导时要清楚它在语义上代表列还是行。

### 4.1.4 转置的表示方法

```python
x = np.array([[1., 2., 3.]])  # (1,3)，行向量
print(x.T.shape)              # (3,1)，列向量
```

对一维数组 `np.array([1,2,3]).T` 不会改变形状，这是一个常见陷阱。若需要列向量，显式使用 `x[:, None]` 或 `reshape(-1, 1)`。

### 4.1.5 加法和减法

$$
\boldsymbol{x}+\boldsymbol{y}=(x_1+y_1,\ldots,x_D+y_D).
$$

```python
x = np.array([1., 2.])
y = np.array([3., 5.])
print(x + y, x - y)
```

向量加法的几何意义是平移；在数据处理中，减去均值就是把数据云平移到原点附近。

### 4.1.6 标量积

$$
a\boldsymbol{x}=(ax_1,\ldots,ax_D).
$$

```python
print(0.5 * x)
```

标量积改变长度，若 $a<0$ 还会反转方向。学习率、特征缩放和单位换算都可以先用这个视角理解。

### 4.1.7 内积

$$
\boldsymbol{x}^T\boldsymbol{y}=\sum_{i=1}^{D}x_i y_i.
$$

```python
print(x @ y)
print(np.dot(x, y))
```

内积同时表达“加权求和”和“相似程度”。线性回归的预测 `w^T x + b`、神经元的输入和余弦相似度，都建立在内积上。

### 4.1.8 向量的模

$$
\|\boldsymbol{x}\|_2=\sqrt{\sum_i x_i^2}.
$$

```python
print(np.linalg.norm(x))
```

模是向量长度。它既可度量样本离原点的距离，也可作为正则化项惩罚过大的参数。距离度量改变时，聚类结果也会改变。

## 4.2 求和符号

### 4.2.1 带求和符号的数学式的变形

$$
\sum_{i=1}^{n}(a_i+b_i)=\sum_{i=1}^{n}a_i+\sum_{i=1}^{n}b_i,
$$

$$
\sum_{i=1}^{n}c a_i=c\sum_{i=1}^{n}a_i.
$$

这些变形看似简单，却是推导损失函数梯度的基础：把与参数无关的常数提出，把可以逐项求导的部分拆开。

```python
errors = np.array([1., -2., 3.])
print(np.sum(errors ** 2))
```

### 4.2.2 通过内积求和

令全 1 向量为 $\boldsymbol{1}$，则

$$
\sum_i a_i=\boldsymbol{1}^T\boldsymbol{a}.
$$

批量计算时，很多求和都可以改写成矩阵乘法或向量化操作，减少 Python 循环，并让公式和代码保持一一对应。

## 4.3 累乘符号

$$
\prod_{i=1}^{n}a_i=a_1a_2\cdots a_n.
$$

概率模型中，独立样本的联合似然常写成多个概率的乘积。直接相乘容易下溢，因此工程中通常取对数，把累乘变成求和：

$$
\log\prod_i p_i=\sum_i\log p_i.
$$

这也是“最大似然”和“交叉熵”在代码中常以 log 概率出现的原因。

## 4.4 导数

### 4.4.1 多项式的导数

幂函数的基本规则是

$$
\frac{d}{dx}x^k=kx^{k-1}.
$$

例如 $f(x)=3x^2+2x+1$ 的导数为 $f'(x)=6x+2$。导数表示在当前点附近，输入发生很小变化时输出会怎样变化。

```python
def f(x):
    return 3 * x**2 + 2 * x + 1

def numerical_derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)
```

### 4.4.2 带导数符号的数学式的变形

线性性给出

$$
\frac{d}{dx}(af+bg)=a\frac{df}{dx}+b\frac{dg}{dx}.
$$

常数的导数为 0；和式可以逐项求导。机器学习推导中，先把表达式拆成可识别的基本块，再逐块求导，错误会更少。

### 4.4.3 复合函数的导数

若 $y=g(u)$ 且 $u=f(x)$，那么 $y=g(f(x))$ 的导数不能只看外层函数，必须考虑内层变化。

### 4.4.4 复合函数的导数：链式法则

$$
\frac{dy}{dx}=\frac{dy}{du}\frac{du}{dx}.
$$

反向传播只是把链式法则系统地应用到一张计算图上。神经网络看似复杂，是因为复合层多，而不是因为每一步的微积分不同。

## 4.5 偏导数

### 4.5.1 什么是偏导数

对多变量函数 $f(x_1,x_2)$，偏导数只改变一个变量，暂时固定其他变量：

$$
\frac{\partial f}{\partial x_1},\quad \frac{\partial f}{\partial x_2}.
$$

所有偏导数排成的向量就是梯度：

$$
\nabla f=\left(\frac{\partial f}{\partial x_1},\ldots,\frac{\partial f}{\partial x_D}\right)^T.
$$

### 4.5.2 偏导数的图形

```python
def loss(w0, w1):
    return (w0 - 1.0)**2 + 3.0 * (w1 + 0.5)**2

w0 = np.linspace(-3, 3, 100)
w1 = np.linspace(-3, 3, 100)
W0, W1 = np.meshgrid(w0, w1)
Z = loss(W0, W1)
plt.contour(W0, W1, Z, levels=15)
plt.xlabel("w0")
plt.ylabel("w1")
plt.show()
```

椭圆等高线表示不同方向的曲率不一样；梯度指向损失上升最快的方向，所以梯度下降沿负梯度走。

### 4.5.3 绘制梯度的图形

```python
def grad_loss(w0, w1):
    return 2 * (w0 - 1.0), 6 * (w1 + 0.5)

step = 0.5
g0, g1 = grad_loss(W0[::8, ::8], W1[::8, ::8])
plt.contour(W0, W1, Z, levels=15)
plt.quiver(W0[::8, ::8], W1[::8, ::8], -g0, -g1, color="red")
plt.show()
```

图形能把“梯度是一个向量”变成可见现象。箭头指向损失下降方向，但箭头长度还受到学习率、坐标尺度和曲率影响。

### 4.5.4 多变量的复合函数的偏导数

如果 $z=g(u,v)$，而 $u=u(x,y)$、$v=v(x,y)$，则

$$
\frac{\partial z}{\partial x}=\frac{\partial z}{\partial u}\frac{\partial u}{\partial x}+\frac{\partial z}{\partial v}\frac{\partial v}{\partial x}.
$$

这说明一个参数对最终损失的影响，可能通过多条路径叠加。反向传播会把这些路径的贡献累加起来。

### 4.5.5 交换求和与求导的顺序

在满足适当条件时，有限求和可以交换求导：

$$
\frac{\partial}{\partial w}\sum_i L_i(w)=\sum_i\frac{\partial L_i(w)}{\partial w}.
$$

这正是批量训练梯度可以由每个样本梯度相加得到的原因。随机小批量只是用一部分样本近似整体平均。

## 4.6 矩阵

### 4.6.1 什么是矩阵

矩阵是按行列组织的数字表，也可以看作把一个向量空间映射到另一个向量空间的线性变换。数据矩阵通常写成 `X.shape == (n_samples, n_features)`。

### 4.6.2 矩阵的加法和减法

只有形状相同的矩阵才能直接相加：

$$
(A+B)_{ij}=A_{ij}+B_{ij}.
$$

```python
A = np.array([[1., 2.], [3., 4.]])
B = np.array([[5., 6.], [7., 8.]])
print(A + B)
```

### 4.6.3 标量积

$$
(cA)_{ij}=cA_{ij}.
$$

它相当于统一缩放每一列/行的所有元素，是学习率和正则化推导中最常见的操作之一。

### 4.6.4 矩阵的乘积

若 $A$ 为 $m\times k$，$B$ 为 $k\times n$，则 $AB$ 为 $m\times n$：

$$
(AB)_{ij}=\sum_{r=1}^{k}A_{ir}B_{rj}.
$$

```python
A = np.array([[1., 2., 3.], [4., 5., 6.]])
B = np.array([[1., 0.], [0., 1.], [1., 1.]])
print((A @ B).shape)  # (2,2)
```

内层维度相等是矩阵乘法成立的形状条件。把形状写在纸上，往往比盯着报错更快。

### 4.6.5 单位矩阵

单位矩阵 $I$ 满足 $AI=A$、$IA=A$。在 NumPy 中：

```python
I = np.eye(3)
```

它是线性变换中的“不改变”操作，也是定义逆矩阵的基准。

### 4.6.6 逆矩阵

若存在 $A^{-1}$ 使得 $AA^{-1}=I$，则 $A^{-1}$ 可以撤销 $A$ 的变换。并非所有矩阵都可逆，接近奇异时数值也会不稳定。

```python
A = np.array([[2., 1.], [1., 2.]])
print(np.linalg.inv(A))
```

实际求解线性回归不应显式计算逆矩阵，优先使用 `np.linalg.solve` 或 `np.linalg.lstsq`，因为数值更稳定。

### 4.6.7 转置

转置交换行和列：

$$
(A^T)_{ij}=A_{ji}.
$$

重要恒等式是 $(AB)^T=B^T A^T$。线性回归梯度中的 `X.T @ (...)` 就来自这个结构。

### 4.6.8 矩阵和联立方程式

联立方程可以写成 $A\boldsymbol{x}=\boldsymbol{b}$。若 $A$ 可逆，理论上 $x=A^{-1}b$；数值计算更推荐：

```python
A = np.array([[3., 1.], [1., 2.]])
b = np.array([9., 8.])
x = np.linalg.solve(A, b)
```

这会在第 5 章解析求线性回归参数时再次出现。

### 4.6.9 矩阵和映射

矩阵可以把一组坐标旋转、缩放、投影到另一个空间。神经网络的一层本质上就是矩阵乘法加偏置：

$$
\boldsymbol{z}=W\boldsymbol{x}+\boldsymbol{b}.
$$

若没有激活函数，多层矩阵相乘仍然只是一次线性映射，这为第 7 章“为什么需要非线性”做铺垫。

## 4.7 指数函数和对数函数

### 4.7.1 指数

指数函数 $e^x$ 把加法关系转换成乘法尺度。它增长快，数值可能溢出，因此实际代码会关注输入范围。

```python
x = np.array([-1., 0., 1.])
print(np.exp(x))
```

### 4.7.2 对数

对数把乘法变成加法：$\log(ab)=\log a+\log b$。它还会把很小的概率变成较大的负数，适合累计似然，但 `log(0)` 不可用。

### 4.7.3 指数函数的导数

$$
\frac{d}{dx}e^x=e^x.
$$

指数函数的导数等于自身，是 softmax、最大似然和神经网络梯度推导的关键。

### 4.7.4 对数函数的导数

$$
\frac{d}{dx}\log x=\frac1x.
$$

当预测概率很小时，负对数似然会产生较大的惩罚，这解释了交叉熵为什么会强烈惩罚“自信但错误”的预测。

### 4.7.5 Sigmoid 函数

$$
\sigma(x)=\frac1{1+e^{-x}}.
$$

它把任意实数压到 `(0,1)`，可解释为二分类中正类的概率。导数可以写成

$$
\sigma'(x)=\sigma(x)(1-\sigma(x)).
$$

当输入绝对值很大时，导数接近 0，深层网络中可能出现梯度消失。

### 4.7.6 Softmax 函数

$$
\operatorname{softmax}(\boldsymbol{a})_k=
\frac{e^{a_k}}{\sum_j e^{a_j}}.
$$

它把多个类别的分数变成和为 1 的概率。稳定实现要先减去最大值：

```python
def softmax(a):
    a = np.asarray(a)
    a_shift = a - np.max(a, axis=-1, keepdims=True)
    exp_a = np.exp(a_shift)
    return exp_a / exp_a.sum(axis=-1, keepdims=True)
```

减去最大值不会改变结果，因为分子分母同时乘了同一个常数，却能防止指数溢出。

### 4.7.7 Softmax 函数和 Sigmoid 函数

二分类时，两个类别的 softmax 可以化为 sigmoid；多分类时使用 softmax，使各类概率相互竞争并总和为 1。不要把 sigmoid 用在互斥多分类的输出上，也不要把 softmax 当成已经校准的业务概率。

### 4.7.8 高斯函数

一维高斯密度可写成

$$
p(x)=\frac1{\sqrt{2\pi\sigma^2}}
\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).
$$

均值决定中心，方差决定分布宽窄。高斯函数不是“所有数据都应该服从的真理”，而是一个可解释、可计算的建模假设。

### 4.7.9 二维高斯函数

二维高斯的协方差矩阵决定等密度线的方向和长短轴。协方差非对角元素表示特征一起变化；第 9 章的混合高斯模型会用多个二维高斯组合出更灵活的密度。

```python
from scipy.stats import multivariate_normal
mean = [0, 0]
cov = [[1, 0.6], [0.6, 1]]
```

## 工业视角：数值稳定性是正确性的一部分

大规模训练中，`exp` 溢出、`log(0)`、矩阵病态、梯度过小或过大都会让结果失真。稳定实现常见原则包括：

- softmax 使用减最大值；
- 计算 log-likelihood 时优先使用 log-sum-exp；
- 解方程使用分解/`lstsq`，避免显式逆矩阵；
- 标准化特征，减少不同量纲造成的病态；
- 监控 `NaN`、`inf`、梯度范数和损失曲线。
