## 第17章 监督降维

### 17.1 与分类问题相对应的判别分析

**书中思路**：无监督降维（PCA，第13.2节）追求"方差最大"，但这不保证类别可分。监督降维的目标是——**在低位空间中，不同类别尽可能分开，同类样本尽可能紧凑**。这就是判别分析（Discriminant Analysis）的核心。

**线性判别分析（LDA）的数学形式**：

定义类内散布矩阵（Within-class scatter）和类间散布矩阵（Between-class scatter）：

$$
S_W=\sum_{c=1}^{C}\sum_{x_i\in C_c}
(x_i-\mu_c)(x_i-\mu_c)^{\mathsf T}
$$

$$
S_B=\sum_{c=1}^{C}
(\mu_c-\mu)(\mu_c-\mu)^{\mathsf T}
$$

其中 $\mu_c$ 是第 $c$ 类的均值，$\mu$ 是全局均值。

**LDA 的优化目标**：

$$
\max_W J(W)=
\frac{\left|W^{\mathsf T}S_BW\right|}
{\left|W^{\mathsf T}S_WW\right|}
$$

解为广义特征值问题：$S_Bw=\lambda S_Ww$，取前 $d$ 个最大特征值对应的特征向量。

**🎯 第一性原理洞察：LDA = "类间拉开 / 类内压紧"的比值最大化**

```
LDA 的几何直觉 (二分类, C=2):

       类别1 ● ● ● ● ●            类别1 ● ● ● ● ●
             ● ● ● ●                ● ● ● ●
              ● ● ●                 ● ● ●
              │   │                 │   │
              │   │ ← 类内散布小    │   │ ← 类内散布小
              │   │                 │   │
       类别2 ● ● ● ● ●             │   │
             ● ● ● ●                │   │
              ● ● ●                 │   │
                                     ↓
       类内紧 + 类间远 = 好             投影到 w* 后:
                                     ●●●●●│○○○○○
                                     ●●●● │ ●○○○○
                                     ●●●  │  ●○○○
                                     ↑     ↑
                                   类别1  类别2
                                   完全分离!
                                   
  $w^*=S_W^{-1}(\mu_1-\mu_2)$（Fisher 线性判别）
```

**与 PCA 的本质对比**​ ：

|维度|PCA（第13.2节）|LDA（本节）|
|---|---|---|
|优化目标|全局方差最大|**类间/类内散布比最大**​|
|是否用标签|否（无监督）|**是（监督）**​|
|投影方向|方差最大方向|类别可分性最大方向|
|对异常点|敏感|**相对鲁棒**（类内散布对异常有一定抵抗）|
|适用场景|数据探索、去噪、压缩|**分类前的特征压缩**​|
|类数限制|无|最多降到 C-1 维|

**ASCII 对比 PCA vs LDA 的投影方向**：

```
二维数据 (两类):

       ● ● ● ● ●               ● ● ● ● ●
     ● ● ● ● ● ●             ● ● ● ● ● ●
       ● ● ● ●                 ● ● ● ●
         ● ● ●                   ● ● ●
                                   │
   类别1  ↗                       │ ← LDA 方向 (垂直于两类均值连线)
         ↗                         │
          ↗  PCA 方向 (方差最大)   │
           ↗                       │
       ○ ○ ○ ○ ○                 ○ ○ ○ ○ ○
     ○ ○ ○ ○ ○ ○               ○ ○ ○ ○ ○ ○
       ○ ○ ○ ○ ○               ○ ○ ○ ○ ○
                                   │
                                   ↓
                               投影后两类分离

   PCA: 沿数据长轴投影 → 两类可能重叠
   LDA: 沿"分开两类"的方向投影 → 两类分离最大化
```

**LDA 的隐含假设与局限**​ ：

```
假设1: 各类别协方差矩阵相同 (Σ₁ = Σ₂ = ... = Σ_C)
   → 否则 S_W 的"平均协方差"不再最优
   → 实际中常做椭圆化/白化预处理

假设2: 数据呈高斯分布
   → LDA 在高斯假设下是贝叶斯最优分类器
   → 非高斯时仍是好的线性近似

假设3: 线性可分性
   → 若数据需要非线性边界 → 核判别分析 (KDA)
   → KDA = 核技巧 + LDA (与 Kernel PCA 同理)

类数限制:
   → LDA 最多降到 C-1 维
   → 3 类 → 最多 2 维; 2 类 → 最多 1 维
   → 若需要更低维 → 用 PCA 先降维再 LDA (两步法)
```

**核判别分析（KDA）**​ ：

```
KDA = 核技巧 + LDA
   在核诱导的高维特征空间中做 LDA
   → 能处理非线性可分的数据
   → 与 Kernel PCA (13.4) 和 核SVM (8.4) 同源
   
   计算: 用核矩阵 K 替代内积
   优化: 核空间中的广义特征值问题
```

**🎯 深度洞见：LDA 与最小二乘分类（第7章）的深刻等价性**

```
第7章的洞见回顾:
  最小二乘分类中, 若将标签编码为 {+1/n₊, -1/n₋}
  → 等价于 Fisher LDA!

这意味着:
  最小二乘分类 (第7章) = LDA (本节)
  两者在相同的高斯假设下都是贝叶斯最优

但 LDA 更进一步:
  - 显式地建模类内/类间散布
  - 提供降维 (不只是分类)
  - 自然地扩展到多类 (C>2)
  
  而最小二乘分类:
  - 只给出分类决策
  - 不直接提供降维
```

**工业视角**：

```
LDA 的工业应用：

✓ 适用场景：
  - 有标签数据 + 需要降维后再分类
  - 类别数适中 (2~50)
  - 各类协方差近似相同
  - 需要可解释的降维（判别方向有明确含义）
  
典型应用：
  1. 人脸识别 (经典):
     Fisherfaces = PCA (Eigenfaces) + LDA
     先用 PCA 降维去相关, 再用 LDA 最大化类别可分性
     → 比纯 PCA 识别率高
     
  2. 生物信息学:
     基因表达数据的监督降维
     区分疾病亚型 (如癌症分型)
     
  3. 语音识别:
     声学特征的监督降维
     区分不同音素
     
  4. 医学影像:
     病灶/正常组织的监督降维
     辅助诊断
     
  5. 金融风控:
     用户特征降维 → 提升分类器性能
     信用评分的特征压缩
     
工程组合 (工业标准):
  PCA (去相关/去噪) → LDA (监督降维) → 分类器
  这是模式识别中的经典 Pipeline
```

> 💡 **洞见**：LDA 的精髓是——**它把"降维"和"分类"统一在同一个目标下**。无监督降维（PCA）只关心"数据长什么样"，LDA 关心的是"类别怎么分开"。这种"以分类性能为导向的降维"思想，在今天的深度学习中以"度量学习"（Metric Learning）的形式复活——对比损失（Contrastive Loss）、三元组损失（Triplet Loss）、ArcFace 等，本质都是在学一个"让同类靠近、异类远离"的嵌入空间，与 LDA 的目标完全一致。

### 17.2 充分降维（Sufficient Dimension Reduction, SDR）

**书中思路**：LDA 假设数据服从高斯分布且各类协方差相同。充分降维（SDR）放宽这些假设——它寻找一个投影矩阵 $B$，使得**投影后的数据 $B^{\mathsf T}X$ 对预测标签 $Y$ 是"充分的"**，即 $Y\perp X\mid B^{\mathsf T}X$。

**充分降维的定义**：

$$
Y\perp X\mid B^{\mathsf T}X
$$

含义：在给定投影 $B^{\mathsf T}X$ 的条件下，原始高维特征 $X$ 与标签 $Y$ 条件独立。即——**投影后的低维表示包含了预测 $Y$ 所需的全部信息**。

**切片逆回归（Sliced Inverse Regression, SIR）**​ ：

SIR 是 SDR 的经典方法（Li 1991）：

```
SIR 算法:
1. 将 Y 的取值范围分成 H 个切片 (slices) Y_h, h=1,...,H
2. 对每个切片, 计算 X 的条件均值: m_h = E[X | Y ∈ Y_h]
3. 计算这些均值向量的协方差矩阵:
   M = Cov(E[X | Y])
4. 对 M 做特征值分解
5. 取前 d 个最大特征值对应的特征向量组成 B
```

**🎯 第一性原理洞察：SIR = "逆回归" + 切片 + PCA**

```
传统回归:  X → Y  (用 X 预测 Y)
逆回归:    Y → X  (用 Y 的分组预测 X 的均值)
                ↓
          对 X 的条件均值做 PCA
                ↓
          主方向 = 充分降维方向 ★

为什么"逆回归"能找到降维方向?

直觉: 如果 X 的某个方向对预测 Y 很重要,
      那么当 Y 取不同值时, X 在这个方向上的均值会变化
      
反之: 如果 X 的某个方向对预测 Y 无关,
      那么无论 Y 取何值, X 在这个方向上的均值不变
      → 这个方向应该被"压缩掉"
```

**SIR 的几何示意**：

```
二维 X, 一维 Y:

   Y=高值区域:        Y=中值区域:        Y=低值区域:
    ●●                  ●●                  ●●
   ●  ●                ●  ●                ●  ●
    ●●                  ●●                  ●●
     ↑                    ↑                    ↑
   m_h (条件均值)       m_h                  m_h
     ↓                    ↓                    ↓
   三个均值点的分布方向 = 充分降维方向!
   
   → 对 {m_h} 做 PCA → 主方向 = SIR 方向
```

**SIR vs LDA vs PCA**​ ：

|维度|PCA|LDA|SIR (SDR)|
|---|---|---|---|
|标签使用|否|**是**​|**是**​|
|分布假设|无（仅二阶矩）|高斯 + 等协方差|**非参数（更弱假设）**​|
|目标|方差最大|类间/类内比最大|**Y ⊥ X \| BᵀX**​|
|适用 Y|无限制|类别标签|**任意 Y（连续/离散）**​|
|降维维数|任意|≤ C-1|任意|
|方法本质|协方差分解|广义特征值|逆回归 + 切片 + PCA|

**SIR 的扩展方法**​ ：

```
1. SAVE (Sliced Average Variance Estimation):
   不仅用条件均值 E[X|Y], 还用条件协方差 Cov(X|Y)
   → 能捕捉"方差随 Y 变化"的方向
   → 比 SIR 更强 (SIR 只捕捉均值变化)
   
2. DR (Directional Regression):
   结合 SIR 和 SAVE 的信息
   
3. Kernel SIR:
   核技巧 + SIR → 非线性充分降维
   
4. Contour Regression:
   基于条件分位数的充分降维
```

**🎯 深度洞见：充分降维 = "信息论视角"的降维**

```
充分降维的信息论解释:

Y ⊥ X | BᵀX  等价于  I(Y; X) = I(Y; BᵀX)

即: 投影后的低维表示 BᵀX 与 Y 的互信息
   等于原始 X 与 Y 的互信息
   
→ 降维没有损失任何与 Y 相关的信息!

这是"无损降维"的严格定义
(相对于 PCA 的"方差保留"、LDA 的"可分性保留")

SDR 回答了一个更根本的问题:
  "为了预测 Y, X 中哪些方向是必须的?"
```

**工业视角**：

```
充分降维的工业应用：

✓ 适用场景：
  - 高维特征 + 连续型/离散型标签
  - 不想假设高斯分布
  - 需要"信息无损"的降维
  - 特征选择 + 降维的结合
  
典型应用：
  1. 高维回归的特征降维：
     基因表达 (数万基因) → 预测疾病严重程度 (连续)
     SIR 找到与疾病相关的低维基因组合
     
  2. 金融风控：
     大量交易特征 → 预测违约概率 (连续)
     SDR 降维到关键风险因子
     
  3. 工业过程控制：
     大量传感器通道 → 预测产品质量指标
     SIR/SAVE 提取关键过程变量
     
  4. 环境科学：
     多个气象/环境指标 → 预测污染物浓度
     SDR 降维到核心环境因子
     
  5. 医学诊断：
     多模态医学特征 → 预测生存时间
     SDR 提取预后相关特征
     
挑战：
  - 切片数 H 的选择敏感
  - 样本量需足够大 (每个切片要有足够样本)
  - 大规模数据 (n > 10万) 时计算 SIR 矩阵需近似
  
现代发展：
  - 深度学习中的"信息瓶颈" (Information Bottleneck) 
    与 SDR 思想相通: 压缩 X 到对预测 Y 充分的表示
  - Variational AutoEncoder + 监督信号
    = 非线性版的充分降维
```

> 💡 **洞见**：充分降维（SDR）是降维思想的"终极形态"——它不问"数据方差多大"（PCA），也不问"类别是否分开"（LDA），而是问一个更根本的问题：**"为了预测 Y，X 中哪些方向是信息充分的？"**​ 这个问题的答案是信息论意义上的"无损降维"。
> 
> SDR 的思想在今天以"信息瓶颈"（Information Bottleneck）的形式在现代深度学习中复活——IB 原则要求中间表示 Z 在满足 I(Z;Y) 足够大的同时，使 I(Z;X) 尽可能小。这与 SDR 的 Y⊥X∣Z 本质相同。**理解 SDR，就是理解"表示学习"的信息论根基**。

## 第18章 迁移学习

### 18.1 协变量移位下的迁移学习（Covariate Shift Adaptation）

**书中问题定义**：训练数据（源域）和测试数据（目标域）的**输入分布不同**：$p_{\mathrm{tr}}(x)\ne p_{\mathrm{te}}(x)$，但**条件分布相同**：$p(y\mid x)$ 不变。

**协变量移位的典型场景**：

```
场景1: 情感分析
   训练: 书籍评论 (源域)
   测试: 电影评论 (目标域)
   → 用词分布不同, 但"正面/负面"的标注标准相同
   
场景2: 人群迁移
   训练: 年轻用户的行为数据
   测试: 老年用户的行为数据
   → 行为特征分布不同, 但"是否会购买"的规律相同
   
场景3: 时间漂移
   训练: 去年的交易数据
   测试: 今年的交易数据
   → 用户行为随时间演化 (概念漂移)
   
场景4: 传感器迁移
   训练: 实验室传感器数据
   测试: 现场传感器数据
   → 环境噪声导致分布偏移
```

**🎯 第一性原理洞察：协变量移位 = "输入分布变了，但规律没变"**

```
标准监督学习的假设:               协变量移位的现实:
   p_tr(x,y) = p_te(x,y)            p_tr(x) ≠ p_te(x)
   p_tr(x) = p_te(x)                p(y|x) 相同 ✓
   p(y|x) 相同                      但 p(x) 不同 ✗
   
   训练集和测试集独立同分布          训练集和测试集不同分布
   → 标准方法有效                    → 标准方法失效!
```

**重要性加权（Importance Weighting）方法**​ ：

核心思想：用权重 $w(x)=p_{\mathrm{te}}(x)/p_{\mathrm{tr}}(x)$ 对训练样本加权，使得**加权后的训练分布匹配测试分布**。

**加权经验风险最小化**：

$$
\min_\theta\frac{1}{n}\sum_{i=1}^{n}
\frac{p_{\mathrm{te}}(x_i)}{p_{\mathrm{tr}}(x_i)}
\,\ell\bigl(f_\theta(x_i),y_i\bigr)
$$

**密度比估计方法**（呼应第12.3节）：

$$
w(x)=\frac{p_{\mathrm{te}}(x)}{p_{\mathrm{tr}}(x)}
$$

用 uLSIF / KLIEP 等方法直接估计密度比（无需分别估计两个密度）。

**🎯 深度洞见：协变量移位适应的三种策略**

```
策略1: 重要性加权 (Importance Weighting)
   对每个训练样本加权 wᵢ = p_te(xᵢ)/p_tr(xᵢ)
   加权后的训练目标 ≈ 测试分布上的期望风险
   
   优势: 理论上保证加权风险收敛到测试风险
   挑战: wᵢ 可能极大 (密度比无界) → 高方差
         → 需要截断/归一化权重
         
策略2: 分布匹配 (Distribution Matching)
   直接学习一个特征表示, 使得源域和目标域的特征分布匹配
   例: MMD (最大均值差异) 最小化
   
策略3: 不变风险最小化 (Invariant Risk Minimization, IRM)
   寻找在所有环境下都不变的预测规则
   例: 在不同域上训练, 约束分类器在所有域上一致
```

**重要性加权的偏差-方差权衡**：

```
加权训练的偏差-方差分析:

   无加权 (naive):
     偏差大 (训练/测试分布不匹配)
     方差小 (用全部训练数据)
     
   重要性加权:
     偏差小 (分布匹配)
     方差大 (权重 wᵢ 可能极端)
     
   → 需要权衡: 截断权重 / 核均值匹配 / 域对抗训练
```

**ASCII 图示协变量移位适应**：

```
训练分布 p_tr(x):             测试分布 p_te(x):
   ● ● ● ●                       ○ ○ ○ ○
  ● ● ● ● ● ●                  ○ ○ ○ ○ ○ ○
   ● ● ● ●                       ○ ○ ○ ○
         ↑                                ↑
      大部分样本在这里                  测试样本在这里

重要性加权:
  训练样本 xᵢ 的权重 wᵢ = p_te(xᵢ)/p_tr(xᵢ)
  
  p_te(xᵢ) 大 + p_tr(xᵢ) 小 → wᵢ 大 (重要样本)
  p_te(xᵢ) 小 + p_tr(xᵢ) 大 → wᵢ 小 (不重要样本)
  
  → 加权后, 训练样本的"有效分布" ≈ 测试分布
```

**核均值匹配（Kernel Mean Matching, KMM）**​ ：

```
KMM: 在 RKHS 中匹配均值嵌入

目标: 找权重 βᵢ 使得
  ‖ Σᵢ βᵢ φ(xᵢ) - (1/m) Σⱼ φ(x̃ⱼ) ‖² 最小
  
其中 x̃ⱼ 是测试样本, φ 是特征映射

这等价于在 RKHS 中匹配源域和目标域的均值嵌入
→ 分布匹配的一种核方法实现
```

**工业视角**：

```
协变量移位适应的工业应用：

✓ 高频场景 (工业界最痛的需求之一):

1. 推荐系统:
   用户兴趣随时间漂移 (seasonal shift)
   → 用重要性加权适配当前分布
   
2. 广告 CTR 预估:
   训练数据是历史日志 (有偏: 只记录了展示过的广告)
   测试时需要预测所有候选广告
   → 协变量移位: 展示分布 ≠ 候选分布
   → 重要性加权 / 逆倾向得分 (IPS) 校正选择偏差
   
3. 金融风控:
   经济周期变化 → 用户行为分布漂移
   用去年模型预测今年 → 需要协变量移位适应
   
4. 医疗 AI:
   训练: 某医院数据
   部署: 另一医院 (不同人群/设备)
   → 域适应 (Domain Adaptation)
   
5. 自然语言处理:
   预训练语料 (Wikipedia) vs 下游任务 (Twitter)
   → 领域自适应 (Domain Adaptation)
   → 今天用 LLM + 微调实现
   
6. 计算机视觉:
   合成数据训练 → 真实数据测试 (Sim-to-Real)
   → 域随机化 + 域适应
   
工程方法选型:
  小数据 + 密度比可估 → 重要性加权 (uLSIF/KLIEP)
  大数据 + 深度学习 → 域对抗训练 (DANN)
  特征空间匹配 → MMD / CORAL
  现代统一框架 → 分布鲁棒优化 (DRO)
```

> 💡 **洞见**：协变量移位适应解决的是机器学习从"实验室"到"生产线"的最后一公里问题。**实验室里模型准确率 95%，上线后跌到 70%**——这往往不是模型的问题，而是训练/测试分布不一致。重要性加权是最直接的理论解法，但在深度学习中，更常用的是**域对抗训练（Domain Adversarial Neural Networks）**和**分布鲁棒优化（DRO）**——它们把协变量移位适应的思想融入了神经网络的训练过程。

### 18.2 类别平衡变化下的迁移学习（Class-Balance Shift）

**书中问题定义**：不仅输入分布变化，而且**类别先验概率也变化**：$p_{\mathrm{tr}}(y)\ne p_{\mathrm{te}}(y)$，但 $p(x\mid y)$ 不变（即各类别的条件分布不变）。

**典型场景**：

```
场景1: 欺诈检测
   训练: 历史数据, 欺诈率 ~0.1% (高度不平衡)
   测试: 某时段欺诈率突然升至 5% (分布突变)
   → 类别先验变了, 但"欺诈样本长什么样"没变
   
场景2: 罕见疾病诊断
   训练: 通用人群 (患病率 1%)
   测试: 高危人群 (患病率 15%)
   → 需要重新校准预测概率
   
场景3: 舆情监控
   训练: 日常评论 (负面率 ~5%)
   测试: 危机事件期间 (负面率 ~40%)
   → 类别平衡突变
```

**🎯 第一性原理洞察：类别平衡变化 = "先验变了，似然没变"**

```
贝叶斯视角:
   p(y|x) = p(x|y)·p(y) / p(x)
   
   类别平衡变化: p(y) 改变
   → 后验 p(y|x) 改变 (即使 p(x|y) 不变)
   
   例: p(y=1|x) = p(x|y=1)·p(y=1) / p(x)
       p(y=1) 从 0.01 → 0.15
       → 即使 p(x|y=1) 不变, p(y=1|x) 也会大幅上升
```

**先验概率校正方法**​ ：

```
方法1: 后验概率重新加权
   已知: p_tr(y) 和 p_te(y) (目标域的类别比例)
   
   对训练得到的 p_tr(y|x), 用贝叶斯定理校正:
   
   p_te(y|x) ∝ p(x|y) · p_te(y)
              = p_tr(y|x) · p_te(y) / p_tr(y)
   
   校正因子: w_y = p_te(y) / p_tr(y)
   
   → 对每个类别应用不同的校正权重

方法2: 决策阈值调整
   不改变模型输出, 只调整分类阈值
   正类比例从 1% → 15% → 降低分类阈值

方法3: 代价敏感学习
   为不同类别设置不同的误分类代价
   少数类错误代价 ↑ → 模型偏向少数类
```

**ASCII 图示类别平衡变化的影响**：

```
训练时 (类别平衡 p(y=1)=0.5):
   决策边界: wᵀx + b = 0 (b 基于均衡先验)
   
   类别0 ● ● ● │ ○ ○ ○
          ● ● ●│ ○ ○ ○
          ● ● ●│ ○ ○ ○
                 ↑
               b = 0 (对称)

测试时 (类别不平衡 p(y=1)=0.9):
   若仍用 b=0 → 大量正类被误分为负类
   
   校正: 调整偏置 b → b' = b + log(p_te(y=1)/p_tr(y=1))
   
   类别0 ● ● ● │ ○ ○ ○
          ● ● ●│ ○ ○ ○
          ● ● ●│ ○ ○ ○
               ↑
            b' < 0 (向负类偏移)
            决策边界向负类偏移 → 更多样本判为正类
```

**与代价敏感学习的联系**​ ：

```
类别不平衡 → 代价敏感学习

设代价矩阵 C(y, ŷ):
   C(0,1) = 假正例代价 (如 1)
   C(1,0) = 假负例代价 (如 10, 因为少数类更重要)
   
最小化期望代价:
   min E[C(y, ŷ)]
   
等价于调整分类阈值:
   ŷ = 1  if p(y=1|x) > C(0,1)/(C(0,1)+C(1,0))
   
例: C(1,0)=10, C(0,1)=1
   → 阈值 = 1/11 ≈ 0.09 (远低于 0.5!)
```

**类别平衡变化 vs 协变量移位**​ ：

|维度|协变量移位 (18.1)|类别平衡变化 (18.2)|
|---|---|---|
|变化的量|p(x)|p(y)|
|不变的量|p(y\|x)|p(x\|y)|
|核心方法|重要性加权 w(x)=p_te(x)/p_tr(x)|**先验校正 w_y=p_te(y)/p_tr(y)**​|
|是否需要目标域标签|否（无监督域适应）|**是（需要知道 p_te(y)）**​|
|工业场景|域适应、时间漂移|**类别不平衡、先验漂移**​|

**🎯 深度洞见：类别平衡变化的"隐式假设"问题**

```
关键问题: 如何知道 p_te(y)?

情况A: 知道目标域的类别比例
  → 直接应用先验校正
  → 例: 已知欺诈率从 0.1% 升至 5%
  
情况B: 不知道目标域的类别比例
  → 需要估计 p_te(y)
  → 方法: EM 算法 / 标签传播 / 主动学习
  
情况C: 完全无目标域信息
  → 无法做精确的类别平衡适应
  → 只能用代价敏感学习 (设置代价比例)
  → 或训练时对少数类过采样 (SMOTE)
```

**工业视角**：

```
类别平衡变化的工业应用：

✓ 高频痛点场景:

1. 欺诈检测:
   欺诈率随时间段剧烈波动
   → 监控欺诈率 → 动态调整阈值/先验
   
2. 信用评分:
   经济下行期违约率上升
   → 用宏观指标估计当前违约率
   → 校正模型先验
   
3. 罕见事件预测:
   设备故障 (年故障率 < 1%)
   → 训练时对故障样本过采样
   → 或代价敏感学习 (故障漏检代价极高)
   
4. A/B 测试中的异常检测:
   实验组/对照组的异常率不同
   → 先验校正
   
5. 医疗筛查:
   不同人群患病率不同
   → 按人群调整筛查阈值
   
工程最佳实践:
  - 监控生产环境的类别比例变化
  - 设置自动阈值调整机制
  - 代价敏感学习 + 业务代价矩阵
  - 训练时对少数类过采样 (SMOTE/ADASYN)
  - 对少数类使用 Focal Loss (深度学习)
  
工业案例:
  信用卡欺诈检测:
    历史欺诈率: 0.1%
    某日欺诈率突增至: 3%
    
    方案A: 重要性加权 (若知道哪些样本是欺诈)
    方案B: 先验校正 b' = b + log(3%/0.1%) = b + log(30)
    方案C: 代价敏感 (漏检欺诈代价设为正常的 30 倍)
    
    实际: 方案B+C 结合, 同时监控模型精度/召回
```

> 💡 **洞见**：类别平衡变化揭示了机器学习中一个常被忽视的真相——**模型输出的概率校准依赖于训练数据的类别分布**。当部署环境的类别比例与训练数据不同时，模型的输出概率会系统性偏移。这不是模型"错了"，而是先验变了。理解这一点，你就能理解为什么工业界需要在模型上线后持续监控类别分布、动态调整阈值——**模型的"静态训练"和"动态部署"之间，始终需要一座"分布适配"的桥梁**。

## 第19章 多任务学习

### 19.1 使用最小二乘回归的多任务学习

**书中思路**：不是为单个任务训练单个模型，而是**同时学习多个相关任务**，让任务之间共享表示、互相正则化。

**问题设定**：有 $T$ 个相关任务，每个任务 $t$ 有自己的训练数据 $\{(x_{t,i},y_{t,i})\}_{i=1}^{n_t}$。

**多任务最小二乘的目标函数**：

$$
\min_{\Theta}\ 
\sum_{t=1}^{T}\frac{1}{n_t}\sum_{i=1}^{n_t}
\left\lVert f_{\theta_t}(x_{t,i})-y_{t,i}\right\rVert_2^2
+\lambda R(\Theta)
$$

其中 $\Theta=[\theta_1,\theta_2,\ldots,\theta_T]$ 是所有任务的参数矩阵，$R(\Theta)$ 是跨任务正则化项。

**常见的跨任务正则化**​ ：

```
1. 低秩约束 (Low-rank):
   R(Θ) = ‖Θ‖_*  (核范数, 秩的凸松弛)
   → 假设所有任务的参数矩阵是低秩的
   → 任务间共享一个低维子空间
   
2. 组 Lasso (Group Lasso):
   R(Θ) = Σⱼ √(Σₜ θ_{t,j}²)
   → 对"特征 j 在所有任务上的系数"做组稀疏
   → 同时选择对全部任务都有用的特征
   
3. L2,1 范数:
   R(Θ) = Σⱼ ‖Θ_{:,j}‖₂
   → 特征级联合稀疏
   
4. 任务聚类 (Task Clustering):
   假设任务分为若干簇, 簇内任务共享参数
```

**🎯 第一性原理洞察：多任务学习 = "任务间的归纳迁移"**

```
单任务学习:                    多任务学习:

   Task 1: X → y₁                Task 1: X → y₁ ↘
                                  Task 2: X → y₂  → 共享表示/参数
                                  Task 3: X → y₃  ↗
                                  ...
                                  Task T: X → y_T
                                  
   每个任务独立学习                 所有任务联合学习
   → 数据利用率低                  → 数据利用率高
   → 无法利用任务间相关性           → 任务间互相正则化
   → 小数据任务容易过拟合          → 小数据任务受益于相关大数据任务
```

**低秩假设的信息论解释**：

```
低秩参数矩阵 Θ (d × T):

   特征维度 d
   │
   │  θ₁  θ₂  θ₃ ... θ_T   ← T 个任务
   │  ┌─────────────────┐
   │  │                 │
   │  │   低秩矩阵       │  ← rank(Θ) = r << min(d,T)
   │  │                 │
   │  └─────────────────┘
   │
   └──────────────────────→
   
   低秩含义: 所有任务的参数向量 θₜ 都落在同一个 r 维子空间中
   → 任务间共享 r 个"基础方向"
   → 每个任务 = 这些基础方向的线性组合
   
   类比 PCA:
   PCA: 样本共享低维子空间 (数据降维)
   多任务低秩: 任务参数共享低维子空间 (参数降维)
```

**多任务学习的三种信息共享方式**​ ：

```
方式1: 参数共享 (Hard Sharing)
   所有任务共享底层参数, 顶层任务特定
   深度学习中的标准多任务架构
   
方式2: 参数约束 (Soft Sharing) ★ 本章方法
   任务参数独立但加约束 (低秩/组稀疏)
   → 灵活, 任务可以有自己的参数
   → 约束促进信息共享
   
方式3: 任务关系学习 (Task Relation Learning)
   学习任务间的相似度图/聚类
   → 相似任务共享更多, 不相似任务独立
   → 更灵活但更复杂
```

**工业视角**：

```
多任务学习的工业应用：

✓ 适用场景：
  - 多个相关任务需要同时建模
  - 部分任务数据少 (借相关任务的数据增强)
  - 任务间存在共享的底层结构
  
典型应用：
  1. 推荐系统：
     同时预测点击率 (CTR) + 转化率 (CVR) + 停留时长
     三个任务共享用户/物品表示, 但各有特定输出层
     
  2. 计算机视觉：
     同时检测 + 分类 + 分割
     (目标检测中的多任务损失)
     
  3. 自然语言处理：
     多语言 NLP: 多种语言共享表示
     多任务 NLP: 命名实体 + 词性 + 句法 联合学习
     
  4. 医疗：
     同时预测多种疾病风险
     多病种联合建模
     
  5. 自动驾驶：
     同时预测转向角 + 速度 + 车道偏离
     
  6. 金融：
     同时预测多只相关股票的收益率
     → 低秩约束捕捉共同因子
     
工程优势：
  ✓ 数据共享 → 小数据任务受益
  ✓ 正则化 → 减少过拟合
  ✓ 效率 → 一次训练多个模型
  ✓ 表示学习 → 学到更好的通用特征
  
挑战：
  ✗ 任务间负相关时 ("负迁移") 反而有害
  ✗ 需要 careful 的任务权重平衡
  ✗ 大规模多任务需分布式训练
```

> 💡 **洞见**：多任务学习的精髓是——**让相关任务互相"教"对方**。每个任务都是其他任务的正则化项，因为共享参数迫使模型学到对所有任务都有用的表示。这种"任务间的归纳迁移"思想，在今天的深度学习中以"多任务深度网络"（共享底层 + 任务特定顶层）的形式成为标准范式。低秩约束则揭示了任务间共享的本质——**所有任务的参数都落在同一个低维子空间中**。

### 19.2 使用最小二乘概率分类器的多任务学习

**书中思路**：将 19.1 的多任务最小二乘回归推广到**分类任务**——每个任务是一个二分类问题，使用最小二乘概率分类器（第10.2节）建模。

**多任务分类的目标函数**：

$$
\min_{\Theta}\ 
\sum_{t=1}^{T}\frac{1}{n_t}\sum_{i=1}^{n_t}
\bigl(f_{\theta_t}(x_{t,i})-y_{t,i}\bigr)^2
+\lambda R(\Theta)
$$

其中 $y_{t,i}\in\{0,1\}$ 是二分类标签，$f_{\theta_t}(x)$ 输出概率估计。

**与 19.1 的区别**：

```
19.1 多任务回归:  y ∈ ℝ (连续)
19.2 多任务分类:  y ∈ {0, 1} (离散)
                  f(x) 输出概率 ∈ [0, 1]
                  需裁剪到 [0, 1] 区间
```

**🎯 第一性原理洞察：多任务分类 = "共享表示 + 任务特定校准"**

```
多任务分类的架构 (深度学习版本):

   输入 x
     ↓
   ┌─────────┐
   │ 共享底层 │ ← 所有任务共享的特征提取器
   │ (编码器) │
   └────┬────┘
        ↓
   ┌────┴────┐
   ↓    ↓    ↓    ↓
 头₁   头₂   头₃ ... 头_T   ← 每个任务一个输出头
 (CTR) (CVR) (时长)  (...)
   ↓    ↓    ↓    ↓
  p₁    p₂    p₃    p_T
  
  共享底层 = 跨任务正则化的深度学习实现
  任务头 = 任务特定参数
```

**概率校准在多任务中的重要性**：

```
多任务输出概率的校准问题:

  每个任务的类别比例可能不同
  → 任务 t 的输出概率 p_t 需要独立校准
  
  方法:
  - Platt Scaling (每个任务独立拟合一个 Sigmoid)
  - Isotonic Regression (非参数校准)
  - 温度缩放 (Temperature Scaling)
  
  多任务校准 = 每个任务单独校准 + 共享表示
```

**工业视角**：

```
多任务分类的工业应用：

1. 推荐系统的多目标预估:
   CTR (点击率) + CVR (转化率) + 完播率 + 点赞率
   → 多任务模型 (如 MMoE, PLE)
   → 阿里巴巴的 ESMM (Entire Space Multi-Task Model)
   
2. 内容审核:
   同时预测: 色情 / 暴力 / 政治敏感 / 广告
   → 多标签多任务分类
   
3. 医疗诊断:
   多种疾病的风险概率联合预测
   → 疾病间有相关性 (如糖尿病↔肾病)
   → 多任务学习利用这种相关性
   
4. 金融风控:
   同时预测: 违约 / 欺诈 / 套现
   → 三种风险模式相关但不相同
   
工程趋势:
  深度学习时代的多任务架构:
  - Hard Sharing (共享底层)
  - MMoE (Multi-gate Mixture of Experts)
  - PLE (Progressive Layered Extraction)
  - 这些架构本质是 19.2 思想的深度化实现
```

> 💡 **洞见**：多任务分类在工业界最核心的应用是**推荐系统的多目标预估**。用户的一个行为（看到一条内容）会触发多个信号——点击/不点击、观看时长、点赞/评论/分享、是否转化。把这些信号作为多个相关任务联合学习，比单独为每个信号训练一个模型效果更好。**这正是第19章思想在今日工业界最具影响力的落地场景**。

### 19.3 多次维输出函数的学习（Multi-dimensional Output Learning）

**书中思路**：不仅输出是多维的（多个任务），而且**输入到输出的映射本身是高维的**——学习一个向量值函数 $f:\mathbb{R}^{D}\to\mathbb{R}^{T}$。

**问题设定**：$f(x)=\Theta^{\mathsf T}\phi(x)$，其中 $\Theta$ 是 $d\times T$ 的参数矩阵，$f(x)$ 是 $T$ 维输出向量。

**目标函数**：

$$
\min_{\Theta}\ 
\sum_{i=1}^{n}\lVert f(x_i)-y_i\rVert_2^2+\lambda R(\Theta)
$$

其中 $y_i\in\mathbb{R}^{T}$ 是 $T$ 维标签向量。

**🎯 第一性原理洞察：多维输出 = "一个模型输出 T 个值"**

```
单输出回归:               多输出回归:
   f: ℝᴰ → ℝ                f: ℝᴰ → ℝᵀ
   θ ∈ ℝᵈ                   Θ ∈ ℝᵈˣᵀ
   
   一个标量输出               T 个输出 (T 个任务/目标)
   
   例: 预测房价              例: 预测 [房价, 面积, 房龄]
        (1维输出)                  (3维输出)
```

**低秩约束在多输出学习中的核心作用**​ ：

```
不加约束: Θ ∈ ℝᵈˣᵀ, 参数数 = d·T
   → 当 T 很大时参数爆炸
   → 容易过拟合
   
加低秩约束: rank(Θ) ≤ r << min(d,T)
   → 参数数 ≈ r·(d+T)  (大幅减少)
   → 正则化效果
   → 假设输出维度间存在共享结构
   
   分解: Θ = U·Vᵀ  (U ∈ ℝᵈˣʳ, V ∈ ℝᵀˣʳ)
   → U: 输入特征的低秩表示
   → V: 输出维度的低秩表示
   → f(x) = V·(Uᵀφ(x))
```

**ASCII 图示低秩多输出模型**：

```
输入 φ(x) ∈ ℝᵈ              输出 f(x) ∈ ℝᵀ
     │                            ↑
     ↓                            │
   ┌────┐                       ┌────┐
   │ Uᵀ │  → ℝʳ (r维瓶颈) →   │ V  │
   └────┘                       └────┘
     ↑                            ↑
   输入投影                     输出展开
   (d → r)                     (r → T)
   
   Θ = U·Vᵀ  (低秩分解)
   
   这本质上是一个"瓶颈网络" (Bottleneck Network)!
   与自编码器的中间层结构完全相同
```

**与多任务学习的关系**：

```
19.1 多任务回归:   多个任务, 各自有独立数据
                    → 任务间通过参数约束共享信息
                    
19.3 多维输出:     单个样本有 T 维标签
                    → 所有样本共享同一个多输出模型
                    → 低秩约束 = 假设输出维度间有共享结构
                    
两者统一: 都是学 Θ ∈ ℝᵈˣᵀ, 都用低秩/正则化促进任务间共享
```

**多输出学习的典型方法对比**​ ：

|方法|约束/正则化|假设|适用场景|
|---|---|---|---|
|独立任务|无（每任务独立）|任务间无关|任务确实独立|
|低秩|$\operatorname{rank}(\Theta)\le r$|输出共享 $r$ 维子空间|**任务/输出相关**|
|组 Lasso|$\lVert\Theta_{:,j}\rVert_2$ 惩罚|特征级联合稀疏|共同特征选择|
|图正则化|$\Theta^{\mathsf T}L\Theta$ 惩罚|任务在图上平滑|任务有图结构|
|核方法|多输出核|RKHS 中的多输出|非线性多输出|

**🎯 深度洞见：多维输出学习 = "表示学习的雏形"**

```
低秩多输出模型的深层含义:

f(x) = V · (Uᵀφ(x))

Uᵀφ(x) ∈ ℝʳ 是输入的低秩表示 (瓶颈特征)
V 将这个瓶颈特征映射到 T 维输出

这本质上就是:
  自编码器: x → 瓶颈 → 重建 x
  多输出回归: x → 瓶颈 → 预测 y₁, y₂, ..., y_T
  
瓶颈维度 r 控制了:
  - 模型容量 (r 大 → 容量大)
  - 任务间共享程度 (r 小 → 强制共享)
  - 过拟合风险 (r 小 → 正则化强)
```

**工业视角**：

```
多维输出学习的工业应用：

1. 多变量时间序列预测:
   预测未来 T 个时间步的值
   → 低秩约束捕捉时间步间的相关性
   
2. 多目标优化:
   同时预测多个相关指标
   → 如: 预测股票的 [开盘价, 最高价, 最低价, 收盘价]
   
3. 图像/视频分析:
   一张图像 → 多个属性标签 (多标签分类)
   → 低秩约束假设属性间有共享结构
   
4. 推荐系统:
   一个用户 → 对多个物品的评分预测 (矩阵补全)
   → 低秩矩阵分解 = 协同过滤的核心!
   
5. 生物信息学:
   基因表达 → 多个表型指标的预测
   → 低秩假设: 少数潜在因子驱动多个表型
   
6. 信号处理:
   多通道传感器 → 多维输出
   → 低秩假设: 信号共享少量源信号
   
工业趋势:
  深度学习中的多输出:
  - 多任务 CNN: 一个 backbone + 多个输出头
  - 序列到序列 (Seq2Seq): 多维输出 (T 个时间步)
  - Transformer: 多维输出 (词汇表上的分布)
  
  这些现代架构都可以视为"非线性低秩多输出模型"
```

> 💡 **洞见**：多维输出学习的低秩约束，揭示了机器学习中一个深刻的结构——**当多个输出/任务相关时，它们共享一个低维的"隐因子"结构**。这个思想在推荐系统中以"矩阵分解"（协同过滤）的形式成为工业标准，在自然语言处理中以"词向量/上下文向量"的形式成为 Transformer 的基石。**理解低秩多输出模型，就是理解"嵌入"（Embedding）这一现代机器学习最核心概念的线性版本**。
