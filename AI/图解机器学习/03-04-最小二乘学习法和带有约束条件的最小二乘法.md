
# 《图解机器学习》读书笔记（第3章·第4章）

> 这两章是整本书的"发动机"——第1章定义了学什么，第2章定义了用什么模型，而第3、4章回答的是**怎么让模型从数据里真正学到参数**。
> 
> 杉山将在这里展现了他作为统计机器学习学者的核心洞见：**最小二乘法不是"一种算法"，而是一种"设计哲学"**——把学习问题转化为"在约束条件下的最优化问题"。第3章是无约束版，第4章是约束版，两章合起来构成了后续所有正则化方法的原型。

## 第3章 最小二乘学习法

### 3.1 最小二乘学习法

**书中定义**：对模型的**均方误差**进行最小化时的参数 θ 学习方法。

目标函数：

$$
J_{\mathrm{LS}}(\theta)=\frac{1}{2n}\sum_{i=1}^{n}\bigl(f_\theta(x_i)-y_i\bigr)^2
$$

由于平方误差是残差 ∣fθ​(xi​)−yi​∣ 的 **L2 范数**，最小二乘法也称 **L2 损失最小化学习法**。

**线性模型下的最小二乘**：

设 $f_\theta(x)=\sum_{j=1}^{b}\theta_j\phi_j(x)=\theta^{\mathsf T}\phi(x)$，设计矩阵 $\Phi$ 为 $n\times b$ 阶：

$$
\Phi=
\begin{bmatrix}
\phi_1(x_1) & \cdots & \phi_b(x_1)\\
\vdots & \ddots & \vdots\\
\phi_1(x_n) & \cdots & \phi_b(x_n)
\end{bmatrix}
$$

对 θ 求偏导并令其为 0：

$$
\nabla_\theta J_{\mathrm{LS}}=\Phi^{\mathsf T}\Phi\theta-\Phi^{\mathsf T}y=0
$$

得到**正规方程（Normal Equation）**：

$$
\hat{\theta}_{\mathrm{LS}}=(\Phi^{\mathsf T}\Phi)^{-1}\Phi^{\mathsf T}y
$$

当 $\Phi^{\mathsf T}\Phi$ 不可逆时，引入**广义逆矩阵（Moore--Penrose pseudoinverse）** $\Phi^\dagger=(\Phi^{\mathsf T}\Phi)^{-1}\Phi^{\mathsf T}$，则：

$$
\hat{\theta}_{\mathrm{LS}}=\Phi^\dagger y
$$

**核模型下的最小二乘**：将设计矩阵 Φ 替换为核矩阵 K：

$$
K=
\begin{bmatrix}
K(x_1,x_1) & \cdots & K(x_1,x_n)\\
\vdots & \ddots & \vdots\\
K(x_n,x_1) & \cdots & K(x_n,x_n)
\end{bmatrix}
$$

**加权最小二乘**：对不同样本赋予权重 $w_i$：

$$
\min_\theta\frac{1}{2n}\sum_{i=1}^{n}w_i\bigl(f_\theta(x_i)-y_i\bigr)^2
$$

**🎯 第一性原理洞察**

最小二乘的本质，是**几何空间中的正交投影**：

```
y (观测值向量, 位于ℝⁿ空间)
    │
    │  ╱  residual (残差)
    │ ╱   (与R(Φ)垂直)
    │╱
    ├───━━━━━━━━━━━━━━━━━ R(Φ)  ← Φ的值域(模型可表达的空间)
    │   \  
    │    \  Φθ̂_LS (预测值, y在R(Φ)上的投影)
    │     \
    └──────┴──────────────────
```

**最小二乘解 = 把观测向量 $y$ 正交投影到模型空间 $R(\Phi)$ 上**。残差向量 $y-\Phi\hat{\theta}_{\mathrm{LS}}$ 与 $R(\Phi)$ 垂直——这就是"最小"二字在数学上的精确含义：在模型所能表达的所有预测中，最小二乘解给出的预测是**欧氏距离上离 $y$ 最近的那个**。

> 💡 **洞见**：这个几何视角揭示了一个反直觉的事实——**最小二乘不在乎你的模型"长什么样"，只在乎模型的"表达空间" $R(\Phi)$ 是什么形状**。线性模型、多项式模型、核模型，只要它们的 $R(\Phi)$ 相同，最小二乘解就完全相同。

**为什么是"平方"而不是"绝对值"或"四次"？**

|损失函数|名称|特性|
|---|---|---|
|$\\lVert r\\rVert_1$|L1 损失|鲁棒，但对推导不友好|
|**$\\lVert r\\rVert_2^2$**|**L2 损失（最小二乘）**|**可导、凸、有闭式解**|
|$\\lVert r\\rVert_4^4$|四次损失|对离群值敏感|

平方损失的两个核心优势：**(1) 目标函数是参数的二次函数，凸且可导；(2) 存在闭式解**——这是最小二乘在 200 多年里（从高斯 1809 年算起）长盛不衰的根本原因。

**工业视角**：

- 最小二乘是**所有线性回归、岭回归、Lasso、Elastic Net 的共同祖先**
- 工业级线性回归库（如 scikit-learn 的 `LinearRegression`）底层就是用正规方程或 QR/SVD 分解求解
- 加权最小二乘在**样本可信度不均**的场景极有价值：比如点击率预测中，高频用户的样本权重应高于低频用户

### 3.2 最小二乘解的性质

**书中推导**：对设计矩阵 Φ 做**奇异值分解（SVD）**：

$$
\Phi=\sum_{k=1}^{\min(n,b)}\kappa_k\,\psi_k\phi_k^{\mathsf T}
$$

其中 $\kappa_k$ 是奇异值，$\psi_k$、$\phi_k$ 分别是左右奇异向量，均满足正交性。

广义逆矩阵可表示为：

$$
\Phi^\dagger=\sum_{k=1}^{\min(n,b)}\kappa_k^\dagger\,\psi_k\phi_k^{\mathsf T}
$$

其中 $\kappa_k^\dagger=\frac{1}{\kappa_k}$（当 $\kappa_k\ne 0$）。

最小二乘解由此可写成：

$$
\hat{\theta}_{\mathrm{LS}}=
\sum_{k=1}^{\min(n,b)}
\kappa_k^\dagger(\psi_k^{\mathsf T}y)\phi_k
$$

**关键性质**：

1. **正交投影性**：$\Phi\Phi^\dagger$ 是到 $R(\Phi)$ 的正交投影矩阵，最小二乘输出 $\Phi\hat{\theta}_{\mathrm{LS}}$ 是 $y$ 在 $R(\Phi)$ 上的正交投影
2. **无偏性**：当噪声期望为 $0$ 时，$\hat{\theta}_{\mathrm{LS}}$ 是真实参数的无偏估计
3. **渐近性**：随着训练样本数 $n$ 增加，$\hat{\theta}_{\mathrm{LS}}$ 向最优参数收敛

**🎯 第一性原理洞察**

SVD 视角揭示了最小二乘解最深刻的性质——**解的稳定性由奇异值谱决定**：

```
奇异值谱与解的稳定性：

κ₁ ━━━━━━━━━━━━ 大奇异值 → 对应方向稳定，信号强
κ₂ ━━━━━━       中奇异值 → 对应方向较稳定
κ₃ ━━           小奇异值 → 对应方向不稳定
κ₄ ━             极小奇异值 → 噪声被放大 1/κ₄ 倍！
κ₅ ━             接零奇异值 → 1/κ₅ → ∞，解爆炸
```

**这就是为什么多重共线性（multicollinearity）会毁掉最小二乘**：

当特征间高度相关时，设计矩阵 $\Phi$ 的某些奇异值趋近于 $0$。在求解 $\hat{\theta}=\Phi^\dagger y$ 时，这些小奇异值的倒数 $1/\kappa_k$ 会**巨大化**，把观测噪声无限放大到参数估计中——表现为系数剧烈震荡、符号翻转、对训练数据微小变化极度敏感。

**工业视角**：

这个性质直接解释了工业界的三个常见现象：

1. **为什么高维稀疏特征不能直接上最小二乘**：推荐系统的 one-hot 特征维度可达亿级，且绝大多数特征高度共线，直接最小二乘必炸
2. **为什么需要做特征标准化**：标准化让设计矩阵的奇异值谱更"均匀"，条件数（condition number $=\kappa_{\max}/\kappa_{\min}$）更小，数值稳定性更好
3. **为什么深度学习中 Batch Norm / Layer Norm 如此有效**：本质上是在做"隐层的特征去共线性"，改善该层的奇异值谱

> ⚠️ **实践法则**：动手跑最小二乘前，先看条件数。条件数 > 10³ 就要警惕，> 10⁶ 基本不可用，必须转向带正则的方法（即第4章的内容）。

### 3.3 大规模数据的学习算法

**书中指出**：一般线性模型的目标函数是凸函数，因此通过梯度法可以得到全局最优解。但**批量最小二乘**在大规模数据下有两个致命瓶颈：

1. **求逆成本**：$(\Phi^{\mathsf T}\Phi)^{-1}$ 的计算复杂度是 $O(b^3)$，当特征数 $b$ 很大时不可接受
2. **内存瓶颈**：需要一次性加载全部数据到内存

**大规模场景下的解法**：

**随机梯度下降（SGD）/ 最小均方（LMS）算法**：

$$
\theta_{t+1}=\theta_t-2\eta\bigl(\langle x_i,\theta_t\rangle-y_i\bigr)x_i
$$

其中 t 是迭代次数，η 是学习率。

**🎯 第一性原理洞察**

这一节其实是**"解析解 vs 迭代解"的范式分水岭**：

```
小规模数据 (b < 10⁴):
  批量最小二乘 → 闭式解 → 一步到位，精确最优
       ↓
大规模数据 (b ≥ 10⁴) 或 在线流式数据:
  随机梯度下降 → 迭代解 → 逐步逼近，可扩展
```

**为什么 SGD 能在大规模下胜出？**

|维度|批量最小二乘|随机梯度下降|
|---|---|---|
|单次迭代复杂度|O(n·b²)|O(b)|
|是否需要全量数据|是|否（单样本即可）|
|内存占用|O(n·b)|O(b)|
|收敛性|一步到位|渐进收敛|
|适用规模|n·b < 10⁶|无限扩展|

**深度洞见**：SGD 不仅是"近似解法"，它在工业界大规模机器学习中**甚至是更优的解法**——

1. **正则化效果**：SGD 的迭代过程天然带有"早停（early stopping）"的正则化效应，相当于隐式地做了 L2 正则化
2. **在线学习能力**：流式数据（如实时推荐、在线广告）根本无法用批量方法，只能用 SGD 类的 online 算法
3. **大规模深度学习的唯一选择**：今天所有的深度学习训练，本质都是 SGD 或其变种（Adam、RMSProp 等）

**工业视角**：

```
工业级大规模最小二乘的实践路径：

< 1万特征:       直接正规方程 (numpy.linalg.lstsq)
1万~100万特征:   SGDRegressor / FTRL (在线学习)
> 100万特征:     分布式 SGD (Parameter Server, Ring AllReduce)
流式数据:         Online SGD / FTRL (Google 广告的标配)
```

> 💡 **工业案例**：Google 的 FTRL（Follow-The-Regularized-Leader）算法，正是 SGD 在大规模稀疏特征上的工程化版本，支撑了 Google 广告的实时竞价系统。其核心思想——**SGD 的迭代更新 + L1/L2 正则化的近端梯度**——恰好是本书第3章（最小二乘）+ 第4章（约束）的工业结晶。

## 第4章 带有约束条件的最小二乘法

> 第3章告诉我们最小二乘"能算"，但没告诉我们"算出来的东西好不好用"。当特征共线、维度爆炸、数据有噪声时，无约束最小二乘会过拟合。第4章的核心思想：**给参数 θ 施加约束，用"偏差"换"方差"的下降**——这是机器学习最深刻的权衡之一。

### 4.1 部分空间约束的最小二乘学习法

**书中思路**：不对全部参数空间进行无约束优化，而是**约束参数只能在某个子空间内取值**。

直观理解：

```
无约束最小二乘:
  θ ∈ ℝ^b  (全空间自由搜索)

部分空间约束:
  θ ∈ span{φ₁, φ₂, ..., φ_k}  (k < b, 限制在低维子空间)
```

**🎯 第一性原理洞察**

这一节的本质是**对参数空间做"降秩约束"**：

```
全参数空间 ℝᵇ:
  ┌─────────────────────────────┐
  │  ● ← 无约束最小二乘解         │
  │                             │
  │    ▽ ← 约束解 (投影到子空间)  │
  │   ┌───────────────────────┐ │
  │   │ 允许的 k 维子空间       │ │
  │   └───────────────────────┘ │
  └─────────────────────────────┘
```

**部分空间约束 = 在子空间上再做一次投影**。它在数学上等价于：

1. **PCA 回归（Principal Component Regression）**：只用前 k 个主成分方向
2. **特征选择后的回归**：只允许某些特征的系数非零
3. **低秩矩阵约束**：参数矩阵 $\operatorname{rank}\le k$

**为什么要做部分空间约束？**

- **降方差**：限制参数在 k 维子空间内，等价于把 b-k 个"高方差方向"强行置零
- **抗过拟合**：自由度从 b 降到 k，模型复杂度可控
- **可解释性**：参数集中在少数几个方向上，便于业务解读

**工业视角**：

- **推荐系统的因子分解机（FM）**：本质是部分空间约束——把高维稀疏特征投影到低维稠密空间
- **计算机视觉的 PCA 预处理**：高维图像特征先做 PCA 保留 99% 方差，再做回归
- **风控模型的特征筛选**：业务上只允许使用监管认可的几十个特征，其余强制为零

> 💡 **洞见**：部分空间约束是**"主动降维"**思想的原型。今天所有的 embedding 方法（Word2Vec、Item2Vec、Graph Embedding）都是这个思想的延伸——把高维 one-hot 空间约束到低维稠密子空间。

### 4.2 L2 约束的最小二乘学习法（岭回归）

**书中定义**：在最小二乘目标函数中加入 **L2 范数约束**：

$$
J_{\mathrm{Ridge}}(\theta)=\frac{1}{2n}\sum_{i=1}^{n}\bigl(f_\theta(x_i)-y_i\bigr)^2+\frac{\lambda}{2}\lVert\theta\rVert_2^2
$$

或矩阵形式：

$$
J_{\mathrm{Ridge}}(\theta)=\frac{1}{2}\lVert y-\Phi\theta\rVert_2^2+\frac{\lambda}{2}\lVert\theta\rVert_2^2
$$

**闭式解**：

$$
\hat{\theta}_{\mathrm{Ridge}}=(\Phi^{\mathsf T}\Phi+\lambda I)^{-1}\Phi^{\mathsf T}y
$$

**🎯 第一性原理洞察**

这一节是全书的"高光时刻"——**L2 约束同时解决了三个问题**：

```
问题 1: ΦᵀΦ 不可逆（多重共线性）
   → λI 保证 ΦᵀΦ+λI 永远正定可逆
   
问题 2: 小奇异值放大噪声
   → 新的广义逆: κₖ → κₖ/(κₖ²+λ)
   → 当 κₖ 很小时，κₖ/(κₖ²+λ) ≈ κₖ/λ 不再爆炸
   
问题 3: 过拟合
   → L2 惩罚把系数往 0 压缩，降低模型复杂度
```

**用 SVD 看得更清楚**：

无约束最小二乘：$\theta^{(k)}=\kappa_k^{-1}(\psi_k^{\mathsf T}y)\phi_k$

岭回归：$\theta_{\mathrm{Ridge}}^{(k)}=\frac{\kappa_k}{\kappa_k^2+\lambda}(\psi_k^{\mathsf T}y)\phi_k$

```
奇异值 κₖ  →  岭回归的收缩因子 κₖ/(κₖ²+λ)

κₖ 大 (信号强):  收缩因子 ≈ 1/κₖ  → 几乎不收缩
κₖ 小 (噪声向):  收缩因子 ≈ κₖ/λ → 强烈收缩到 0
```

**这就是岭回归的精髓：对"高信噪比方向"几乎不动，对"低信噪比方向"强烈压缩**。这是一种**自适应的多尺度滤波**，堪称统计学中最优雅的正则化。

**$\lambda$ 的作用**（偏差-方差权衡）：

```
λ = 0:      退化为普通最小二乘，低偏差高方差
λ 小:       轻微正则化，方差略降
λ 适中:     偏差↑ 方差↓，泛化最佳（通过交叉验证选定）
λ 大:       强正则化，高偏差低方差，可能欠拟合
```

**几何解释**：

```
L2 约束的几何意义：

   等高线 (误差面)
     ╭─────╮
    ╱       ╲
   │    ●    │ ← 无约束最小二乘解
   │         │
   ╰─━━━─╯  ← L2 约束球 ‖θ‖² ≤ C
       │
       ● ← 岭回归解 (球面与等高线的切点)
```

**工业视角**：

岭回归是工业界最常用的线性模型正则化方法：

- **Google 的 FTRL 中 L2 正则化**：在线广告点击率预测的标配
- **Netflix Prize 的赢家方案**：大量使用岭回归做集成
- **生物统计/基因组学**：当特征数 >> 样本数（p >> n）时，岭回归是唯一可行方案
- **深度学习中的 Weight Decay**：本质就是 L2 正则化

> ⚠️ **关键认知**：L2 正则化**不会把系数压到精确的 0**，只能趋近于 0。如果需要特征选择（系数为 0），要用 L1 正则化（Lasso）——这是下一章稀疏学习的伏笔。

### 4.3 模型选择

**书中核心问题**：正则化参数 λ 怎么选？

**交叉验证（Cross-Validation）**是标准答案：

```
K-Fold Cross Validation:

  训练集 ─────→ 训练模型 ─→ 验证集 ─→ 计算误差
  
  数据集分割:
  [Train Train Train | Val] → 误差₁
  [Train Train Val | Train] → 误差₂
  [Train Val Train | Train] → 误差₃
  ...
  
  平均误差 = (误差₁ + 误差₂ + ... + 误差ₖ) / K
  
  选择使平均验证误差最小的 λ*
```

**🎯 第一性原理洞察**

模型选择的本质是**在"训练集性能"和"未知数据性能"之间架桥**：

```
训练误差:    模型在见过的数据上的误差 (总是偏低，可能过拟合)
验证误差:    模型在未见过的数据上的代理误差 (通过 CV 估算)
测试误差:    模型在真正未知数据上的真实误差 (只能评估一次！)

        训练误差    验证误差(CV)    测试误差
            ↓          ↓              ↓
   过拟合区 │══════════│══════════│ 
            │          │          │
   最佳模型 │          ●←──┐     │
            │          │   λ*    │
   欠拟合区 │══════════│═════════│
            ↓          ↓          ↓
           λ小        λ适中       λ大
```

**模型选择的三个层次**：

1. **超参数选择**：$\lambda$、核带宽、多项式阶数等
2. **模型选择**：线性 vs 核 vs 层级
3. **特征选择**：哪些特征进入模型

**偏差-方差分解**：

$$
\mathbb{E}[\mathrm{Test\ Error}]
=\mathrm{Bias}^2+\mathrm{Variance}+\mathrm{Irreducible\ Error}
$$

```
模型复杂度 ↑
    │
    │  Variance (方差)
    │  ╱
    │ ╱
    │╱
    ├───●───← 最佳平衡点
    │     ╲
    │      ╲ Bias² (偏差)
    │       ╲
    ↓        ╲
  复杂度 ↓
```

**工业视角**：

```
工业级模型选择的完整流程：

1. 训练集/验证集/测试集 = 8:1:1 或 9:0.5:0.5
2. 对于 λ ∈ {0.001, 0.01, 0.1, 1, 10, 100}:
     做 5-Fold CV，得到平均验证误差
3. 选择验证误差最小的 λ*
4. 用 (train+val) 重新训练，在 test 上报告最终性能
5. 部署后持续监控线上指标，定期重训

工业陷阱:
  ⚠ 不要用测试集做模型选择 (否则测试误差会被低估)
  ⚠ 时间序列数据不能用随机 K-Fold，必须按时间切分
  ⚠ 类别不平衡时需用分层 K-Fold (Stratified K-Fold)
```

> 💡 **洞见**：模型选择不仅选 $\lambda$，更是选**"偏差-方差-计算成本"三角中的工作点**。工业界往往牺牲一点统计最优性，换取：
> 
> - 计算效率（$\lambda$ 取 $10$ 的整数次幂网格，不做精细搜索）
> - 业务可解释性（优先选择稀疏模型）
> - 线上稳定性（偏向稍大的 $\lambda$，避免系数剧烈波动）

## 跨章节总洞察：最小二乘的统一框架

把第3章和第4章连起来，杉山将其实在讲一个**极简的统一范式**：

```
第3章: 无约束最小二乘
       min ‖Φθ - y‖²
       ↓
       解: θ = Φ†y (正交投影)
       问题: 过拟合、病态、不可扩展
       
第4章: 约束最小二乘
       min ‖Φθ - y‖²  s.t. θ ∈ 约束集
       ↓
       三种约束:
       ┌─ 部分空间约束 → 降秩、降维
       ├─ L2 约束     → 岭回归 (最常用)
       └─ 模型选择    → 交叉验证选定约束强度
```

**三个第一性原理式的认知**：

1. **最小二乘 = 正交投影**：所有最小二乘问题，本质都是在模型空间 $R(\Phi)$ 上找观测向量 $y$ 的最近点。这一点在 3.2 节的 SVD 分解中被揭示得淋漓尽致。
2. **约束 = 用偏差换方差**：第4章的所有约束方法，本质都是通过引入**偏差**来降低**方差**，从而在"泛化误差 $=$ 偏差$^2$ + 方差 + 不可约误差"的总账上获得净收益。这是机器学习最深刻的权衡。
3. **模型选择 = 在偏差-方差前沿上找工作点**：$\lambda$ 的选择不是"越大越好"也不是"越小越好"，而是通过交叉验证在偏差-方差曲线上找到那个膝盖点（elbow point）。

**与工业深度学习的关系**：

```
传统机器学习 (本书范畴):        深度学习:
min ‖Φθ-y‖² + λ‖θ‖²      vs.  min ‖f_θ(x)-y‖² + λ‖θ‖²
     ↑                            ↑
   Φ 是固定的基                   f_θ 的参数化复杂函数
   只有 θ 被学习                  基函数和 θ 同时被学习
   
共同点: 都是"经验风险 + 正则化"
差异点: 深度学习的"基"也是可学习的 (层级模型)
```

> 💡 **终极洞见**：今天所有的深度学习训练——无论是 ResNet 还是 GPT——其优化目标依然可以写成"损失函数 + 正则化项"的最小二乘形式。Weight Decay 就是 L2 正则化，Dropout 是隐式的 L2 正则化，Batch Norm 是隐式的约束。**第3、4章看似"古老"，实则是今天所有机器学习算法的"源代码"**。

## 英文补充视角（Beyond the Book）

结合 Hastie《The Elements of Statistical Learning》、Géron《Hands-On Machine Learning》等经典英文教材：

**1. 最小二乘与最大似然的等价性**

当噪声 $\\varepsilon\\sim\\mathcal{N}(0,\\sigma^2)$ 时，最小二乘估计 $\\equiv$ 最大似然估计（MLE）。这一视角把频率学派的最小二乘与贝叶斯推断联系起来——L2 正则化等价于参数先验 $\\theta\\sim\\mathcal{N}(0,1/\\lambda)$。

**2. 闭式解的数值计算**

工业界**不直接计算** $(\Phi^{\mathsf T}\Phi)^{-1}$，而是用：

- **QR 分解**：$\Phi=QR$，$\theta=R^{-1}Q^{\mathsf T}y$（数值更稳定）
- **SVD 分解**：处理奇异/病态矩阵的标准方法
- **Cholesky 分解**：当 $\Phi^{\mathsf T}\Phi$ 正定时最快

**3. 岭回归的贝叶斯解释**

Ridge regression = MAP estimation with Gaussian prior。这一视角在本书第5章（贝叶斯学习）会有更深入的展开。

**4. 大规模优化的现代方法**

本书提到的 SGD 是现代优化的起点。今天的工业级优化器还包括：

- **Adam / AdamW**：深度学习标配
- **L-BFGS**：大规模平滑优化
- **FTRL-Proximal**：Google 在线学习的工业标准

**5. 正则化的现代发展**

从 L2 正则化出发，现代机器学习发展出了丰富的正则化谱系：

- **L1 (Lasso)**：稀疏性 → 特征选择
- **Elastic Net**：L1 + L2 → 兼顾稀疏与稳定性
- **Group Lasso**：结构化稀疏
- **Dropout / Batch Norm**：深度学习的隐式正则化
