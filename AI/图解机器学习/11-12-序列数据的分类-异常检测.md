
# 《图解机器学习》读书笔记 · 第11章 序列数据的分类 + 第12章 异常检测

> 前10章我们处理的都是**独立同分布（i.i.d.）**的样本——每个 xᵢ 独立，标签 yᵢ 独立。但现实世界中**大量数据是有序的**：一句话里的词、一段语音里的帧、一个蛋白质里的氨基酸、一台设备按时间采样的传感器读数……
> 
> 第11章回答：**当数据变成序列，分类该怎么做？**​ 杉山将给出的答案是**条件随机场（CRF）**——它不是对序列里的每个位置独立分类，而是**对整个标签序列联合建模**。
> 
> 第12章进入**无监督学习**的篇章——异常检测。这里有个根本性的视角反转：**没有标签了**。我们手里的"正常数据"是海量的，"异常数据"是稀少的甚至可能完全没有。第12章给出三种思路：LOF（看局部密度）、One-Class SVM（学正常区域的边界）、密度比（直接估正常与异常的分布差异）。

## 第11章 序列数据的分类

### 11.1 序列数据的模型化

**书中问题定义**：输入是一个序列 $X=(x_1,x_2,\ldots,x_T)$，输出是对应的标签序列 $Y=(y_1,y_2,\ldots,y_T)$。目标是学习 $P(Y\mid X)$。

**🎯 第一性原理洞察：为什么序列分类不能"逐点分类"？**

```
逐点分类的失败案例 (命名实体识别 NER):

输入:  "苹果 发布 了 新品"
逐点预测: "B-ORG I-ORG O   B-ORG"
                              ↑ 错误! "新品"不是组织名

正确序列: "B-ORG I-ORG O   B-PRODUCT"
                              ↑ "新品"应是产品名

问题: 逐点分类忽略了标签之间的约束:
  - "B-ORG" 后面应该跟 "I-ORG" 或 "E-ORG"，不应直接跳到 "B-PRODUCT"
  - 标签序列必须满足语法约束 (BIO 标注规范)
```

**序列模型化的两种哲学**：

```
哲学1: 生成式模型 (Generative) — 隐马尔可夫模型 HMM
  建模联合概率 P(X, Y) = P(Y)·P(X|Y)
  需要假设: 观测 xₜ 仅依赖于当前状态 yₜ
  缺陷: 
  - 必须建模 P(X)，但 P(X) 通常复杂且不必要
  - 观测独立性假设过强，限制了特征的使用
  
哲学2: 判别式模型 (Discriminative) — 条件随机场 CRF ★
  直接建模条件概率 P(Y|X)
  跳过对 P(X) 的建模，专注预测任务
  通过特征函数表达丰富的依赖关系
```

**线性链 CRF 的定义**​ ：

$$
P_\lambda(Y\mid X)=
\frac{1}{Z_\lambda(X)}
\exp\!\left(
\sum_{t=1}^{T}\sum_k
\lambda_k f_k(y_{t-1},y_t,X,t)
\right)
$$

其中 Z(X) 是配分函数（归一化因子）：

$$
Z_\lambda(X)=
\sum_{Y'}
\exp\!\left(
\sum_{t=1}^{T}\sum_k
\lambda_k f_k(y'_{t-1},y'_t,X,t)
\right)
$$

**特征函数的两类**：

```
1. 状态特征 (State Features) s_l(y_t, X, t)
   - 描述单个标签与输入的关系
   - 例: "当前词首字母大写且标签为人名时为1"
   
2. 转移特征 (Transition Features) t_k(y_{t-1}, y_t, X, t)
   - 描述相邻标签之间的关系
   - 例: "前一个标签是 B-ORG 且当前标签是 I-ORG 时为1"
```

**ASCII 图示 CRF 的链式结构**：

```
线性链 CRF 的无向图结构:

   x₁ ──── x₂ ──── x₃ ──── ... ──── xₜ
    │       │       │              │
    ↓       ↓       ↓              ↓
   y₁ ──── y₂ ──── y₃ ──── ... ──── yₜ
    ↑       ↑       ↑              ↑
    └───────┴───────┴── 边表示标签间的转移依赖

   每个 yₜ 的条件概率依赖于:
   - 对应的 xₜ (发射特征)
   - 相邻的 yₜ₋₁ 和 yₜ₊₁ (转移特征)
   - 整个输入序列 X (全局特征)
```

**CRF vs HMM 的本质区别**​ ：

|维度|HMM (生成式)|CRF (判别式)|
|---|---|---|
|建模对象|P(X,Y) 联合概率|P(Y\|X) 条件概率|
|特征使用|受限（观测独立性）|**灵活（任意特征函数）**​|
|标注偏置|存在 Label Bias 问题|**全局归一化，无偏置**​|
|训练目标|最大化联合似然|最大化条件似然|
|解码|Viterbi（同CRF）|Viterbi|
|表达能力|弱|**强**​|

> 💡 **洞见**：CRF 的核心突破是**全局归一化**。HMM 在每个时间步局部归一化，导致"标注偏置"——转移概率低的标签即使发射概率很高也难以被选中。CRF 在整个序列层面做归一化（Z(X) 是所有可能标签序列的总和），从根本上消除了这个问题。

**工业视角**：

```
CRF 的工业应用版图：

自然语言处理 (NLP):
  ✓ 命名实体识别 (NER): 识别文本中的人名、地名、组织名
  ✓ 词性标注 (POS): 为每个词标注词性
  ✓ 句法分析: 构建句子的语法树
  ✓ 中文分词: 序列标注的经典任务
  
生物信息学:
  ✓ 基因识别: DNA 序列中的基因边界标注
  ✓ 蛋白质二级结构预测
  ✓ 肽链测序
  
计算机视觉:
  ✓ 图像分割: 像素级标注
  ✓ 姿态估计: 关节点序列标注
  ✓ 目标跟踪: 时序边界框标注
  
工业时序:
  ✓ 设备状态标注: 传感器读数的状态序列
  ✓ 语音识别: 音素序列标注
  ✓ 手写识别: 笔画序列标注
```

> ⚠️ **工业现状**：在深度学习时代，CRF 常与 LSTM/CNN 结合（LSTM-CRF、CNN-CRF），作为输出层的"标签约束模块"。纯 CRF 在小数据集上仍有价值，但大数据场景下被端到端的神经 CRF 或 Transformer + CRF 取代。

### 11.2 条件随机场模型的学习

**书中思路**：CRF 的学习就是**最大化训练数据的条件对数似然**。

**目标函数**：

$$
L(\lambda)=
\sum_{i=1}^{N}\log P_\lambda\!\left(Y^{(i)}\mid X^{(i)}\right)
-\frac{C}{2}\lVert\lambda\rVert_2^2
$$

其中第二项是对参数 $\lambda$ 的 L2 正则化。

**对数似然的展开**：

$$
\log P_\lambda(Y\mid X)
=\sum_{t,k}\lambda_k f_k(y_{t-1},y_t,X,t)-\log Z_\lambda(X)
$$

**梯度的计算**：

$$
\frac{\partial L}{\partial\lambda_k}
=\sum_{i=1}^{N}\left[
\sum_t f_k\!\left(y_{t-1}^{(i)},y_t^{(i)},X^{(i)},t\right)
-\mathbb{E}_{P_\lambda(Y\mid X^{(i)})}
\left[\sum_t f_k(y_{t-1},y_t,X^{(i)},t)\right]
\right]-C\lambda_k
$$

**关键：期望项的计算需要前向-后向算法**​ 。

**🎯 第一性原理洞察：CRF 学习的本质是"特征期望匹配"**

```
梯度 = 训练数据中特征 k 的出现次数
     - 模型预测中特征 k 的期望出现次数
     - 正则化项

直观理解:
  如果某个特征在训练数据中出现得比模型预测的更频繁
  → 梯度为正 → 增大该特征的权重 λ_k
  → 让模型更多地"使用"这个特征
  
  反之，如果模型过度使用了某个特征
  → 梯度为负 → 减小该特征的权重
  → 抑制这个特征
```

**前向-后向算法**​ ：

```
前向概率 α_t(y_t):
  表示"在时刻 t 到达状态 y_t 的所有路径的概率和"
  
  α_t(y_t) = Σ_{y_{t-1}} α_{t-1}(y_{t-1}) · 
             exp(Σ_k λ_k f_k(y_{t-1}, y_t, X, t))

后向概率 β_t(y_t):
  表示"从时刻 t 的状态 y_t 出发，到达序列末尾的所有路径的概率和"
  
  β_t(y_t) = Σ_{y_{t+1}} β_{t+1}(y_{t+1}) · 
             exp(Σ_k λ_k f_k(y_t, y_{t+1}, X, t))

配分函数:
  Z(X) = Σ_{y_T} α_T(y_T)

特征期望的计算:
  E_{P(Y|X)}[f_k] = (1/Z(X)) · Σ_{t} Σ_{y_{t-1},y_t} 
                    α_{t-1}(y_{t-1}) · exp(Σ_k λ_k f_k(...)) · β_t(y_t)
```

**ASCII 图示前向-后向的传播**：

```
前向传播 (Left to Right):

  x₁     x₂     x₃     x₄
   │      │      │      │
   ↓      ↓      ↓      ↓
  y₁ ──→ y₂ ──→ y₃ ──→ y₄
   ↑      ↑      ↑      ↑
   │      │      │      │
  α₁     α₂     α₃     α₄
  
  α₁(y₁) = 1 (初始化)
  α₂(y₂) = Σ_{y₁} α₁(y₁)·exp(转移+发射)
  ...

后向传播 (Right to Left):

  x₁     x₂     x₃     x₄
   │      │      │      │
   ↓      ↓      ↓      ↓
  y₁ ──→ y₂ ──→ y₃ ──→ y₄
   ↑      ↑      ↑      ↑
   │      │      │      │
  β₁     β₂     β₃     β₄
  
  β₄(y₄) = 1 (初始化)
  β₃(y₃) = Σ_{y₄} β₄(y₄)·exp(转移+发射)
  ...

合并计算特征期望:
  E[f_k] ∝ α_{t-1}(y_{t-1}) · exp(Σλf) · β_t(y_t)
```

**优化算法**：

```
1. 梯度上升/下降:
   λ_k ← λ_k + η · ∂L/∂λ_k
   问题: 朴素梯度下降收敛慢
   
2. 改进的优化方法:
   - SGD (随机梯度下降): 工业界主流
   - L-BFGS: 小规模数据的默认选择
   - SGD + 学习率衰减: 大规模数据
   
3. 正则化:
   L2 正则化 (λ 的 L2 范数) — 防止过拟合
   或 L1 正则化 — 特征选择 (稀疏化)
```

**🎯 深度洞见：CRF 学习的计算瓶颈**

```
计算复杂度分析:

  前向-后向算法: O(T · K²)
    T = 序列长度
    K = 标签数量
    
  梯度计算: O(T · K² · F)
    F = 特征函数数量
    
  总训练复杂度: O(N · T · K² · F · Iter)
    N = 样本数
    Iter = 迭代次数
    
  大规模场景的挑战:
  - 特征函数数量 F 可能达百万级 (如 NLP 中的词-标签组合)
  - 需要特征哈希 (Feature Hashing) 压缩
  - 或使用基于模板的特征生成
```

**工业视角**：

```
CRF 训练的工业级实践：

1. 特征工程是关键:
   - 状态特征: 词本身、词性、大小写、前后缀、词典匹配
   - 转移特征: 标签间的合法/非法转移
   - 特征模板: 自动生成 (如"当前词-1"、"当前词+窗口")
   
2. 优化器选择:
   - 小规模 (< 10万样本): L-BFGS
   - 中规模 (10万~100万): SGD
   - 大规模 (> 100万): Mini-batch SGD + 学习率调度
   
3. 正则化:
   - L2 正则化: λ ∈ [0.01, 10]
   - 通过交叉验证选择
   
4. 工具:
   - CRF++: 工业界经典 C++ 实现
   - sklearn-crfsuite: Python 接口
   - TensorFlow/PyTorch: 神经 CRF 实现
```

> 💡 **洞见**：CRF 的学习过程揭示了判别式模型训练的本质——**让模型预测的特征期望匹配训练数据的特征经验频率**。这一思想在今天的深度学习中以"对比学习"、"能量模型"的形式复活。CRF 训练时的前向-后向算法，本质上是概率图模型中的"消息传递"（Message Passing），与今天的 Graph Neural Networks 中的消息传递算法同源。

### 11.3 利用条件随机场模型对标签序列进行预测

**书中思路**：训练完成后，对新输入序列 $X$，我们需要找到**最可能的标签序列** $Y^*=\arg\max_Y P_\lambda(Y\mid X)$。

**预测问题**：

$$
Y^*=\arg\max_Y P_\lambda(Y\mid X)
=\arg\max_Y\sum_{t,k}\lambda_k f_k(y_{t-1},y_t,X,t)
$$

由于直接枚举所有 $Y$ 是指数级复杂度 $O(K^T)$，需要用动态规划。

**维特比算法（Viterbi Algorithm）**​ ：

```
动态规划递推:

  δ_t(y_t) = max_{y_{t-1}} [δ_{t-1}(y_{t-1}) + 
             Σ_k λ_k f_k(y_{t-1}, y_t, X, t)]

  ψ_t(y_t) = argmax_{y_{t-1}} [δ_{t-1}(y_{t-1}) + 
             Σ_k λ_k f_k(y_{t-1}, y_t, X, t)]

回溯得到最优序列:
  y_T^* = argmax_{y_T} δ_T(y_T)
  y_t^* = ψ_{t+1}(y_{t+1}^*)  for t = T-1, T-2, ..., 1
```

**时间复杂度**：O(T · K²) — 多项式级，相比暴力枚举的指数级是质的飞跃。

**ASCII 图示维特比解码**：

```
维特比解码的动态规划网格:

时间 →
      t=1    t=2    t=3    t=4
       │      │      │      │
标签 B │ δ₁(B)│ δ₂(B)│ δ₃(B)│ δ₄(B)
       │ ↗    │ ↗    │ ↗    │
标签 I │ δ₁(I)│ δ₂(I)│ δ₃(I)│ δ₄(I)
       │ ↗    │ ↗    │ ↗    │
标签 O │ δ₁(O)│ δ₂(O)│ δ₃(O)│ δ₄(O)
       │      │      │      │
       
每个格子存储:
  - δ_t(y): 到达该状态的最优路径得分
  - ψ_t(y): 最优前驱标签

回溯路径 (假设最优序列为 B-I-O-O):
  t=4: O ← t=3: O ← t=2: I ← t=1: B
  
  δ₄(O) 最大 ← ψ₄(O)=O ← ψ₃(O)=I ← ψ₂(I)=B
```

**维特比 vs 前向-后向**：

|维度|维特比算法|前向-后向算法|
|---|---|---|
|目的|找**最可能**的标签序列|计算**所有**序列的概率和|
|操作|max（最大化）|sum（求和）|
|输出|单一最优序列|配分函数 Z(X) + 边际概率|
|用途|预测/解码|训练/学习|
|复杂度|O(T·K²)|O(T·K²)|

**边际概率与训练的关系**：

```
训练中需要特征期望:
  E_{P(Y|X)}[f_k] = Σ_Y P(Y|X) · f_k(Y, X)
  
  直接计算需要枚举所有 Y → 不可行
  
  利用前向-后向:
  E[f_k] = (1/Z(X)) · Σ_t Σ_{y_{t-1},y_t} 
           α_{t-1}(y_{t-1})·exp(Σλf)·β_t(y_t)·f_k
  
  复杂度 O(T·K²) — 可行!
```

**🎯 第一性原理洞察：维特比解码 = 在"得分图"上找最长路径**

```
维特比的本质:

把 CRF 的条件概率取对数:
  log P(Y|X) = Σ_t Σ_k λ_k f_k(y_{t-1}, y_t, X, t) - log Z(X)
  
由于 log Z(X) 与 Y 无关，最大化 P(Y|X) 等价于最大化:
  Score(Y) = Σ_t Σ_k λ_k f_k(y_{t-1}, y_t, X, t)
  
这是一个在"格图 (Grid Graph)"上的最短/最长路径问题:
  - 节点: 每个时间步的每个标签
  - 边权: 转移特征 + 发射特征的得分
  - 目标: 找从 t=1 到 t=T 的最大得分路径
  
维特比算法就是解决这个问题的动态规划
```

**工业视角**：

```
CRF 预测的工业实践：

1. 解码加速:
   - 维特比本身是 O(T·K²)，对长序列仍需优化
   - Beam Search: 只保留 top-B 个候选路径 (B << K)
   - 近似解码: 当 T 很大时（如长文档），分块解码
   
2. 约束解码:
   - 硬约束: 强制某些标签转移非法 (如 B-ORG → B-ORG)
   - 软约束: 在特征函数中加入惩罚
   - 业务规则: 结合外部知识库 (如字典) 调整解码
   
3. 典型工业流水线:
   输入文本 → 分词 → 特征提取 → CRF预测 → 后处理
   
   案例: 中文 NER 系统
   输入: "苹果公司发布了iPhone15"
   输出: "苹果公司/B-ORG 发布/O 了/O iPhone15/B-PRODUCT"
   
4. 与深度学习的结合:
   LSTM-CRF: LSTM 提取特征 → CRF 层做标签约束
   Transformer-CRF: BERT 提取特征 → CRF 层解码
   
   工业趋势: 神经 CRF 在大规模数据上全面超越传统 CRF
```

> 💡 **洞见**：维特比算法不仅是 CRF 的解码工具，它更是**动态规划在序列决策中的经典应用**。今天的 Beam Search（用于机器翻译、语音识别）、CTC 解码（用于语音识别）、甚至强化学习中的策略优化，都流淌着维特比算法的血液。**理解维特比，就是理解序列决策的动态规划基因**。

## 第12章 异常检测

### 12.1 局部离群因子 (LOF)

**书中思路**：LOF 通过比较样本的**局部密度**与邻居的局部密度来识别异常。

**核心概念**：

```
1. k-距离 (k-distance): 对象到其第 k 近邻的距离
2. 可达距离 (Reachability Distance): 
   reach-dist(p, o) = max(k-dist(o), dist(p, o))
3. 局部可达密度 (Local Reachability Density):
   lrd(p) = 1 / (Σ_{o∈N_k(p)} reach-dist(p,o) / |N_k(p)|)
4. 局部离群因子:
   LOF_k(p) = Σ_{o∈N_k(p)} lrd(o) / lrd(p) / |N_k(p)|
```

**🎯 第一性原理洞察：LOF 的本质是"局部密度比"**

```
LOF 的直觉:

正常点:     密度与邻居相似 → LOF ≈ 1
异常点:     密度远低于邻居 → LOF >> 1

关键: "局部"二字
  - 不是看全局密度，而是看局部密度
  - 不同区域的密度基准不同
  - 一个稀疏区域中的点，相对于其稀疏邻居可能并不异常
  - 一个密集区域中的点，稍微偏离就会被判为异常
```

**ASCII 图示 LOF 的原理**：

```
数据点分布:

        ● ● ● ● ● ●         ● ●
     ● ● ● ● ● ● ● ●      ●   ●
        ● ● ● ● ●          ● ●
                             
       密集区域               稀疏区域
       (正常)               (正常，因为邻居也稀疏)
       
   插入一个异常点:
   
        ● ● ● ● ● ●         ● ●
     ● ● ● ● ● ● ● ●      ●   ●
        ● ● ● X ●          ● ●
              ↑
              异常点! 
              其局部密度远低于邻居 → LOF 值高
              
   但如果在稀疏区域插入点:
   
        ● ● ● ● ● ●         ● ●
     ● ● ● ● ● ● ● ●      ● X ●
        ● ● ● ● ●          ● ●
                              ↑
                              这个点 LOF ≈ 1 (邻居也稀疏)
                              不被认为是异常!
```

**LOF 的关键参数**：

```
k (n_neighbors):
  - k 太小: 对噪声敏感，密度估计不稳定
  - k 太大: 局部性丧失，变成全局密度
  - 经验值: k = 20 (scikit-learn 默认)
  - 当异常比例高时，需要增大 k
  
contamination: 预期的异常比例
  - 用于阈值化 LOF 得分
  - 通常设为 0.1 (10% 异常)
```

**工业视角**：

```
LOF 的工业应用：

✓ 适用场景:
  - 局部密度差异显著的数据
  - 异常是"相对邻居而言"的稀疏点
  - 中小规模数据 (n < 10万)
  
典型应用:
  1. 信用卡欺诈检测:
     正常交易聚集在特定模式，欺诈交易偏离
  2. 网络入侵检测:
     正常流量有模式，攻击流量是离群点
  3. 工业传感器:
     正常工况下传感器读数聚集，故障是离群
  4. 医疗诊断:
     正常生理指标聚集，异常病症是离群
     
✗ 不适用场景:
  - 大规模数据 (O(n²) 复杂度)
  - 高维数据 (维度灾难，距离度量失效)
  - 流数据 (需要在线更新)
  
性能数据 (信用卡欺诈数据集) :
  样本量     LOF训练时间
  10,000    1.8s
  50,000    45s
  全部数据  内存溢出
  
  → LOF 在 > 5万样本时扩展性差
```

> 💡 **洞见**：LOF 的精髓是"**相对异常**"而非"绝对异常"。它不预设全局的密度模型，而是问"这个点相对于它的邻居是不是太稀疏了？"这种局部视角使 LOF 能处理密度不均匀的数据——全局密度方法（如 One-Class SVM）会把稀疏区域中的所有点都判为异常，而 LOF 能区分"稀疏区域中的正常点"和"稀疏区域中的异常点"。

### 12.2 支持向量机异常检测 (One-Class SVM)

**书中思路**：One-Class SVM 通过在特征空间中寻找**最小超球体**来包裹正常数据，落在球体外的点被判为异常。

**两种等价形式**​ ：

```
形式1: SVDD (Support Vector Data Description)
   min R² + C·Σξᵢ
   s.t. ‖φ(xᵢ) - a‖² ≤ R² + ξᵢ, ξᵢ ≥ 0
   
   找最小半径 R 的超球体，中心 a，包裹正常数据

形式2: One-Class SVM (Schölkopf et al.)
   min ½‖w‖² + C·Σξᵢ - ρ
   s.t. w·φ(xᵢ) ≥ ρ - ξᵢ
   
   找最大间隔的超平面，将正常数据与原点分离
   
两者通过对偶转化是等价的
```

**核技巧**：使用 RBF 核处理非线性边界：

$$
k(x_i,x_j)=\exp\!\left(-\gamma\lVert x_i-x_j\rVert_2^2\right)
$$

**关键参数**：

```
ν (nu):
  - 控制异常点比例的上限
  - 同时控制支持向量的比例
  - ν ∈ (0, 1)，典型值 0.01~0.1
  
γ (gamma):
  - RBF 核的带宽参数
  - 影响决策边界的形状
  - 过大: 过拟合，边界复杂
  - 过小: 欠拟合，边界过于平滑
```

**🎯 第一性原理洞察：One-Class SVM 是"边界学习"而非"密度估计"**

```
One-Class SVM vs LOF 的本质差异:

LOF: 密度视角
  异常 = 局部密度低的点
  需要估计密度 → 受维度灾难影响
  
One-Class SVM: 边界视角
  异常 = 落在正常数据边界之外的点
  只需学一个决策边界 → 对维度更鲁棒
  
对比可视化:

LOF 视角:                    One-Class SVM 视角:
                                                   
   ● ● │ ○ ○                   ● ● │ ○ ○
   ● ● │ ○ ○                   ● ● │ ○ ○
   ● ● │ ○○                    ● ● │ ○○
      │                             │ ← 非线性边界
   密度低→异常                  边界外→异常
   边界内→正常
   
   LOF 关注密度                  OCSVM 关注边界
   密度低不一定是异常            边界外一定是异常
   边界内一定是正常
```

**One-Class SVM 的"新颖性检测"本质**​ ：

```
⚠️ 重要: One-Class SVM 是"新颖性检测 (Novelty Detection)"
   而非"异常检测 (Outlier Detection)"
   
区别:
  新颖性检测: 训练数据**纯净**（无异常），
            模型学习"正常"的边界，
            新数据落在边界外 → 判为新颖/异常
            
  异常检测: 训练数据**可能被污染**（含异常），
          模型需要从含噪数据中识别异常
          
One-Class SVM 假设:
  - 训练集不包含异常点
  - 如果存在异常点，模型会"拟合"它们
  - 导致决策边界变形，漏检真正的异常
```

**工业视角**：

```
One-Class SVM 的工业定位：

✓ 适用场景:
  - 训练数据纯净 (无异常污染)
  - 需要非线性决策边界
  - 中等维度数据 (10 < d < 1000)
  - 中小规模数据 (n < 10万)
  
典型应用:
  1. 工业质量控制:
     训练数据全是合格产品，检测新产品的缺陷
  2. 网络安全:
     训练数据全是正常流量，检测新型攻击
  3. 医疗影像:
     训练数据全是健康组织，检测病变区域
  4. 语音处理:
     训练数据全是正常语音，检测异常声音
     
✗ 不适用场景:
  - 训练数据含异常 (应使用 LOF 或 Isolation Forest)
  - 大规模数据 (O(n²)~O(n³) 复杂度)
  - 高维稀疏数据 (d > 1000，应选择线性方法)
  
性能数据 :
  样本量     One-Class SVM 训练时间
  10,000    3.4s
  50,000    82s
  全部数据  内存溢出
  
  → 与 LOF 类似，大规模数据扩展性差
```

> 💡 **洞见**：One-Class SVM 的哲学是**"把正常数据圈起来"**。它不试图建模密度，而是学一个"包围正常数据的最小边界"。这种边界学习的思想，与第8章的 SVM 分类一脉相承——只不过这里只有一个类别。它的优势是对维度相对鲁棒（核技巧），劣势是训练数据必须纯净，且计算复杂度高。

### 12.3 基于密度比的异常检测

**书中思路**：直接估计**正常数据分布与测试数据分布的比值**，密度比高的区域即为异常。

**密度比的定义**：

$$
w(x)=\frac{p_{\mathrm{test}}(x)}{p_{\mathrm{normal}}(x)}
$$

其中 $p_{\mathrm{normal}}$ 是正常数据分布，$p_{\mathrm{test}}$ 是测试数据分布。

**异常判定**：

```
w(x) ≈ 1: x 在正常数据分布内 → 正常
w(x) >> 1: x 在测试分布中更常见，在正常分布中罕见 → 异常
w(x) << 1: x 在正常分布中更常见 → 不太可能，通常不考虑
```

**🎯 第一性原理洞察：密度比是"直接"的异常度量**

```
三种异常检测方法的本质对比:

LOF: 间接密度估计
  估计局部密度 → 比较密度 → 判定异常
  两步过程，密度估计误差会传播
  
One-Class SVM: 边界学习
  学正常数据的边界 → 边界外即异常
  不直接建模密度
  
密度比方法: 直接估计密度比 ★
  直接估计 w(x) = p_test(x) / p_normal(x)
  一步到位，异常分数 = 密度比
  
为什么密度比方法更优雅?
  1. 避免分别估计两个密度 (密度估计是难的)
  2. 密度比可以直接从样本估计 (如 KLIEP 算法)
  3. 异常分数有明确的概率解释
```

**密度比估计的方法**：

```
1. KLIEP (Kullback-Leibler Importance Estimation Procedure):
   最小化 KL 散度，直接学习密度比 w(x)
   
2. uLSIF (unconstrained Least Squares Importance Fitting):
   最小化平方误差，学习密度比
   
3. RuLSIF (Robust uLSIF):
   uLSIF + 鲁棒性改进
   
共同特点: 
   - 不需要分别估计 p_test 和 p_normal
   - 直接估计它们的比值
   - 基于最小二乘框架 (呼应第3章)
```

**ASCII 图示密度比方法**：

```
正常数据分布 p_normal:          测试数据分布 p_test:
         ● ● ● ●                       ●
       ● ● ● ● ● ●                   ●   ●
         ● ● ● ●                       ●
         
密度比 w(x) = p_test / p_normal:

   高密度比区域 (异常):             低密度比区域 (正常):
         ○ ○ ○ ○                      ● ● ● ●
       ○ ○ ○ ○ ○ ○                  ● ● ● ● ● ●
         ○ ○ ○ ○                      ● ● ● ●
         
   w(x) >> 1: 异常区域
   w(x) ≈ 1: 正常区域
   w(x) << 1: 罕见 (通常不考虑)
```

**🎯 深度洞见：密度比方法与前面章节的统一**

```
密度比方法是全书思想的集大成:

第3章 最小二乘 ←→  uLSIF 用最小二乘估计密度比
第4章 L2 约束 ←→  密度比估计中的正则化
第5章 L1 约束 ←→  RuLSIF 的鲁棒化 (L1 约束)
第6章 鲁棒学习 ←→  RuLSIF 抵抗异常值的污染
第8章 核技巧 ←→  密度比估计中使用核模型

本质: 异常检测 = 密度比估计 = 最小二乘 + 核技巧 + 正则化
```

**工业视角**：

```
密度比异常检测的工业应用：

✓ 适用场景:
  - 有明确的正常数据 + 待检测的测试数据
  - 需要概率化的异常分数
  - 数据维度中等 (10 < d < 1000)
  - 异常比例较低 (< 10%)
  
典型应用:
  1. 工业故障检测:
     正常工况数据 vs 实时传感器数据
     密度比高的传感器读数 → 故障预警
     
  2. 金融欺诈检测:
     历史正常交易 vs 当前交易
     密度比高的交易 → 欺诈嫌疑
     
  3. 网络入侵检测:
     正常流量模式 vs 实时流量
     密度比高的流量 → 攻击嫌疑
     
  4. 医疗异常检测:
     健康人群数据 vs 患者数据
     密度比高的指标 → 疾病标志
     
优势:
  - 异常分数有明确的概率解释
  - 不需要假设数据分布的具体形式
  - 可直接估计密度比，避免密度估计的误差
  
挑战:
  - 需要足够多的正常数据样本
  - 高维数据下性能下降
  - 计算复杂度与样本数平方成正比
```

> 💡 **洞见**：密度比方法是异常检测的"第一性原理"视角——**异常的本质就是"测试数据分布相对于正常数据分布的变化"**。LOF 和 One-Class SVM 都是这个本质的某种近似：
> 
> - LOF 用局部密度比近似全局密度比
> - One-Class SVM 用边界学习隐式地建模密度比
> - 密度比方法直接估计这个比值，最为直接
> 
> 这也是为什么密度比方法在理论上最优雅——它直接回答了"什么叫做异常"这个根本问题。

## 跨章节总洞察：序列建模与异常检测在全书的位置

把第11章、第12章与前面的章节串联：

```
第3-6章: 监督学习的基础 (最小二乘 + 正则化 + 鲁棒性)
     ↓
第7-10章: 监督分类的完整光谱
   ├─ 第7章: 最小二乘分类 (目标错配)
   ├─ 第8章: SVM (间隔最大化)
   ├─ 第9章: 集成学习 (Bagging/Boosting)
   └─ 第10章: 概率分类 (Logistic回归)
     ↓
第11章: 序列数据的分类 ★
   → 把"独立样本分类"扩展到"序列分类"
   → CRF: 判别式模型 + 序列建模 + 全局归一化
   → 维特比解码: 动态规划在序列决策中的经典应用
     ↓
第12章: 异常检测 (无监督学习开篇) ★
   → 视角反转: 没有标签了
   → LOF: 局部密度比
   → One-Class SVM: 边界学习
   → 密度比: 直接估计异常分数
```

**三个第一性原理式的认知**：

1. **序列分类的本质是"联合概率建模"**。逐点分类忽略了标签间的依赖，CRF 通过全局归一化和转移特征，对整个标签序列联合建模。维特比解码是动态规划在序列决策中的经典应用，与今天的 Beam Search、CTC 同源。
2. **异常检测的本质是"密度比估计"**。LOF 用局部密度近似、One-Class SVM 用边界学习隐式建模、密度比方法直接估计。密度比方法最为直接，也最为优雅——它直接回答了"什么叫做异常"。
3. **无监督学习与监督学习的内在统一**。密度比估计用的是最小二乘（第3章）、核技巧（第2章、第8章）、正则化（第4章）——无监督学习并不是"另一个领域"，而是监督学习思想在无标签数据上的自然延伸。

**与工业深度学习的联系**：

```
传统 CRF → 神经 CRF:
  LSTM-CRF / BiLSTM-CRF: 神经网络提取特征 + CRF 层做标签约束
  Transformer-CRF: BERT 提取特征 + CRF 解码
  → 工业 NLP 的标准组件 (NER, POS, 句法分析)
  
CRF 层在深度学习中的作用:
  - 提供标签转移的约束
  - 解决"标注偏置"问题
  - 端到端训练中作为损失函数的一部分
  
异常检测 → 深度异常检测:
  - AutoEncoder: 重构误差作为异常分数
  - VAE: 似然概率作为异常分数
  - GAN: 判别器输出作为异常分数
  - Deep SVDD: 深度版本的 One-Class SVM
  - 隔离森林的深度学习版本: 深度隔离森林
  
核心思想的一脉相承:
  - LOF 的局部密度 → 深度特征空间中的局部密度
  - One-Class SVM 的边界 → Deep SVDD 的超球体
  - 密度比 → 深度密度比估计 (如 ADGAN)
```

> 💡 **终极洞见**：第11章和第12章是全书从"监督"走向"无监督"的桥梁。
> 
> **序列建模方面**：CRF 的思想——"用特征函数表达丰富的依赖关系 + 全局归一化 + 动态规划解码"——在今天以 LSTM-CRF、Transformer-CRF 的形式继续发光发热。维特比算法更是动态规划的基因，流淌在 Beam Search、CTC、强化学习策略优化中。
> 
> **异常检测方面**：三种方法（LOF、One-Class SVM、密度比）分别从局部密度、全局边界、分布比值三个视角切入，但它们共享一个核心——**异常的本质是"不同于正常的模式"**。这个思想在深度异常检测中以 AutoEncoder 重构误差、VAE 似然、GAN 判别器输出的形式复活。
> 
> **理解这两章，就是理解现代序列建模和无监督异常检测的理论根基**。

## 英文补充视角（Beyond the Book）

**1. CRF 的理论基础**：

- **Lafferty, McCallum, Pereira (2001)**: CRF 的原始论文，提出判别式无向图模型
- **Sutton & McCallum (2012)**: 《An Introduction to Conditional Random Fields》— CRF 的权威教程
- **Hammersley-Clifford 定理**: CRF 的因子分解理论基础

**2. CRF 的训练与推断**：

- **前向-后向算法**: 来源于 HMM，适配 CRF 的特征期望计算
- **维特比算法**: 动态规划解码最优标签序列
- **优化算法**: L-BFGS 是小规模 CRF 的标准优化器；SGD 用于大规模

**3. CRF 的现代发展**：

- **LSTM-CRF (Huang et al. 2015)**: 神经网络 + CRF 的命名实体识别
- **BiLSTM-CRF**: 双向 LSTM 提取特征，CRF 层做标签约束（NLP 的标配）
- **Transformer-CRF**: BERT 等预训练模型 + CRF

**4. 异常检测的理论基础**：

- **LOF (Breunig et al. 2000)**: Local Outlier Factor 的原始论文
- **One-Class SVM (Schölkopf et al. 2001)**: SVDD 的原始论文
- **KLIEP (Sugiyama et al. 2007)**: 密度比估计的直接方法
- **uLSIF/RuLSIF (Kanamori et al. 2009)**: 最小二乘密度比估计

**5. 工业级实践**：

- **CRF++**: 工业界经典的 CRF 实现（C++）
- **sklearn-crfsuite**: Python 接口
- **scikit-learn**: `LocalOutlierFactor`, `OneClassSVM` 的实现
- **PyOD**: Python 异常检测库，包含 20+ 种算法

**6. 深度异常检测**：

- **Deep SVDD (Ruff et al. 2018)**: 深度版本的 One-Class SVM
- **Anomaly Detection with GANs**: 使用 GAN 判别器输出作为异常分数
- **VAE for Anomaly Detection**: 使用重构似然作为异常分数

```
  One-Class SVM: 边界学习 → 纯净训练数据、非线性边界
  密度比: 直接估计 → 理论最优雅、异常分数有概率解释
  
  工业演进: 传统方法 → 深度异常检测 (AutoEncoder, VAE, GAN)
```

**带着"全局归一化"和"密度比"这两条主线去读后续章节（聚类、降维），你会发现无监督学习的统一图景**：聚类是寻找数据的"自然分组"、降维是寻找数据的"本质表示"、异常检测是寻找数据的"偏离模式"——三者共同构成了从无标签数据中提取知识的完整工具箱。
