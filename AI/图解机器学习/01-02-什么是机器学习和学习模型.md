
# 《图解机器学习》读书笔记（第1章·第2章）

## 第1章 什么是机器学习

### 1.1 学习的种类

**书中定义**：机器学习按"数据是否带老师"分为三大类——监督学习、无监督学习、强化学习。

- **监督学习**：学生（计算机）从老师（环境）获取带对错指示的知识，目标是获得对未学习过的问题也能正确解答的**泛化能力**。典型任务：回归、分类、排序。
- **无监督学习**：没有老师，学生自学。典型任务：聚类、异常检测、降维。
- **强化学习**：没有老师指示，学生对自己的预测结果自行评估，为了获得最高嘉奖而不断学习。典型应用：机器人自动控制、博弈 AI、市场战略最优化。

**🎯 第一性原理洞察**

Tom Mitchell 在 1997 年给出了一个更"工程化"的定义，可以作为本书定义的英文补充：

> _"A computer program is said to learn from experience E with respect to some task T and some performance measure P, if its performance on T, as measured by P, improves with experience E."_

把这句话拆开看，**学习的本质 = 任务 T + 经验 E + 性能度量 P 三者构成的闭环**。所谓"学没学到东西"，唯一的判据是 **P 是否随 E 增加而改善**——如果只是下载了全 Wikipedia，计算机的数据变多了，但没有任何任务 T 的性能提升，那就**不是机器学习**。

这就是为什么传统垃圾邮件过滤如果用"规则堆砌"（看到"免费""中奖"就标记）不属于机器学习——它是人把规则显式写出来，机器只是执行。而现代 spam filter 是从海量标注样本中**自己学出决策边界**，这才是 ML。

**三种学习范式的关系（ASCII 图）**：

```
有无标签?
           /         \
        有标签       无标签
          |            |
    监督学习      无有无反馈信号?
                   /        \
                有反馈    无反馈
                  |          |
              强化学习   无监督学习
              (自评奖罚)  (自学结构)
```

**工业视角**：今天工业界 90% 的落地系统是监督学习（推荐、风控、CV 分类、NLP 抽取），无监督多用于数据探索、特征预训练、异常检测，强化学习则在游戏、机器人、动态定价等"决策序列"场景发力。选哪种范式，本质上取决于**你手里有没有标签、能不能定义奖励**。

### 1.2 机器学习任务的例子

书中把任务细分为五种：

|任务|学习类型|输出形式|工业例子|
|---|---|---|---|
|**回归**​|监督|连续数值|房价预测、销量预估、股价预测|
|**分类**​|监督|离散标签|垃圾邮件识别、医学影像诊断|
|**异常检测**​|无监督|异常/正常|信用卡盗刷、设备故障预警|
|**聚类**​|无监督|簇归属|用户分群、基因序列分组|
|**降维**​|无监督|低维表示|可视化、特征压缩、数据去噪|

**🎯 第一性原理洞察**

这五个任务看似各异，但在数学本质上是**同一个问题的不同面孔**——都是**从数据分布中恢复某个函数 f:X→Y**：

```
回归:      Y ⊆ ℝ           (连续)
分类:      Y ⊆ {1,...,K}   (离散)
聚类:      Y 隐含于 X 的内部结构中
异常检测:  Y = {正常, 异常}，但标签缺失
降维:      Y ⊆ ℝ^d, d << D (X 的维度)
```

**关键认知**：很多初学者把"回归 vs 分类"看作两种截然不同的算法族，其实**区别仅在输出空间的拓扑结构**——回归的输出是连续域，分类的输出是离散集。这也是为什么逻辑回归又叫"对数几率回归"——它本质是一个线性回归套了一层 sigmoid 把输出压到 [0,1] 当作概率。

**异常检测 vs 分类的本质差异**（书中强调）：异常检测属于无监督，一般采用**密度估计**的方法，把靠近密度中心的数据作为正常数据，把偏离密度中心的数据作为异常数据。这意味着——**异常检测不是在"分类"，而是在"建模正常"**，凡是偏离正常模型的都判异常。这一思路在工业风控里极其关键：欺诈样本极少且持续演化，根本无法用纯监督方法覆盖。

**工业案例**：

- **回归**​ → 滴滴预估等待时间、亚马逊销量预测
- **分类**​ → 支付宝刷脸支付、字节内容审核
- **异常检测**​ → 银行反欺诈、Kubernetes 容器异常告警
- **聚类**​ → 淘宝"猜你喜欢"的用户分群、Netflix 内容标签
- **降维**​ → 高维特征送入下游模型前的 PCA 预处理

### 1.3 机器学习的方法

本节是整本书最"哲学"的一节，杉山将把方法层面分为两条正交的轴：

**轴一：判别式分类 vs 生成式分类**

```
判别式 (Discriminative):  直接学 p(y|x) —— "给定 x，y 最可能是啥"
生成式 (Generative):      先学 p(x,y)，再用贝叶斯公式推 p(y|x) —— "数据是怎么生成的"
```

**轴二：统计概率 vs 朴素贝叶斯**

- **统计概率方法**：把模型参数 θ 当作**决定性变量**（点估计），典型如最大似然估计
- **贝叶斯方法**：把 θ 当作**概率变量**（分布估计），典型如朴素贝叶斯

**🎯 第一性原理洞察**

这两条轴的交叉揭示了机器学习最根本的**归纳偏置（Inductive Bias）**问题：

```
参数θ的性质
                 /                 \
              决定性变量          概率变量
               (点估计)           (分布估计)
              /        \          /        \
        判别式          生成式    判别式      生成式
        逻辑回归        GDA      ——        朴素贝叶斯
        (MLE)         (联合分布)           (先验+似然)
```

**为什么这个区分至关重要？**

1. **判别式效率高**：直接建模 p(y|x)，目标明确，样本利用率高，工业界主流。
2. **生成式可生成**：学会了 p(x,y) 意味着你能**采样新数据**——这正是今天 Diffusion、GPT 等生成式 AI 的理论根源。
3. **贝叶斯方法天然抗过拟合**：把参数当分布而非点，相当于内置了正则化。

> 💡 **洞见**：今天大火的深度学习，绝大多数是**判别式 + 决定性参数**的路子（如 CNN 分类器）；而 AIGC 浪潮则是**生成式 + 决定性参数**（如 Stable Diffusion）。朴素贝叶斯看似"古老"，但其"参数即分布"的思想在 Bayesian Deep Learning、Bayesian Optimization 中复活。

**工业视角**：在实际系统中，**判别式分类器（如 XGBoost、神经网络）是工业落地的主力**，因为它们在有限数据下精度更高、训练更快；生成式模型主要用于**数据增强、异常检测、AIGC**​ 等判别式做不好的场景。

## 第2章 学习模型

> 本章是全书的理论基石。杉山将提出了一个极简的统一视角：**机器学习 = 选一个函数族（模型）+ 用数据拟合它**。模型的三大类——线性、核、层级——代表了**函数近似能力的三次跃迁**。

### 2.1 线性模型

**书中定义**：线性模型是**最简单的模型**，形式为：

$$
f_\theta(x)=\sum_{j=1}^{b}\theta_j\phi_j(x)=\theta^{\mathsf T}\phi(x)
$$

其中 $\phi_j(x)$ 是**基函数**。基函数可以是多项式、三角多项式等。

**多维输入的两种扩展**：

```
乘法模型:  f_θ(x) = Σ_{j1}...Σ_{jd} θ_{j1,...,jd} ϕ_{j1}(x^{(1)})···ϕ_{jd}(x^{(d)})
           参数总数 = (b')^d  → 维数灾难，但表现力丰富

加法模型:  f_θ(x) = Σ_{k=1}^{d} Σ_{j=1}^{b'} θ_{k,j} ϕ_j(x^{(k)})
           参数总数 = b'·d  → 复杂度可控，但表现力受限
```

**🎯 第一性原理洞察**

线性模型的本质是**用一组基函数的线性组合去逼近目标函数**。这里有三个关键认知：

1. **"线性"指的是对参数 θ 线性，不是对输入 x 线性**。只要基函数 ϕj​(x) 选得巧妙（如 ϕj​(x)=xj 做多项式），线性模型可以拟合**任意非线性曲线**——它依然是"线性模型"，因为损失函数对 θ 是线性的，可以用闭式解（最小二乘）求出。
2. **乘法模型 vs 加法模型的权衡是全书第一个"偏差-方差"隐喻**：
    - 乘法模型参数随维度**指数爆炸**（维数灾难），但能捕捉特征交叉
    - 加法模型参数**线性增长**，但忽略特征交互
3. **工业界的真相**：今天主流的 LR（Logistic Regression）、FM（Factorization Machine）、Wide&Deep 的 Wide 侧，本质都是线性模型。它们在**推荐、广告、风控**里仍然是主力，原因是：
    - 训练快、可分布式
    - 可解释性强（每个特征的权重清晰）
    - 在特征工程到位的前提下，精度不输复杂模型

```
线性模型的工业定位：
┌─────────────────────────────────────────┐
│  简单问题 / 海量数据 / 需可解释性        │
│  → 线性模型（LR、FM、FTRL）              │
├─────────────────────────────────────────┤
│  复杂问题 / 中等数据 / 可接受黑箱        │
│  → 树模型（GBDT、XGBoost）               │
├─────────────────────────────────────────┤
│  复杂问题 / 海量数据 / 有 GPU            │
│  → 深度学习                              │
└─────────────────────────────────────────┘
```

> ⚠️ 很多人轻视线性模型，但**Facebook 的 LR+GBDT 组合、Google 的 Wide&Deep，核心组件都是线性模型**。线性模型不是"简单过时"，而是"可靠基线 + 可解释性担当"。

### 2.2 核模型

**书中定义**：核模型与线性模型的关键区别在于——**线性模型的基函数与训练样本无关，而核模型的基函数会使用输入样本**。

核模型的形式：

$$
f_\theta(x)=\sum_{j=1}^{n}\theta_j K(x,x_j)
$$

**高斯核**：

$$
K(x,c)=\exp\!\left(-\frac{\lVert x-c\rVert^2}{2h^2}\right)
$$

**核模型的两大优势**：

1. **参数个数不依赖输入维度 d，而由训练样本数 n 决定**——缓解了维数灾难
2. **核映射可扩展**：当输入不是向量时（字符串、决策树、图表），可通过构造两个样本的核函数 $K(x,x^{\prime})$ 来建模

**🎯 第一性原理洞察**

核模型的本质是 **"局部相似度加权"**——预测一个新点时，看它与训练集中每个点的相似度（由核函数度量），相似度高的训练样本拥有更大的投票权。

```
核模型 = 在隐式高维特征空间中做线性学习
         ↓
    核技巧 (Kernel Trick)
         ↓
不用显式计算 Φ(x)，只需计算 K(x,x') = <Φ(x), Φ(x')>
```

**为什么说核模型是"非参数模型"？**

- 参数模型的参数个数**固定**（与训练样本数无关）
- 核模型的参数个数**等于训练样本数 n**——数据越多，参数越多，模型越"灵活"

这就解释了为什么核方法在**小样本、非线性、需要理论保证**的场景表现出色（如 SVM 在小样本分类上的经典优势），但在**大数据**场景下计算量 O(n2) 甚至 O(n3) 成为瓶颈。

**工业视角**：

- **SVM + RBF 核**曾是分类任务的 SOTA，今天仍用于中小数据集、需要 kernel 隐式映射到高维的场景
- **高斯过程（Gaussian Process）**是核模型的贝叶斯版本，在**贝叶斯优化、超参搜索、不确定性估计**中是核心技术
- 但核模型在**超大数据集（百万级以上）**上几乎被深度学习取代，因为核矩阵存不下、算不动

```
核模型的典型应用场景：
┌──────────────────────────────────────────┐
│  小样本 + 需要不确定性估计               │
│  → 高斯过程回归                           │
├──────────────────────────────────────────┤
│  中小样本 + 非线性分类                    │
│  → SVM with RBF kernel                    │
├──────────────────────────────────────────┤
│  非向量数据（图、序列、树）               │
│  → Graph Kernel, String Kernel            │
└──────────────────────────────────────────┘
```

### 2.3 层级模型

**书中定义**：层级模型是**对参数非线性的模型**：

$$
f_\theta(x)=\sum_{j=1}^{b}\alpha_j\phi(x;\beta_j)
$$

其中 $\phi(x;\beta_j)$ 是**含参数向量 $\beta$ 的基函数**。常见的基函数：

- **S 型函数**（Sigmoid）→ 构成**人工神经网络**
- **高斯函数**​ → 与核模型的高斯核形式相同，但**带宽和均值不再是固定的，而是要学习出来的**

**层级模型 vs 核模型的关键区别**：

```
核模型:  高斯核的带宽 h 和均值 c 是固定的，只有耦合系数 θ 被学习
层级模型: 耦合系数 α、带宽 h、均值 c 全部被学习 → 更灵活
```

**🎯 第一性原理洞察**

层级模型的本质是**让基函数本身也成为可学习的**——这是从"用固定基函数去拟合"到"学出最适合数据的基函数"的范式跃迁。

```
模型表达能力递进：

线性模型    基函数固定，参数线性        → 全局单一基
   ↓
核模型      基函数=训练样本，参数线性    → 局部基，但形状固定
   ↓
层级模型    基函数形状也可学习，参数非线性 → 自适应基
   ↓
深度神经网络  多层层级模型堆叠            → 逐层抽象特征
```

**为什么层级模型开启了深度学习的序幕？**

1. **表征学习（Representation Learning）**：层级模型不再依赖人工设计基函数，而是**让数据自己告诉模型"什么样的基函数最有用"**。
2. **参数共享与组合**：深层堆叠后，底层学习边缘/纹理，中层学习部件，高层学习语义——这是 CV、NLP 革命的核心理念。
3. **端到端**：从原始输入直接学到输出，中间的层级自动形成特征层级。

**工业视角**：

```
层级模型的工业演进路径：

1980s-1990s  多层感知机 (MLP)         → 浅层网络，训练困难
2006         Deep Belief Network       → Hinton 开启深度学习
2012         AlexNet                   → CNN 引爆 CV
2014         GAN / VAE                 → 生成式建模
2017         Transformer               → 自注意力统一 NLP/CV
2020s        LLM (GPT/BERT/Claude)    → 规模化定律 (Scaling Law)
```

> 💡 **洞见**：杉山将的层级模型一节，实际上是为后续深度学习埋下的伏笔。理解了"层级模型 = 基函数可学习的非线性模型"，你就能看穿今天所有深度学习架构的统一本质——**它们都是层级模型的不同实例化**。

## 跨章节总洞察：一条主线串起全书

把第1章和第2章连起来看，杉山将其实在讲一个**极简的统一框架**：

```
第1章: 学习 = 任务(T) + 经验(E) + 性能(P) 的闭环
         ↓
第2章: 模型 = 在函数空间中选择一个近似器 $f_\theta(x)$
         ↓
      线性 → 核 → 层级 = 近似器复杂度的三次跃迁
         ↓
第3章开始: 如何用最小二乘法等算法去拟合这些模型
```

**三个第一性原理式的认知**：

1. **所有学习任务都是函数近似**：无论是回归、分类、聚类还是降维，本质都是在估计某个函数 f:X→Y。区别只在输出空间的性质和是否有标签。
2. **模型的三大类是"归纳偏置"的三次松绑**：
    - 线性模型：强偏置（全局线性）→ 高可解释、低方差、高偏差
    - 核模型：中偏置（局部相似）→ 理论优雅、小样本友好
    - 层级模型：弱偏置（自适应基）→ 高表现力、但需要大数据防过拟合
3. **工业选择的本质是对偏差-方差-计算成本的三角权衡**：
    - 数据少、需可解释 → 线性模型
    - 数据中等、要理论保证 → 核模型
    - 数据海量、有 GPU、可接受黑箱 → 层级模型/深度学习

> ⚠️ **给读者的实践建议**：不要盲目追新。在工业落地时，**从线性模型起步**（作为基线），评估是否需要核模型（小数据非线性），最后才考虑深度学习（大数据复杂模式）。这三个模型不是替代关系，而是**工具箱里的不同扳手**。

## 英文补充视角（Beyond the Book）

结合国外经典教材的表述，有几个视角值得叠加进来：

**1. 实例学习与基于模型学习的区分**

国外教材（如 Hastie 的 ESL、Géron 的 Hands-On ML）常把 ML 另分为：

- **Instance-based**（如 KNN、核模型）：记住训练样本，预测时查相似度
- **Model-based**（如线性、层级）：从数据中学出参数化的模型

杉山将的"线性 vs 核"之分，恰好对应这个轴——**线性是基于模型的，核是基于实例的**，层级模型又是基于模型的（但更复杂）。

**2. 在线学习 vs 批量学习**

本书侧重批量学习，但工业界流式场景（如实时推荐、在线广告）必须用在线学习（如 FTRL、Online SVM）。这是本书的局限性，读者需自行补充。

**3. Scikit-learn 的视角**

工业界最广泛使用的 ML 库把模型按任务组织：分类、回归、聚类、降维、模型选择。这与本书第1章的任务分类完全对齐，可作为实践映射。
