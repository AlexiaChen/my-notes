
# 《图解机器学习》读书笔记 · 第5章 稀疏学习

> 第4章我们学了 L2 约束的最小二乘（岭回归）——它能降方差、抗过拟合，但**永远无法把系数压成精确的 0**。这意味着：
> 
> - 50 个基函数，岭回归会用满 50 个，一个都不舍得扔
> - 百万维稀疏特征（推荐/广告场景），岭回归的系数向量也是稠密的——**预测时不得不算满全部特征，算力爆炸**
> 
> 第5章要解决的就是这个痛点：**能不能让模型自己"挑特征"，把不重要的系数精确置零？**
> 
> 答案是 L1 约束——它在数学上是一个非常特殊、也非常优雅的存在。

---

## 5.1 L1 约束的最小二乘学习法

**书中定义**：在最小二乘目标中加入 **L1 范数惩罚**：

$$
J_{\mathrm{L1}}(\theta)=\frac{1}{2n}\sum_{i=1}^{n}\bigl(f_\theta(x_i)-y_i\bigr)^2+\lambda\lVert\theta\rVert_1
$$

其中 $\lVert\theta\rVert_1=\sum_j|\theta_j|$。

**🎯 第一性原理洞察：为什么 L1 能产生稀疏解？**

这是全书最经典的一幅图，用 ASCII 还原二维参数空间的情形：

```
L1 约束 (菱形)                    L2 约束 (圆形)
              θ₂                                θ₂
               ↑                                 ↑
        ●      │      ●                   ●      │      ●
         \     │     /                     \     │     /
          \    │    /                       \    │    /
           \   │   /                         \   │   /
            \  │  /                           \  │  /
             \ │ /                             \ │ /
   ───────────●┼───────────→ θ₁     ───────────●┼───────────→ θ₁
             / │ \                             / │ \
            /  │  \                           /  │ \
           /   │   \                         /   │  \
          /    │    \                       /    │    \
         /     │     \                     /     │     \
        ●      │      ●                   ●      │      ●

   等高线(椭圆)与菱形      等高线(椭圆)与圆
   在"角点"相切 → 某个      在圆弧上相切 →
   θⱼ 精确为 0              两个 θⱼ 都非零
```

**核心机制**：

- L2 的约束域是**光滑的圆/球面**——等高线切点几乎不可能正好落在坐标轴上，所以系数被压缩但**不为 0**
- L1 的约束域是**菱形/超立方体**——它有**尖角**，而尖角恰好**坐落在坐标轴上**。等高线与约束域的切点**极大概率落在角点上** → 对应的参数**精确为 $0$**

> 💡 **洞见**：稀疏性不是 L1 的"副作用"，而是**几何的必然**。L1 约束域的"尖角"天生就长在坐标轴上，而坐标轴的物理意义就是"该特征不参与模型"。这是 L1 区别于所有其他范数的本质特征。

**书中实验**（高斯核模型，50 个基函数）：

- L2 约束：50 个参数**全部非零**
- L1 约束：50 个参数中**37 个精确为 0**，仅用 13 个核函数就拟合出了与 L2 几乎相同的曲线

**工业视角**：

```
L1 稀疏化的工业价值：

稠密模型 (L2):                稀疏模型 (L1):
预测 = θ₁x₁ + θ₂x₂ + ... + θ₅₀x₅₀   预测 = θ₃x₃ + θ₇x₇ + ... + θ₄₂x₄₂
   需要计算 50 次乘法                 只需计算 13 次乘法
   内存: 存储 50 个参数              内存: 存储 13 个参数
   推理延迟: 高                      推理延迟: 降低 74%
```

在推荐/广告的精排场景，特征维度常达**千万级**，L1 稀疏化能让线上推理从"算千万次乘法"降到"算数百次"——**这是 L1 在工业界最致命的吸引力**。

> ⚠️ **前置条件**：L1 对特征尺度极度敏感（$|\theta_j|$ 的大小依赖于 $x_j$ 的量纲）。工业实践中**必须先做标准化**（zero-mean, unit-variance），否则量纲大的特征会被不公平地惩罚。

## 5.2 L1 约束的最小二乘学习的求解方法

**书中挑战**：L1 范数在 $\theta_j=0$ 处**不可导**——传统的"令梯度$=0$求闭式解"失效了。必须引入新的优化工具。

**主流求解算法**：

```
1. 坐标下降法 (Coordinate Descent) — sklearn 默认
   每次只优化一个 θⱼ，固定其他所有参数
   单变量更新规则 = 软阈值函数 (Soft-Thresholding)：
      θⱼ ← S( (1/n)Σᵢ xᵢⱼ·rᵢ⁽ʲ⁾ , λ )
      其中 S(z, γ) = sign(z)·max(|z|-γ, 0)
      
   💡 软阈值的直觉：把"不大重要的"系数直接压成 0
   
2. LARS (Least Angle Regression) — Efron et al. 2004
   高效计算 λ 从 ∞ 到 0 的完整解路径
   适合小样本高维数据
   
3. 近端梯度下降 (Proximal Gradient Descent / ISTA)
   梯度步 + 近端算子(软阈值)
   FISTA 是其加速版本
   
4. ADMM (Alternating Direction Method of Multipliers)
   适合大规模/分布式数据
```

**🎯 第一性原理洞察：软阈值函数就是 L1 的"灵魂"**

```
软阈值函数 S(z, λ):

   S(z,λ)
     │
   λ  ─────────●───────────  (z > λ)
     │        /|
     │       / |
     │      /  |
   0 ──────●───┼───────●─── z
     │    -λ   |       λ
     │    /|   |
     │   / |   |
  -λ ───●  |   |
     │    |   |
     ↓    ↓   ↓
   压成0  线性收缩  压成0
  (|z|≤λ) (|z|>λ)
```

**这个简单的函数揭示了 L1 的本质操作**：

- 当某特征的"信号强度" $|z|\le\lambda$ 时 → **直接归零**（特征被剔除）
- 当信号强度 $|z|>\lambda$ 时 → **向零收缩 $\lambda$**（保留但被惩罚）

对比 L2 的更新规则：$\theta_j\leftarrow\frac{1}{1+\lambda}\theta_j^{\mathrm{LS}}$ —— 永远是**按比例缩小**，永远不会精确归零。

> 💡 **洞见**：L1 求解器的核心，本质上就是在反复应用**软阈值函数**。坐标下降法是逐特征应用，近端梯度是全局应用后再逐特征修正。**所有 L1 求解算法的"魔法"都浓缩在这个 5 行的数学公式里**。

**与第4章的承接**：

```
第4章 L2:  目标函数可导 → 闭式解 θ = (ΦᵀΦ+λI)⁻¹Φᵀy
第5章 L1:  目标函数不可导 → 迭代求解 (坐标下降/ADMM/近端梯度)
                              ↓
              代价: 失去闭式解的优雅
              收获: 稀疏性 + 特征选择 + 工业级可部署
```

**工业视角**：

```
工业级 L1 求解选型：

sklearn (中小数据):      CoordinateDescent (LassoCV 默认)
R 语言 glmnet:           CoordinateDescent (Friedman et al.)
Matlab (大数据):         ADMM
Spark MLlib:             OWL-QN (正交拟牛顿法)
分布式场景:              ADMM / 参数服务器 + 异步坐标下降
```

> ⚠️ **工程经验**：坐标下降法看似朴素，但凭借"单变量闭式解 + 软阈值"的组合，它在实际中**往往比其他"高级"优化器更快收敛**。这也是为什么 sklearn 的 `Lasso` 默认用它。

## 5.3 通过稀疏学习进行特征选择

**书中动机**：传统的特征选择方法（向前选择、向后删除）需要评估 2d 种特征组合——**计算量随特征数 d 指数爆炸**，工业界不可行。

**L1 的颠覆性**：L1 正则化把特征选择**嵌入到了模型训练的过程中**——你不需要单独做特征选择，模型在拟合参数的同时**自动完成选择**。

```
传统特征选择:                     L1 特征选择:
                                   
   评估 2^d 种组合  ← 不可行!      训练带 L1 惩罚的模型
        ↓                          ↓
   选出最优子集                    系数=0 的特征自动剔除
        ↓                          ↓
   用子集重新训练                  一步到位
   
   复杂度: O(2^d)                  复杂度: O(nd·迭代次数)
```

**🎯 第一性原理洞察：L1 特征选择的统计本质**

L1 特征选择等价于假设参数服从 **Laplace 先验**（双指数分布）：

```
Laplace 先验 P(θ) ∝ exp(-λ|θ|):
                                   
     P(θ)
      │
      │   ╱╲
      │  ╱  ╲
      │ ╱    ╲
      │╱      ╲
      ●────────●──→ θ
     -1/λ    1/λ
      
   峰值在 θ=0 → 先验"偏好"系数为 0
   即: 模型先验认为"大多数特征不重要"
```

与之对比，L2 对应 **Gaussian 先验**（钟形曲线，峰值在 0 但不尖锐）→ 系数被拉向 0 但**不精确为 0**。

**这就是为什么 L1 是"特征选择"，L2 只是"系数收缩"**——它们在贝叶斯框架下对应完全不同的先验信念。

**工业案例**：

1. **基因数据分析**：数万个基因（特征）但样本仅几百例 → L1 自动识别出与疾病相关的关键基因子集
2. **遥感影像 RPC 模型修正**：Long et al. (2015) 用 L1LS 方法对有偏 RPC 模型进行全参数修正，部分 RPC 参数的改正量被压缩为 0，在地面控制点较少的条件下实现了参数的直接优化
3. **金融风控**：从几千个交易特征中选出几十个真正有预测力的，满足监管可解释性要求
4. **推荐系统特征筛选**：从海量用户行为特征中自动选出核心特征，降低线上推理成本

> 💡 **洞见**：L1 特征选择的真正威力不在于"选得准"，而在于"**选得快且可扩展**"。它的计算复杂度是多项式级的，而穷举法是指数级的——这是它能工业落地的根本原因。

## 5.4 Lp 约束的最小二乘学习法

**书中推广**：L1 和 L2 是 Lp 范数家族的两个特例：

$$
\lVert\theta\rVert_p=\left(\sum_j|\theta_j|^p\right)^{1/p}
$$

**Lp 单位球的形状随 p 变化的规律**：

```
p = ∞ (最大值范数):     立方体 (超矩形)
     
p = 2 (L2):              ○ 圆/球 (光滑凸集)
     │
p = 1 (L1):              ◇ 菱形/八面体 (有尖角)
     │
p < 1:                   ✦ 星形/十字形 (非凸!)
     │
p = 0 (L0):              非零元素个数 (离散, 极难优化)
```

**🎯 第一性原理洞察：为什么"只有 L1 是特殊的"？**

书中给出了一个极深刻的结论——**同时满足以下两个条件的约束才能既凸又产生稀疏解**：

```
条件 1: 约束空间为凸形  → 保证优化问题是凸优化 (可解)
条件 2: 坐标轴上有尖点  → 保证解落在坐标轴上 (稀疏)

     p > 1:  凸形 ✓   但光滑 ✗  → 不稀疏 (如 L2)
     p = 1:  凸形 ✓   有尖点 ✓  → 既凸又稀疏 ★
     p < 1:  有尖点 ✓  但非凸 ✗  → 稀疏但 NP-hard
```

> 💡 **洞见**：L1 是 Lp 范数家族中**唯一的"甜点"**——它是在"可优化的凸性"与"可稀疏的尖点"之间的**唯一交集**。p<1 虽然理论上更稀疏，但优化问题变成非凸的，容易陷入局部最优；p>1 虽然是凸的，但失去了稀疏性。

**这解释了为什么 L1 在历史上胜出**：

- L0 约束（直接最小化非零元素个数）是最直观的稀疏化方法，但是**NP-hard**
- L1 是 L0 的**凸松弛（Convex Relaxation）**——用凸优化问题去近似这个 NP-hard 问题
- 在很多情况下，L1 的解与 L0 的解**完全一致**（Donoho 的压缩感知理论证明了这一点）

**工业视角**：

```
稀疏优化的演进路径：

L0 约束 ──(NP-hard, 不可解)──→ 放弃
   ↓
L1 约束 ──(凸松弛, 可解)──→ Lasso (本书第5章)
   ↓
Lp (0<p<1) ──(非凸但更稀疏)──→ 近年研究热点
   代表: MCP, SCAD 等非凸惩罚
   工业应用: 仍在学术界探索阶段
```

> ⚠️ **实践忠告**：工业界**默认用 L1**，不要试图用 p<1 的约束——非凸优化的不稳定性和调参难度远超其理论收益。除非你在做学术研究或极端高维场景。

## 5.5 L1+L2 约束的最小二乘学习法（弹性网络）

**书中动机**：L1 虽好，但有两大局限：

```
局限 1: 当参数数 b > 训练样本数 n 时，
        L1 最多只能选出 n 个非零特征
        → 特征数超过样本数时"不够用"

局限 2: 当特征间高度相关 (集群构造) 时，
        L1 会随机挑一个、抛弃其他
        → 选择结果不稳定，且丢失相关信息
```

**弹性网络（Elastic Net）的解法**：同时使用 L1 和 L2 惩罚：

$$
J_{\mathrm{EN}}(\theta)=\frac{1}{2n}\lVert y-\Phi\theta\rVert_2^2
+\lambda\left(\frac{1-\rho}{2}\lVert\theta\rVert_2^2+\rho\lVert\theta\rVert_1\right)
$$

其中 $\rho\in[0,1]$ 控制 L1/L2 的混合比例。

**约束域的形状**：

```
ρ=1 (纯 L1)              ρ=0.5 (弹性网络)         ρ=0 (纯 L2)
            θ₂                       θ₂                       θ₂
             ↑                        ↑                        ↑
      ●      │      ●          ●     ╱│╲     ●          ●      │      ●
       \     │     /            \   ╱ │ ╲   /            \     │     /
        \    │    /              \ ╱  │  ╲ /              \    │    /
         \   │   /                \╱   │   ╱                \   │   /
          \  │  /                 ●────●──●──→ θ₁             \  │  /
           \ │ /                 /╲    │   ╱╲                 \ │ /
            \|/                 /  ╲   │  ╱  ╲                \|/
             ●                      ●──●                      ●
           
   尖角+凸 → 稀疏              圆角菱形 → 既稀疏又稳定      光滑圆 → 不稀疏
```

**🎯 第一性原理洞察：弹性网络 = 稀疏性 × 稳定性**

弹性网络同时获得了两个世界的最佳：

```
特征选择能力          稳定性          可选特征上限
L1 (ρ=1):     ★★★★            ★★             ≤ n
L2 (ρ=0):     ✗                ★★★★          无限制
Elastic Net:  ★★★              ★★★            > n (突破 L1 的 n 限制)
```

**三个关键优势**：

1. **突破 n 个特征的瓶颈**：弹性网络可以选择**超过 n 个**非零特征（L1 做不到）
2. **处理特征集群**：当多个特征高度相关时，弹性网络**倾向于把它们作为一个组一起选中**（L1 只会随机选一个）
3. **兼具稀疏与稳定**：L1 负责稀疏化，L2 负责在相关特征间**均匀分配权重**

**几何直觉**：弹性网络的约束域是"带圆角的菱形"——**既有尖角（保证稀疏），又有弧度（保证稳定）**。

**工业视角**：

```
弹性网络的工业定位：

场景 1: 特征数 >> 样本数 (p >> n)
   → 纯 L1 最多选 n 个特征，可能不够
   → 弹性网络 (ρ≈0.5-0.7) 可以选更多特征
   
场景 2: 特征高度相关 (如推荐系统中的用户相似行为特征)
   → 纯 L1 随机选择，结果不稳定
   → 弹性网络 (ρ≈0.5) 把相关特征作为组一起选入
   
场景 3: 基因数据 (数万特征, 几百样本, 基因高度相关)
   → 弹性网络是事实标准
   → Zou & Hastie (2005) 原始论文的杀手锏应用
   
场景 4: 精排模型的特征选择
   → 弹性网络 + 交叉验证 是工业级标配
   → sklearn 的 ElasticNetCV 自动化整个流程
```

> 💡 **实践法则**（基于工业经验）：
> 
> - $\rho=1.0$：纯 Lasso，追求极致稀疏
> - $\rho=0.5$：L1/L2 各半，**工业界最常用的默认值**
> - $\rho=0.1\sim0.3$：接近 Ridge，但保留轻微稀疏性
> - 用 ElasticNetCV 自动搜索 $(\alpha,\rho)$ 的最优组合

## 跨章节总洞察：稀疏学习在全书的位置

把第4章和第5章连起来看，杉山将其实在讲一个**正则化谱系**：

```
第4章: L2 约束 (岭回归)
       min ‖Φθ-y‖² + λ‖θ‖₂²
       解: 闭式解 θ = (ΦᵀΦ+λI)⁻¹Φᵀy
       特性: 凸、可导、系数收缩但不为 0
       角色: 降方差、抗过拟合
       
第5章: L1 约束 (Lasso)
       min ‖Φθ-y‖² + λ‖θ‖₁
       解: 迭代法 (坐标下降/ADMM/近端梯度)
       特性: 凸、不可导、系数精确为 0
       角色: 特征选择 + 降方差 + 工业可部署
       
第5章: L1+L2 约束 (弹性网络)
       min ‖Φθ-y‖² + λ(ρ‖θ‖₁ + (1-ρ)‖θ‖₂²/2)
       解: 坐标下降的扩展
       特性: 凸、系数稀疏、对相关特征友好
       角色: L1 与 L2 的优势融合
```

**三个第一性原理式的认知**：

1. **稀疏性 = 几何的必然，不是算法的技巧**。L1 约束域的尖角生长在坐标轴上，这是它产生稀疏解的根本原因。任何其他范数要么不可凸优化（$p<1$），要么不产生稀疏（$p>1$）。
2. **L1 求解的"灵魂"是软阈值函数**。所有的 L1 优化器——坐标下降、LARS、近端梯度、ADMM——本质上都在反复应用 $S(z,\lambda)=\operatorname{sign}(z)\max(|z|-\lambda,0)$。理解了这个，就理解了 L1 优化的全部。
3. **正则化谱系是"偏差-方差-稀疏性"的三维权衡**：
    - L2：高偏差、低方差、稠密解
    - L1：中偏差、中方差、**稀疏解**
    - Elastic Net：中偏差、低方差、**稀疏解 + 稳定性**

**与工业深度学习的关系**：

```
传统机器学习:                    深度学习:
L1/L2 正则化  ←─── 对应 ───→  Weight Decay (L2)
                                      ↓
Elastic Net  ←─── 对应 ───→  ? (深度学习中鲜少使用 L1)
                                      ↓
                              Dropout (隐式正则化)
                              Batch/Layer Norm (隐式约束)
                              
缺口: 深度神经网络中如何做"特征选择"?
   → 答案: 剪枝 (Pruning)、量化 (Quantization)
   → 本质: 就是 L1 稀疏化思想在深度网络中的延伸
```

> 💡 **终极洞见**：今天大模型领域的 **模型压缩（Model Compression）**、**稀疏 MoE**、**LoRA 的低秩约束**——追根溯源，都是第5章思想的延伸。L1 稀疏化、弹性网络的选择稳定性，在 Transformer 时代以"稀疏激活"、"低秩适配"的新面貌复活。**第5章看似在处理"线性模型的稀疏性"，实则奠定了整个压缩学习领域的理论基础**。

## 英文补充视角（Beyond the Book）

**1. Lasso 的统计基础**（Tibshirani 1996 原始论文）：

- Lasso = L1 penalized least squares
- 在正交设计下，Lasso 解有显式闭式解：$\hat{\beta}_j=\operatorname{sign}(\hat{\beta}_j^{\mathrm{LS}})\max\bigl(|\hat{\beta}_j^{\mathrm{LS}}|-\lambda,0\bigr)$
- 这解释了为什么软阈值函数是 Lasso 的"原子操作"

**2. Elastic Net 的提出**（Zou & Hastie 2005, JRSSB）：

- 解决 Lasso 在 p >> n 和特征相关时的两大局限
- 弹性网络可以选择超过 n 个特征
- 在相关特征间均匀分配权重（"grouping effect"）

**3. 求解算法的演进**：

- **Coordinate Descent**（Friedman et al. 2010）：glmnet 包的核心，sklearn 默认
- **ADMM**（Boyd 2011）：适合大规模分布式数据
- **ISTA/FISTA**（Beck & Teboulle 2009）：近端梯度方法，理论性质优美

**4. 工业级实现**：

- **MathWorks MATLAB**：坐标下降 + 大数据时用 ADMM
- **sklearn**：`Lasso` (坐标下降), `ElasticNet` (坐标下降), `LassoCV/ElasticNetCV` (交叉验证)
- **R glmnet**：坐标下降的事实标准实现

**5. 现代扩展**：

- **Group Lasso**：结构化的 L1（一组特征要么全选要么全不选）
- **Sparse Group Lasso**：组间 L1 + 组内 L1
- **MCP / SCAD**：非凸惩罚，比 L1 更激进的稀疏化
