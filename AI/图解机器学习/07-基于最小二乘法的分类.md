## 7.1 最小二乘分类

**书中定义**：把分类问题看作函数近似问题，通过在分类器构造中应用最小二乘法。

**二分类的情形**：

标签编码为 $y\in\{+1,-1\}$，学习一个判别函数 $f_\theta(x)$。预测时由**符号**决定类别：

$$
\hat{y}=\operatorname{sign}\bigl(f_\theta(x)\bigr)=
\begin{cases}
+1, & f_\theta(x)>0,\\
0, & f_\theta(x)=0,\\
-1, & f_\theta(x)<0.
\end{cases}
$$

**训练标签的特殊设定**（书中的关键洞见）：

把训练输出 $y_i$ 由 $\{+1,-1\}$ 改为 **$\{+1/n_+,-1/n_-\}$**，其中 $n_+$ 和 $n_-$ 分别代表正训练样本和负训练样本的个数。

> 💡 通过这样的设定，使用最小二乘学习进行模式识别，**与线性判别分析（LDA）算法就是一致的**。在 LDA 中，当正负两类样本的模式都服从协方差矩阵相同的高斯分布时，可以获得最佳的泛化能力。

**🎯 第一性原理洞察：最小二乘分类 = 回归 + 符号截断**

```
最小二乘分类的本质：

  回归视角:                   分类视角:
  y ∈ ℝ (连续)                y ∈ {+1, -1} (离散)
       ↓                           ↓
  最小化 ‖Φθ - y‖²           学习 f_θ(x)
       ↓                           ↓
  输出 f_θ(x) ∈ ℝ            预测 ŷ = sign(f_θ(x))
       ↓                           ↓
  把连续输出                 在 0 处"一刀切"
  当作分类分数
```

**决策边界的几何意义**：

```
f_θ(x) > 0 的区域 (预测 +1)
                    │
                    │
   ● ● ● ● ● ● ●    │    ○ ○ ○ ○ ○ ○ ○
   ● ● ● ● ● ● ●    │    ○ ○ ○ ○ ○ ○ ○
   ● ● ● ● ●        │───●────────────── 决策边界: f_θ(x) = 0
   ● ● ● ● ● ●      │    ○ ○ ○ ○ ○
                    │    ○ ○ ○ ○ ○ ○ ○
                    │
              f_θ(x) < 0 的区域 (预测 -1)

   |f_θ(x)| 的大小 = 到决策边界的距离
   → 可用于衡量"置信度"（但不是概率！）
```

**闭式解**（沿用第3章的结论）：

$$
\hat{\theta}_{\mathrm{LS}}=(\Phi^{\mathsf T}\Phi)^{-1}\Phi^{\mathsf T}y
$$

其中 $y$ 是编码后的标签向量（$\{+1/n_+,-1/n_-\}$）。

**最小二乘分类的特性**：

|特性|说明|
|---|---|
|计算效率|有闭式解，O(b³) 或 SGD 迭代|
|可解释性|线性模型的权重直接可读|
|决策边界|线性（或核技巧后非线性）|
|输出性质|实数分数，**不是概率**|
|离群点敏感度|**高**（继承自L2损失）|

**🎯 深度洞见：为什么最小二乘分类"有效但不够好"？**

最小二乘分类有一个**根本性的目标不匹配**：

```
真正想要:  最小化分类错误率 → 0/1损失
实际优化:  最小化平方误差 → L2损失

矛盾: L2损失会"过度惩罚"那些已经正确分类但分数很远的样本
```

举例说明（来自 Bishop PRML 的经典例子）：

```
假设某样本 y=+1，模型输出 f_θ(x)=11
  → L2损失 = (11-1)² = 100  （巨大！）
  → 但实际上这个样本已经被正确分类了，且置信度高

再假设某样本 y=+1，模型输出 f_θ(x)=0.5
  → L2损失 = (0.5-1)² = 0.25  （很小）
  → 但这个样本就在决策边界旁边，分类其实很不稳

L2损失在"奖励"那些模棱两可的预测！
```

这就是为什么最小二乘分类**对离群点极其敏感**——一个远处的错误样本会产生巨大的平方误差，把决策边界"拽"过去。

**工业视角**：

```
最小二乘分类的工业定位：

✓ 适合作为:
  - 分类任务的"基线模型"（baseline）
  - 可解释的线性打分卡（如传统信用评分）
  - 大规模线性分类（配合 SGD/FTRL）
  - 特征工程的快速验证

✗ 不适合作为:
  - 最终的工业级分类器（精度不如 SVM/GBDT/神经网络）
  - 需要概率输出的场景（如风险评估需要 P(y=1|x)）
  - 数据含离群点的场景（如欺诈检测）
  - 类别不平衡严重的场景

工业案例:
  - 传统信用评分卡: 线性打分 + 人为设定阈值
  - 简单文本分类: TF-IDF + 最小二乘分类
  - 推荐系统的二分类CTR预估早期: 线性回归 + 截断
  - 在线广告的初筛层: 线性分类器快速过滤明显负样本
```

> ⚠️ **工业经验**：今天工业界几乎**不会**用纯最小二乘做最终分类器——它的位置被 Logistic 回归（概率输出）、SVM（间隔最大化）、GBDT（非线性+鲁棒）取代。但最小二乘分类作为**基线**和**可解释模型**仍有价值。

## 7.2 0/1 损失和间隔

**书中定义**：分类问题用 0/1 损失比 L2 损失更合适，因为分类只关心符号，不关心函数值的大小。

**0/1 损失的定义**：

$$
L_{0/1}(\theta)=\frac{1}{2n}\sum_{i=1}^{n}\left(1-\operatorname{sign}\bigl(f_\theta(x_i)y_i\bigr)\right)
$$

等价于指示函数：

$$
\delta\!\left(\operatorname{sign}(f_\theta(x))\ne y\right)=
\begin{cases}
1, & \operatorname{sign}(f_\theta(x))\ne y,\\
0, & \operatorname{sign}(f_\theta(x))=y.
\end{cases}
$$

**间隔（Margin）的概念**：

定义第 $i$ 个样本的间隔为 **$m_i=f_\theta(x_i)y_i$**。

- $m_i>0$：分类正确（$f_\theta(x_i)$ 与 $y_i$ 同号）
- $m_i\le0$：分类错误

**0/1 损失用间隔表示**：

```
L0/1(m) = { 0  if m > 0
          { 1  if m ≤ 0

损失值
  │
 1├───────●━━━━━━━━━━━━━━━ m ≤ 0 (分类错误)
  │       │
  │       │
 0├───────●━━━━━━━━━━━━━━━ m > 0 (分类正确)
  └───────┼────────────────→ 间隔 m
        0
```

**L2 损失用间隔表示**（关键推导）：

由于 $y^2=1$，L2 损失可重写为：

$$
r^2=\bigl(y-f_\theta(x)\bigr)^2
=\bigl[y\bigl(1-f_\theta(x)y\bigr)\bigr]^2
=y^2\bigl(1-f_\theta(x)y\bigr)^2
=(1-m)^2
$$

其中 $m=f_\theta(x)y$ 是间隔。

**L2 损失 vs 0/1 损失的对比**：

```
损失值
  │
  │ L2: (1-m)²
  │        ╱╲
  │       ╱  ╲
  │      ╱    ╲
  │     ╱      ╲
  │    ╱        ╲___
 1├──●──────────●───────── m=1
  │  ╱            ╲
  │ ╱              ╲
 0├●────────────────●──── m=0
  │                    
  └────────────────────→ 间隔 m
  -2  -1   0   1   2

  L2损失: 在 m>1 后仍然增长 → 惩罚"过度正确"
  0/1损失: 在 m>0 后恒为0 → 只关心对错
```

**代理损失（Surrogate Loss）的概念**：

0/1 损失虽然理想，但**不可导、不连续、难以优化**。因此实际应用中使用**代理损失**来计算：

```
理想的损失:             L0/1(m) = {0 if m>0; 1 if m≤0}
                              ↓
代理损失（各种"软化"版本）:
  ┌─ L2损失 (m-1)²         → 最小二乘分类（本章）
  ├─ Hinge损失 max(0,1-m)  → SVM（第8章）
  ├─ Ramp损失              → 鲁棒学习（第8章6节）
  ├─ 指数损失 exp(-m)      → Boosting（第9章）
  └─ Logistic损失 log(1+e^-m) → Logistic回归（第10章）
```

**代理损失的几何对比**：

```
损失值
  │
  │  L2: (1-m)²
  │        ╱╲
  │       ╱  ╲___
  │      ╱        ╲
 1├──●───┼─────────●── Hinge: max(0,1-m)
  │  ╱   │        │╲
  │ ╱    │        │ ╲
 0├●─────┼────────┼──●── m
  │    0│       1 │
  │     │        │
  │     │        │
  │     ●────────●── Ramp损失
  │    ╱          ╲
  │   ╱            ╲
  │  ╱              ╲
  │ ╱                ╲
  └────────────────────→ 间隔 m
 -2 -1  0   1   2   3
```

**🎯 第一性原理洞察：为什么"间隔"是分类的核心概念？**

0/1 损失只关心 $m$ 的符号，但优化时我们优化的是代理损失。不同的代理损失体现了对"间隔"的不同态度：

```
代理损失对间隔的态度：

L2损失:      希望 m 越大越好（无上限）
             → 过度自信，对离群点敏感

Hinge损失:   希望 m ≥ 1（达到即可）
             → 适度自信，间隔最大化

Ramp损失:    希望 m ≥ 1，且对极端错误鲁棒
             → 鲁棒间隔最大化

指数损失:    希望 m 越大越好（指数级奖励）
             → 极度自信，但容易被离群点带偏

Logistic损失: 希望 m 越大越好（对数级奖励）
             → 概率解释，温和自信
```

> 💡 **洞见**：这一节是整本书的"枢纽"——**后续的 SVM (Hinge)、Boosting (指数)、Logistic回归 (Logistic)** 全部可以统一到"0/1损失的代理损失"这个框架下。理解了这一点，你会发现第8、9、10章其实是同一件事的不同变体。

**工业视角**：

```
代理损失在工业界的选择：

线性分类 + 需要概率:
  → Logistic损失 (Logistic回归)
  → 工业标准: 信用评分、CTR预估、医学诊断

线性分类 + 最大间隔:
  → Hinge损失 (SVM)
  → 中小数据集的分类首选

集成分类 + 指数损失:
  → AdaBoost
  → 人脸检测 (Viola-Jones) 的经典选择

鲁棒分类 + Ramp损失:
  → 鲁棒SVM
  → 离群点多的场景（如欺诈检测）

回归损失用于分类（本章）:
  → L2损失
  → 仅作基线，工业中少用
```

> ⚠️ **关键认知**：L2损失是0/1损失的**糟糕代理**——它在 $m>1$ 时继续增长，导致模型过度关注那些"已经分对的远处样本"，而忽视那些"在决策边界附近的不确定样本"。这违背了分类的本质——我们更应该关注边界附近的点。

## 7.3 多类别的情形

**书中提出的方法**：利用二类别模式识别算法识别多分类。

**方法一：一对多法（One-vs-Rest, OvR）**

```
对于 c 个类别，训练 c 个二分类器：
  分类器 1: 类别1 vs 其他所有 (标签: +1/-1)
  分类器 2: 类别2 vs 其他所有 (标签: +1/-1)
  ...
  分类器 c: 类别c vs 其他所有 (标签: +1/-1)

预测时:
  f̂₁(x), f̂₂(x), ..., f̂c(x)
  预测类别 ŷ = argmax f̂ⱼ(x)
             j∈{1,...,c}
```

ASCII 示意图：

```
三分类问题 (c=3):

  类别1 ● ● ●          训练分类器1: ● ● ● vs ○ ○ ○ + △ △ △
            │
  类别2 ○ ○ ○           训练分类器2: ○ ○ ○ vs ● ● ● + △ △ △
            │
  类别3 △ △ △           训练分类器3: △ △ △ vs ● ● ● + ○ ○ ○

  预测新样本 x:
    f̂₁(x) = +2.5
    f̂₂(x) = +0.3
    f̂₃(x) = -1.2
    → ŷ = argmax = 1 (类别1)
```

**方法二：一对一法（One-vs-One, OvO）**

```
对于 c 个类别，训练 c(c-1)/2 个二分类器：
  每两个类别之间训练一个分类器

预测时:
  每个分类器投票，多数票获胜
```

```
三分类问题 (c=3) 需要 3 个分类器:

  分类器1₂: 类别1 vs 类别2
  分类器1₃: 类别1 vs 类别3
  分类器2₃: 类别2 vs 类别3

预测新样本 x:
  分类器1₂ → 投给 类别1
  分类器1₃ → 投给 类别3
  分类器2₃ → 投给 类别3
  → 多数票: 类别3 胜出
```

**🎯 第一性原理洞察：多类最小二乘的"掩蔽问题"**

Bishop PRML 指出了最小二乘多类分类的一个**根本性缺陷**——**掩蔽（Masking）**：

```
当类别数 K > 2 时，某些决策区域会变得非常小甚至消失
```

为什么？因为最小二乘分类的判别函数是：

$$
y_k(x)=w_k^{\mathsf T}x+w_{k0}
$$

对于 $K$ 个类别，我们有 $K$ 个线性函数。决策边界是 $y_k(x)=y_j(x)$ 的直线。问题在于：

```
K=3 的情形:

  y₁(x) 平面          y₂(x) 平面          y₃(x) 平面
     ╱                    ╱                    ╱
    ╱                    ╱                    ╱
   ╱                    ╱                    ╱
  ╱                    ╱                    ╱

  取 max 后的决策区域:
  ┌─────────────────────────────────────┐
  │ ■ ■ ■ │ ○ ○ ○ │ △                   │
  │ ■ ■ ■ │ ○ ○ ○ │                     │
  │ ■ ■ ■ │ ○ ○ ○ │ ○ ○ ○               │
  │ ■ ■ ■ │ ○ ○ ○ │ △ △ △               │
  │ ■ ■ ■         │ △ △ △               │
  │                │ △ △ △               │
  │                │ △ △ △               │
  └─────────────────────────────────────┘
   类别1区域大      类别2区域中   类别3区域小!
                                    ↑
                                被"掩蔽"了
```

**原因**：在最小二乘框架下，所有类别共用同一个特征空间的正交基。当某个类别的样本数少、或与其它类别的高度重叠时，其判别函数的系数会被"压制"——导致该类别的决策区域变得极小甚至消失。

**OvR vs OvO 的对比**：

|维度|一对多 (OvR)|一对一 (OvO)|
|---|---|---|
|分类器数量|c|c(c-1)/2|
|训练样本/分类器|全部样本|两类样本|
|类别不平衡|**严重**（正类远小于负类）|缓解（两类平衡）|
|预测速度|快（c 次评估）|慢（c(c-1)/2 次评估）|
|掩蔽问题|可能发生|减少发生|
|工业偏好|**默认选择**（简单高效）|特定场景（如 SVM 多类）|

**工业视角**：

```
多类分类的工业实践：

1. 类别数 c 较小 (< 10):
   → OvR + Logistic回归 (工业标准)
   → 每个类别训练一个二分类器，输出概率

2. 类别数 c 中等 (10~1000):
   → OvR + 适当的基分类器
   → 或用 softmax 回归 (直接多类)
   
3. 类别数 c 很大 (1000+，如 ImageNet 1000类):
   → 深度神经网络 + Softmax
   → 最小二乘/OvR 完全不适用

4. 类别极度不平衡:
   → OvR + 类别权重调整
   → 或用一对一法

工业案例:
  - 文本分类 (新闻归类): OvR + Logistic回归
  - 图像分类: 深度 CNN + Softmax
  - 推荐系统多类目: OvR + GBDT
  - 语音识别声学模型: 深度神经网络 + Softmax
```

> 💡 **洞见**：多类最小二乘分类的真正问题在于——它**强行用回归的思维做分类**。当类别数增多时，这种"思维错位"被放大：
> 
> - 回归假设输出是连续的 → 但类别是离散的
> - 回归假设误差是加性的 → 但分类错误是对等的
> - 回归假设高斯噪声 → 但分类标签是确定的
> 
> 这也是为什么现代多类分类更倾向于用 **softmax 回归**（概率框架）或 **深度神经网络**（表示学习框架），而不是多类最小二乘。

## 跨章节总洞察：最小二乘分类在全书的位置

把第7章放入全书的脉络中：

```
第3章: 最小二乘回归
       min ‖Φθ - y‖²
       闭式解，对离群点敏感
       
第4章: L2约束最小二乘 (降方差)
第5章: L1约束最小二乘 (稀疏)
第6章: 鲁棒最小二乘 (抗离群点)
        ↓
第7章: 最小二乘分类 ★
       把回归的损失用于分类
       有效但目标不匹配
        ↓
       引出三个改进方向:
       ┌─ 第8章: 换损失函数 (Hinge) → SVM
       ├─ 第9章: 集成多个弱分类器 → Boosting
       └─ 第10章: 概率框架 → Logistic回归
```

**三个第一性原理式的认知**：

1. **最小二乘分类的本质是"目标错配"**。分类真正关心的是0/1损失（只问对错），但最小二乘优化的是L2损失（关心分数远近）。这种错配导致：
    - 模型过度关注已正确分类的远处样本
    - 对离群点极度敏感
- $|f_\theta(x)|$ 不是校准的概率
2. **间隔是分类的统一语言**。0/1损失的代理损失家族（Hinge、Ramp、指数、Logistic、L2）全部可以用间隔 $m=f_\theta(x)y$ 来表达。**后续第8、9、10章的所有分类算法，本质上都是"间隔"的不同化身**。
3. **多类分类暴露了最小二乘的根本局限——掩蔽问题**。这揭示了用回归做分类的深层矛盾：分类是离散的、对称的、确定的；回归是连续的、非对称的、概率的。当类别增多时，这种矛盾不可调和，必须切换到专门的多类框架（softmax、深度网络）。

**与工业深度学习的关系**：

```
传统最小二乘分类:              深度学习的分类:
线性判别函数 f_θ(x)      ←→   Softmax 层的 logits
sign(f_θ(x)) 决策         ←→   argmax(softmax(logits))
L2损失 (1-m)²            ←→   Cross-Entropy Loss
                                     ↓
                           -∑ yᵢ log(softmax(f_θ(x))ᵢ)
                           
本质区别:
  最小二乘分类: 用回归损失做分类 (目标错配)
  CE + Softmax: 用概率框架做分类 (目标匹配)
  
工业现实:
  今天几乎所有的神经网络分类器都用 Cross-Entropy
  + Softmax，而不是最小二乘分类
  → 因为 CE 直接优化 0/1 损失的连续可微上界
  → 而 L2 损失不是 0/1 损失的紧上界
```

> 💡 **终极洞见**：第7章看似在讲"如何用最小二乘做分类"，实则在讲**"为什么最小二乘不适合做分类"**。杉山将通过展示最小二乘分类的有效性和局限性，为后续三章（SVM、集成、概率分类）铺设了完美的伏笔。**这一章是"反面教材"，但比正面教材更有价值**——它告诉你什么路走不通，以及为什么后来者要换一条路。

## 英文补充视角（Beyond the Book）

**1. Bishop《Pattern Recognition and Machine Learning》第4章**：

- 明确指出最小二乘分类的掩蔽（masking）问题
- 展示了最小二乘分类对离群点的敏感性（图4.4）
- 提出用概率生成模型（LDA）或判别模型（Logistic回归）作为替代

**2. 最小二乘分类与 Fisher LDA 的等价性**：

- 当训练标签设为 {+1/n_+, -1/n_-} 时，最小二乘分类 ≡ Fisher LDA
- 这一等价性在统计学中被称为"判别分析的最小二乘形式"
- 前提是各类别协方差矩阵相等（高斯假设）

**3. 代理损失的理论框架**：

- 0/1 损失是分类的理想目标，但 NP-hard 不可优化
- 代理损失必须满足：凸、连续、在 0/1 损失上方（surrogate bound）
- 不同代理损失对应不同算法：
    - Hinge → SVM
    - 指数 → AdaBoost
    - Logistic → Logistic回归
    - L2 → 最小二乘分类（最松的bound）

**4. 现代多类分类方法**：

- **Softmax 回归**：直接建模 P(y=k|x)，避免掩蔽问题
- **深度神经网络**：末端 Softmax + Cross-Entropy
- **多类 SVM**：Crammer-Singer 形式，直接优化多类间隔
- **Error-Correcting Output Codes (ECOC)**：将多类分解为多个二类问题

**5. 工业级实现**：

- sklearn: `LinearRegression` + `sign()` 可作基线
- 实际工业分类: `LogisticRegression` (OvR), `SGDClassifier` (OvR), `RandomForestClassifier`, `XGBClassifier`
- 深度学习: PyTorch `nn.CrossEntropyLoss` + `nn.LogSoftmax`

```
分类的真正目标: 0/1损失最小化
       ↓

  ┌─ L2损失 → 最小二乘分类 (本章, 目标错配)
  ├─ Hinge损失 → SVM (第8章, 间隔最大化) ★
```
