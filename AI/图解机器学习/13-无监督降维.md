
# 《图解机器学习》读书笔记 · 第13章 无监督降维

> 前两章我们处理了**有结构的数据**——序列（第11章）和有标签的异常（第12章）。第13章进入无监督学习的核心战场之一：**降维**。
> 
> 为什么要降维？工业数据动辄千维、万维、百万维——图像像素、用户行为序列、蛋白质表达式、传感器通道……**维度灾难**让所有距离度量失效、让所有模型训练变慢、让所有结果不可解释。
> 
> 杉山将这一章的精妙之处在于：他没有把降维讲成"算法大全"，而是**用一条主线串起来**——

```
降维的本质: 找一个投影/映射, 在低位空间中"保留某种结构"
                │
    ┌───────────┼───────────┬───────────┐
    ↓           ↓           ↓           ↓
  保留方差    保留距离    保留局部    保留非线性
    ↓           ↓           ↓           ↓
   PCA         MDS       LPP/LE      Kernel PCA
  (线性全局)  (线性全局) (线性/非线性局部) (非线性全局)
```

**这一章是"流形学习"与"线性投影"的交汇点**——理解它，你就理解了从 PCA 到深度学习表征学习的完整演进。

---

## 13.1 线性降维的原理

**书中定义**：线性降维通过线性变换将高维数据投影到低维空间，形式为 $y=W^{\mathsf T}x$，其中 $W$ 是投影矩阵。

**🎯 第一性原理洞察：降维的本质是"信息保留的优化"**

```
降维的数学本质:

  高维空间 ℝᴰ  ──投影 W──→  低维空间 ℝᵈ  (d << D)
       x                    y = Wᵀx
       
  我们想让 y "尽可能像" x:
  
  不同"像"的定义 → 不同的降维算法:
  
  定义1: 方差最大 → PCA
  定义2: 距离不变 → MDS
  定义3: 近邻关系不变 → LPP / LE
  定义4: 非线性结构不变 → Kernel PCA / Isomap / LLE
```

**线性降维的三个核心要素**：

```
1. 投影矩阵 W (d×D 维)
   - 每一列是一个"主方向"
   - 学习 W 使得某种"结构保留度量"最大化/最小化

2. 优化目标 J(W)
   - PCA: max Tr(WᵀΣW) s.t. WᵀW = I
   - LPP: min WᵀXLXᵀW s.t. WᵀXDWᵀW = I
   - 本质: 广义特征值问题

3. 求解方法
   - 特征值分解 (Eigendecomposition)
   - 奇异值分解 (SVD) — 数值更稳定
```

**ASCII 图示线性降维的几何意义**：

```
高维空间 (D=2) 投影到低维 (d=1):

   ● ● ● ● ● ● ● ●
  ● ● ● ● ● ● ● ● ●
   ● ● ● ● ● ● ● ●
    ● ● ● ● ● ● ●
     ● ● ● ● ● ●
      ● ● ● ● ●
       ● ● ●
        ● ●
         ●
         ↑
         投影方向 w (方差最大方向)
         ↓
   ───────────────────→ 低维空间 (1D)
   ●● ●●●● ●●●●● ●●●● ●● 
   
   PCA: w = 数据方差最大的方向
```

**线性降维 vs 非线性降维的本质区别**：

```
线性降维:
   假设数据分布在线性子空间上
   投影是直线/平面
   计算高效、可解释、可扩展到新样本
   例: PCA, LPP, Linear ICA
   
非线性降维:
   假设数据分布在弯曲的流形上
   投影是弯曲的流形
   表达能力强，但计算复杂、难扩展到新样本
   例: Kernel PCA, LE, LLE, Isomap, t-SNE
```

**工业视角**：

```
线性降维的工业定位：

✓ 完美适用:
  - 数据维度高但线性结构明显 (d < 1000)
  - 需要实时/在线投影新样本
  - 需要可解释的降维 (主成分的物理意义)
  - 计算资源受限
  
典型场景:
  - 金融: 多因子模型的因子提取
  - 推荐: 用户/物品 Embedding 的线性压缩
  - 信号处理: 传感器数据的特征压缩
  - 生物信息: 基因表达数据的降维可视化
  - NLP: 词袋模型的高维稀疏特征压缩
  
工业标准:
  PCA 是降维的"hello world"
  几乎所有数据科学流水线都从 PCA 开始
```

> 💡 **洞见**：线性降维的本质是**用最低的复杂度换最大的结构保留**。它不求完美还原数据，而是求"在线性变换的约束下，尽可能保留最重要的结构"。这种"受限优化"的思想，与第4章的正则化、第5章的稀疏化一脉相承——**都是在某个约束下求最优解**。

## 13.2 主成分分析 (PCA)

**书中定义**：PCA 通过最大化投影后数据的方差，找到一组正交的投影方向（主成分）。

**数学推导**：

1. 数据中心化：$x_i\leftarrow x_i-\mu$
2. 计算协方差矩阵：$\Sigma=\frac{1}{n}X^{\mathsf T}X$
3. 特征值分解：$\Sigma=U\Lambda U^{\mathsf T}$
4. 取前 $d$ 个最大特征值对应的特征向量：$W=[u_1,u_2,\ldots,u_d]$
5. 投影：$y_i=W^{\mathsf T}x_i$

**🎯 第一性原理洞察：PCA 是"方差最大化"与"信息保留"的最优解**

```
PCA 的几何意义:

高维数据椭球:

         ● ● ● ●
      ● ● ● ● ● ● ●
    ● ● ● ● ● ● ● ● ●
   ● ● ● ● ● ● ● ● ● ●
    ● ● ● ● ● ● ● ● ●
      ● ● ● ● ● ● ●
         ● ● ● ●
         
   主轴 (PC1): 方差最大的方向 → 保留最多信息
   次轴 (PC2): 垂直于 PC1 的方差最大方向
   依此类推...

投影到 PC1:
   ─────────────────→
   ●● ●●●● ●●●●● ●●●● ●●
   
   信息保留率 = λ₁ / Σλᵢ
```

**PCA 的五大核心性质**：

```
1. 正交性: 主成分之间互不相关 (WᵀW = I)
2. 方差递减: λ₁ ≥ λ₂ ≥ ... ≥ λ_d
3. 最优线性重构: 在 d 维子空间中重构误差最小
4. 全局性: 保留全局方差结构 (非局部)
5. 无参数: 不需要调参 (除了选择 d)
```

**方差保留率与维度选择**：

```
累计方差贡献率:

  1.0 ┤━━━━━━━━━━●━━━━━━●━━━━━
      │          ┊     ┊     ┊
  0.8 ┤━━━━━━━━━┊━━━━━┊━━━━━┊━━
      │        ┊  ┊   ┊  ┊   ┊  ┊
  0.6 ┤━━━━━━┊   ┊   ┊  ┊   ┊  ┊
      │     ┊  ┊   ┊   ┊  ┊   ┊  ┊
  0.4 ┤━━━┊   ┊   ┊   ┊  ┊   ┊  ┊
      │  ┊  ┊   ┊   ┊   ┊  ┊   ┊  ┊
  0.2 ┤━┊  ┊   ┊   ┊   ┊  ┊   ┊  ┊
      │┊  ┊  ┊   ┊   ┊   ┊  ┊   ┊  ┊
  0.0 ┼┴──┴──┴──┴──┴──┴──┴──┴──┴──→
      PC1 PC2 PC3 PC4 PC5 PC6 PC7 PC8 PC9 PC10
      
   工业经验:
   - 保留 95% 方差 → 常用
   - 保留 99% 方差 → 高精度场景
   - 保留 90% 方差 → 快速预览
```

**PCA 的 SVD 视角**（数值计算的标准方法）：

```
数据矩阵 X (n×D) 的 SVD 分解:
   X = UΣVᵀ
   
   U: n×n 左奇异向量 (样本空间)
   Σ: n×D 对角矩阵 (奇异值)
   V: D×D 右奇异向量 (特征空间)
   
   PCA 的主成分 = V 的前 d 列
   投影: Y = X·V[:, :d] = UΣ[:, :d]
   
   优势:
   - 数值稳定 (不用显式计算 XᵀX)
   - 可处理 n < D 的情况
   - 与特征值分解完全等价
```

**🎯 深度洞见：PCA 的三个隐藏假设**

```
假设1: 数据均值有意义
   → 如果数据有明显偏移，PCA 会失效
   → 解决: 先去中心化
   
假设2: 方差大的方向 = 信息多的方向
   → 但异常点的方差最大!
   → PCA 对异常点极度敏感 
   → 解决: Robust PCA (RPCA)
   
假设3: 数据结构是全局线性的
   → 无法捕捉非线性流形
   → 例: 瑞士卷 (Swiss Roll)
   → PCA 会把它压平，丢失流形结构
   → 解决: 非线性降维 (Kernel PCA, LE, LLE)
```

**ASCII 图示 PCA 的局限**：

```
瑞士卷流形:                    PCA 投影结果:

       ●●●●●●                     ●●●●●●
     ●●      ●●                 ●●      ●●
    ●●        ●●               ●●        ●●
   ●●          ●●             ●●          ●●
    ●●        ●●               ●●        ●●
     ●●      ●●                 ●●      ●●
       ●●●●●●                     ●●●●●●
       
   3D 流形结构                  压扁成 2D 后
   沿流形展开有结构              流形结构丢失!
                                不同颜色混在一起
                                
   → PCA 无法"展开"流形
   → 需要非线性方法 (如 LE, Isomap)
```

**工业视角**：

```
PCA 的工业应用版图：

1. 数据预处理 (最常用):
   - 消除特征间多重共线性 → 改善最小二乘的数值稳定性 (呼应第3章)
   - 降维到 50-200 维 → 加速后续模型训练
   - 例: 随机森林/XGBoost 前的特征压缩
   
2. 可视化:
   - 高维数据投影到 2D/3D 进行可视化
   - 例: 用户分群可视化、基因表达可视化
   
3. 去噪:
   - 丢弃小特征值对应的主成分 → 去除噪声
   - 例: 图像去噪、信号去噪
   
4. 特征提取:
   - 人脸识别: Eigenfaces (PCA 提取人脸主成分)
   - 推荐系统: 用户/物品 Embedding 压缩
   
5. 异常检测预处理:
   - PCA 重构误差 → 异常分数
   - 例: 工业传感器异常检测
   
工业案例:
   - Netflix: 用户-电影矩阵的 PCA 分解 → 推荐
   - 金融风控: 多因子 PCA → 提取独立风险因子
   - 生物信息: 基因表达 PCA → 识别疾病亚型
   - 计算机视觉: 图像 PCA → 人脸特征提取
```

> 💡 **洞见**：PCA 是降维的"地基"——它简单、快速、可解释、可扩展。**但它有三个根本性局限**：对异常点敏感、只能捕捉全局线性结构、方差最大不等于信息最多。理解这三个局限，你就能理解为什么需要 LPP（解决局部结构）、Kernel PCA（解决非线性）、Robust PCA（解决异常点）。

## 13.3 局部保持投影 (LPP)

**书中思路**：PCA 保留全局方差，但忽略了局部邻域结构。LPP 通过构建样本间的相似度图，寻找一个线性投影，使得**投影后近邻样本依然保持近邻关系**。

**算法步骤**：

```
1. 构建邻接图:
   对于每个样本 xᵢ，找到其 k 近邻
   定义权重:
   Wᵢⱼ = { exp(-‖xᵢ-xⱼ‖²/t)  if xⱼ ∈ N(xᵢ)
         { 0                     otherwise
         
2. 构建矩阵:
   D: 对角矩阵, Dᵢᵢ = Σⱼ Wᵢⱼ
   L: 拉普拉斯矩阵, L = D - W
   
3. 求解广义特征值问题:
   X L Xᵀ a = λ X D Xᵀ a
   
4. 取前 d 个最小特征值对应的特征向量:
   W = [a₁, a₂, ..., a_d]
   
5. 投影: yᵢ = Wᵀ xᵢ
```

**目标函数**：

$$
\min_W\ \sum_{i,j}\lVert W^{\mathsf T}x_i-W^{\mathsf T}x_j\rVert_2^2\,W_{ij}
\quad\text{s.t.}\quad
W^{\mathsf T}XDX^{\mathsf T}W=I
$$

**🎯 第一性原理洞察：LPP = PCA 的"局部化"版本**

```
PCA 的优化目标:              LPP 的优化目标:
   
   max Tr(WᵀΣW)              min Σᵢⱼ ‖Wᵀxᵢ-Wᵀxⱼ‖²·Wᵢⱼ
   s.t. WᵀW = I              s.t. WᵀXDWᵀW = I
   
   Σ = (1/n)XᵀX 是全局协方差    Wᵢⱼ 是局部相似度
   → 全局方差最大化            → 局部邻域保持
   
   PCA: 方差大的方向 ≠ 近邻保持
   LPP: 近邻样本投影后仍近邻
```

**LPP 的核心思想可视化**：

```
高维空间中的流形:             LPP 投影到低维:

      ● ● ● ●                    ● ● ● ●
    ● ● ● ● ● ●                ● ● ● ● ● ●
   ● ● ● ● ● ● ●              ● ● ● ● ● ● ●
    ● ● ● ● ● ●                ● ● ● ● ● ●
     ● ● ● ●                    ● ● ● ●
      ● ● ●                      ● ● ●
      
   流形上的近邻关系            投影后近邻关系保持!
   ●-●-●-●-● 近邻              ●-●-●-●-● 仍近邻
   ●   ●   ● 远邻              ●   ●   ● 仍远邻
   
   PCA 会把它压扁 → 近邻混在一起
   LPP 会"展开"流形 → 近邻保持分离
```

**LPP vs PCA 的本质差异**​ ：

|维度|PCA|LPP|
|---|---|---|
|优化目标|全局方差最大|局部邻域保持|
|图结构|无（全局协方差）|有（k近邻图）|
|假设|数据呈全局线性|数据呈局部线性（流形）|
|对异常点|敏感|**相对鲁棒**（只看近邻）|
|投影性质|线性变换|**线性变换**​|
|新样本投影|直接 Wᵀx|直接 Wᵀx|
|适用数据|线性结构|**流形结构**​|

**LPP 的关键优势**：

```
1. 线性变换 → 新样本可直接投影
   (与 LE 的关键区别! LE 只能用于训练集)
   
2. 局部保持 → 适合流形数据
   (与 PCA 的关键区别! PCA 只能处理线性数据)
   
3. 图结构灵活 → 可融入先验知识
   权重 Wᵢⱼ 可自定义:
   - 热核: exp(-‖xᵢ-xⱼ‖²/t)
   - 余弦相似度
   - 业务定义的相似度
```

**🎯 深度洞见：LPP 是连接线性与流形的桥梁**

```
降维方法的谱系:

   线性 + 全局:          线性 + 局部:
   PCA, LDA              LPP ★
   
   非线性 + 全局:        非线性 + 局部:
   Kernel PCA, Isomap    LE, LLE
   
LPP 的独特地位:
   - 它是线性方法 → 计算高效、可扩展到新样本
   - 它保持局部 → 能捕捉流形结构
   - 它是 LE 的线性近似 → 兼具两者优势
   
   工业价值:
   - 需要流形学习能力
   - 但又需要线性变换的效率
   - → LPP 是最佳选择
```

**工业视角**：

```
LPP 的工业应用：

✓ 适用场景:
  - 数据呈流形结构但维度适中 (D < 1000)
  - 需要线性投影 (在线推理)
  - 局部结构比全局方差更重要
  - 中等规模数据 (n < 10万)
  
典型应用:
  1. 人脸识别:
      PCA (Eigenfaces) 的升级版 → LPP (Laplacianfaces)
      LPP 比 PCA 更能保持人脸图像的流形结构
      
  2. 图像检索:
      图像特征降维 → 保持视觉相似度
      近邻检索时相似图像仍相似
      
  3. 文本聚类:
       词袋特征降维 → 保留语义近邻关系
       文档聚类效果更好
       
  4. 生物信息:
       基因表达数据 → 保留生物学近邻关系
       疾病亚型识别
       
  5. 推荐系统:
       用户行为特征 → 保持用户相似度
       用户分群更准确
       
挑战:
  - k 近邻的 k 选择敏感
  - 热核参数 t 需要调参
  - 小规模数据可能过拟合 
  - 计算邻接图 O(n²) 复杂度
```

> ⚠️ **工业经验**：LPP 在实际应用中需要注意：
> 
> 1. **邻居数 k 的选择**：k 太小 → 图不连通；k 太大 → 失去局部性。经验值 k=5~20
> 2. **热核参数 t**：控制相似度的衰减速度。可通过交叉验证选择
> 3. **图连通性**：如果图不连通（孤立点），LPP 会失效。需要保证图的连通性

> 💡 **洞见**：LPP 的精髓在于——**它用一个线性变换去近似一个非线性目标（局部保持）**。这种"以线性之形，行非线性之神"的思想，是机器学习中极具威力的范式。它与今天的**神经网络**有异曲同工之妙：神经网络也是用线性层的组合（配合非线性激活）去近似任意非线性函数。LPP 可以理解为"单层"的流形学习网络。

## 13.4 核函数主成分分析 (Kernel PCA)

**书中思路**：PCA 只能处理线性结构。Kernel PCA 通过核技巧将原始数据映射到高维特征空间，再在高维空间中执行 PCA。

**算法步骤**：

```
1. 选择核函数 k(xᵢ, xⱼ) (如 RBF 核)
2. 计算核矩阵 K (n×n): Kᵢⱼ = k(xᵢ, xⱼ)
3. 中心化核矩阵: K̃ = K - 1ₙK - K1ₙ + 1ₙK1ₙ
   (1ₙ 是 n×n 的全1矩阵/n)
4. 特征值分解: K̃ = UΛUᵀ
5. 取前 d 个最大特征值对应的特征向量
6. 投影新样本: y = [k(x₁,x), ..., k(xₙ,x)]ᵀ · UΛ^(-1/2)
```

**🎯 第一性原理洞察：Kernel PCA = 高维空间中的线性 PCA**

```
Kernel PCA 的本质:

   原始空间 ℝᴰ          高维特征空间 ℝ^∞
   x ────φ(x)────→     φ(x)
   
   PCA 在高维空间中做线性投影:
   y = Wᵀφ(x)
   
   核技巧: 不需要显式计算 φ(x)
   直接用 k(xᵢ, xⱼ) = φ(xᵢ)ᵀφ(xⱼ)
   
   → 在无限维空间中做 PCA
   → 能捕捉任意复杂的非线性结构
```

**Kernel PCA 的几何意义**：

```
原始空间 (线性不可分):        高维空间 (线性可分):

   ● ● │ ○ ○                  ● ● ● ● ●
   ● ● │ ○ ○                ● ● ● ● ● ●●
   ●● │○○ ○         φ 映射   ●● ●● ● ●●●
      │                         ↑
   环形分布                      线性 PCA 可以"切开"
   
   Kernel PCA 的效果:
   ─────────────────→
   ●● ●●●● ●●●●● ●●●● ●●
   
   环形流形被"展开"成线性结构
   PCA 在高维空间中找到了主成分
```

**常见核函数选择**：

|核函数|公式|适用场景|
|---|---|---|
|线性核|$k(x_i,x_j)=x_i^{\mathsf T}x_j$|高维稀疏特征（退化为标准 PCA）|
|多项式核|$k(x_i,x_j)=(x_i^{\mathsf T}x_j+c)^d$|特征有阶数关系|
|**RBF 核**|**$k(x_i,x_j)=\exp\!\left(-\lVert x_i-x_j\rVert_2^2/(2\sigma^2)\right)$**|**通用首选**|
|Sigmoid 核|$k(x_i,x_j)=\tanh(\gamma x_i^{\mathsf T}x_j+c)$|类神经网络|

**🎯 深度洞见：Kernel PCA vs 标准 PCA 的本质差异**

```
标准 PCA:
   投影矩阵 W (D×d) — 显式
   新样本投影: y = Wᵀx — 直接线性计算
   复杂度: O(D³ + nD²)
   
Kernel PCA:
   投影"矩阵"是隐式的 — 表现为训练样本的核组合
   新样本投影: y = Σᵢ αᵢk(xᵢ, x) — 核计算
   复杂度: O(n³) — 核矩阵特征值分解
   
关键差异:
   - Kernel PCA 的计算复杂度与样本数 n 立方成正比
   - 不适合大规模数据 (n > 1万)
   - 但表达能力强 — 能处理任意非线性
```

**核矩阵中心化的必要性**：

```
为什么需要中心化?

在高维特征空间中，φ(x) 的均值可能不为 0
→ 直接对 φ(x) 做 PCA 会偏移
→ 需要在高维空间中也中心化: φ̃(x) = φ(x) - μ_φ

核技巧下的中心化:
   K̃ᵢⱼ = (φ(xᵢ)-μ_φ)ᵀ(φ(xⱼ)-μ_φ)
       = Kᵢⱼ - (1/n)ΣₐKₐⱼ - (1/n)Σ_bKᵢ_b + (1/n²)Σₐ_bKₐ_b
       
   即: K̃ = K - 1ₙK - K1ₙ + 1ₙK1ₙ
```

**工业视角**：

```
Kernel PCA 的工业定位：

✓ 适用场景:
  - 数据呈复杂非线性流形
  - 样本数适中 (n < 1万)
  - 需要非线性降维但希望保持 PCA 的优雅性
  - 作为其他核方法的预处理
  
典型应用:
  1. 图像去噪:
       核 PCA 重构 → 去除非线性噪声
       例: 人脸图像去噪
       
  2. 异常检测:
       核 PCA 重构误差 → 异常分数
       比线性 PCA 更敏感
       
  3. 特征提取:
       作为 SVM/核机器 的预处理
       降低维度，提升核方法效率
       
  4. 生物信息:
       蛋白质结构数据降维
       基因表达的非线性结构提取
       
✗ 不适用场景:
  - 大规模数据 (n > 1万) → 计算不可行
  - 需要在线投影新样本 (核计算 O(n))
  - 高维稀疏特征 → 线性核退化为 PCA，直接用 PCA
  
工业挑战:
  - 核矩阵 O(n²) 存储
  - 特征值分解 O(n³) 时间
  - 核参数选择需经验
  
现代解决方案:
  - 随机傅里叶特征 (Random Fourier Features)
  - Nyström 近似
  - 这些方法让核 PCA 扩展到大规模数据
```

> 💡 **洞见**：Kernel PCA 是"核技巧"与"PCA"的完美结合——它继承了 PCA 的所有数学优雅（特征值分解、方差解释、主成分正交），同时通过核技巧获得了处理非线性数据的能力。**它证明了"线性方法 + 核技巧 = 非线性方法"这一深刻洞见**。这也是为什么核技巧在机器学习中具有如此核心的地位——它不仅用于 SVM（第8章），也用于 PCA（本章）。

> ⚠️ **工业现实**：今天工业界在大规模非线性降维时，**很少直接使用 Kernel PCA**——它的 O(n³) 复杂度是硬伤。取而代之的是：
> 
> - 小规模数据：Kernel PCA 仍可用
> - 中大规模数据：用 AutoEncoder（神经网络）或近似核方法
> - 超大规模数据：用 Word2Vec、Node2Vec 等表示学习算法

## 13.5 拉普拉斯特征映射 (Laplacian Eigenmaps, LE)

**书中思路**：LE 是流形学习的经典算法。它构建一个图来表示数据的局部邻域结构，然后通过求解图拉普拉斯矩阵的特征值问题，得到低维嵌入。

**算法步骤**：

```
1. 构建邻接图 (与 LPP 相同):
   Wᵢⱼ = { exp(-‖xᵢ-xⱼ‖²/t)  if xⱼ ∈ N(xᵢ)
         { 0                     otherwise
         
2. 构建矩阵:
   Dᵢᵢ = Σⱼ Wᵢⱼ (度矩阵)
   L = D - W (拉普拉斯矩阵)
   
3. 求解广义特征值问题:
   L y = λ D y
   
4. 取前 d 个最小非零特征值对应的特征向量:
   Y = [y₁, y₂, ..., y_d]
   
5. Y 的每一行是对应样本的低维嵌入
```

**目标函数**：

$$
\min_Y\ \sum_{i,j}\lVert y_i-y_j\rVert_2^2\,W_{ij}
\quad\text{s.t.}\quad
Y^{\mathsf T}DY=I,\qquad Y^{\mathsf T}D\mathbf{1}=0
$$

**🎯 第一性原理洞察：LE 是"图上的傅里叶变换"**

```
LE 的几何直觉:

   高维流形上的数据点:
   ●──●──●──●──●──●
   │              │
   ●──●──●──●──●──●
   │              │
   ●──●──●──●──●──●
   
   构建图 (k近邻):
   ●──●──●──●──●──●
   │╲ │ ╱│╲ │ ╱│
   ●──●──●──●──●──●
   │ ╱│╲ │ ╱│╲ │
   ●──●──●──●──●──●
   
   LE 求解: 图上"最平滑"的嵌入
   即: 相邻点的 y 值尽可能接近
   
   等价于: 在图上做傅里叶变换
   拉普拉斯矩阵 L 的特征向量 = 图上的傅里叶基
   最小特征值 → 最低频 → 最平滑的嵌入
```

**LE 与 LPP 的本质区别**​ ：

```
LE (Laplacian Eigenmaps):
   - 直接得到训练样本的低维嵌入 Y (n×d)
   - 新样本无法直接投影
   - 需要"out-of-sample"扩展 (如核 LE)
   - 是非线性流形学习方法
   
LPP (Locality Preserving Projections):
   - 得到投影矩阵 W (D×d)
   - 新样本可直接投影: y = Wᵀx
   - 是线性变换
   - 是 LE 的线性近似
   
关系:
   LPP ≈ LE 的线性化版本
   LPP 通过求解投影矩阵，将 LE 的非线性嵌入
   近似为一个线性变换
```

**ASCII 图示 LE 的嵌入过程**：

```
瑞士卷流形:                    LE 嵌入到 2D:

       ●●●●●●                     ● ● ● ●
     ●●      ●●                 ● ● ● ● ● ●
    ●●        ●●               ● ● ● ● ● ● ●
   ●●          ●●             ● ● ● ● ● ● ●
    ●●        ●●               ● ● ● ● ● ●
     ●●      ●●                 ● ● ● ●
       ●●●●●●                     ● ● ● ●
       
   3D 流形                       2D 嵌入
   沿流形展开有结构              流形被"展开"!
   但 PCA 无法展开              不同颜色清晰分离
                                
   LE 的成功关键:
   - 构建近邻图捕捉流形局部结构
   - 求解图拉普拉斯 → 展开流形
```

**LE 的理论基础**：

```
图拉普拉斯矩阵 L = D - W 的性质:

1. 对称性: L 是对称半正定矩阵
2. 瑞利商: 最小化 Σᵢⱼ‖yᵢ-yⱼ‖²Wᵢⱼ 等价于
           最小化 yᵀLy / yᵀDy
3. 特征值: 0 = λ₁ ≤ λ₂ ≤ ... ≤ λₙ
4. 特征向量: 对应图上的傅里叶基
   - 最小非零特征值 → 最低频 → 最平滑嵌入
   - 这就是 LE 取前 d 个最小非零特征值的原因
```

**LE 的优势与局限**​ ：

```
优势:
  ✓ 能展开复杂非线性流形
  ✓ 对噪声相对鲁棒 (只看局部)
  ✓ 理论优雅 (图上的谱方法)
  ✓ 与图神经网络 (GNN) 有深刻联系
  
局限:
  ✗ 无法处理新样本 (非线性的代价)
  ✗ 计算复杂度高 O(n²) 建图 + O(n³) 特征值分解
  ✗ 对参数敏感 (k, t)
  ✗ 难以扩展到大规模数据
  ✗ 实际工业应用受限
```

**工业视角**：

```
LE 的工业定位：

✓ 适用场景:
  - 小规模数据 (n < 1万)
  - 数据呈复杂流形结构
  - 探索性数据分析 (EDA)
  - 作为其他算法的理论基础
  
典型应用:
  1. 流形学习研究:
       瑞士卷、S 形曲线等玩具数据集
       验证流形学习算法的有效性
       
  2. 图像分析:
       人脸图像流形学习
       手写数字流形展开
       
  3. 图嵌入:
       社交网络节点嵌入
       知识图谱表示学习
       
  4. 生物信息:
       基因表达流形结构发现
       蛋白质折叠流形
       
✗ 工业部署挑战:
  - 无法在线投影新样本 → 实用性差
  - 计算复杂度高 → 难以扩展到大数据
  - 参数敏感 → 需要大量调参
  
工业现实:
  纯 LE 在工业界很少直接部署
  但它的思想影响了:
  - 谱聚类 (Spectral Clustering)
  - 图神经网络 (GNN) 的消息传递
  - 图嵌入算法 (DeepWalk, Node2Vec)
  - t-SNE, UMAP 等现代可视化方法
```

> 💡 **洞见**：LE 虽然工业部署受限，但它的**思想价值无可估量**。它提出的"图拉普拉斯 + 谱分解"范式，开启了谱图理论在机器学习中的应用。今天的**图神经网络（GNN）**——GCN、GraphSAGE、GAT——其核心消息传递机制，本质上就是 LE 思想的深度学习版本。LE 的每一步：构图、定义拉普拉斯、谱分解，都在今天的 GNN 中以"聚合邻居特征"的形式复活。

> ⚠️ **LE vs LPP 的工业选择**：
> 
> ```
> 需要线性投影 (在线推理) → LPP
> 需要最强流形展开能力 (离线分析) → LE
> 工业部署 → LPP (因为可扩展到新样本)
> 学术研究 → LE (因为理论更优雅)
> ```

## 跨章节总洞察：降维在全书的位置

把第13章放入全书的脉络：

```
第3-6章: 监督学习基础
     ↓
第7-10章: 监督分类
     ↓
第11章: 序列分类 (CRF)
     ↓
第12章: 异常检测 (无监督)
     ↓
第13章: 无监督降维 ★
   ├─ 13.1 线性降维原理: 投影矩阵 + 结构保留
   ├─ 13.2 PCA: 全局方差最大化
   ├─ 13.3 LPP: 局部邻域保持 (线性)
   ├─ 13.4 Kernel PCA: 非线性 + 核技巧
   └─ 13.5 LE: 非线性流形学习 (谱方法)
```

**降维方法的统一框架**：

```
所有降维方法的本质:

   寻找投影/映射 f: ℝᴰ → ℝᵈ
   使得某种"结构度量" S 被保留:
   
   S = 方差        → PCA
   S = 距离        → MDS
   S = 近邻关系    → LPP, LE
   S = 非线性流形  → Kernel PCA, Isomap, LLE
   
   优化问题:
   max/min S(f(X))  s.t. f 是某种形式的映射
   
   线性映射 f(x)=Wᵀx:
   → PCA, LPP, Linear ICA
   → 广义特征值问题
   
   非线性映射 f (隐式):
   → Kernel PCA (核技巧)
   → LE, LLE, Isomap (图/流形)
   → 谱方法
```

**三个第一性原理式的认知**：

1. **降维的本质是"结构保留的优化"**。所有降维方法都在回答同一个问题："在低位空间中，我想保留什么结构？" PCA 保留方差、LPP/LE 保留局部邻域、Kernel PCA 保留非线性流形。**选择哪种降维，本质是选择保留哪种结构**。
2. **线性与是非线性的权衡是降维的核心矛盾**。线性方法（PCA, LPP）计算高效、可扩展到新样本，但表达受限；非线性方法（Kernel PCA, LE）表达能力强，但计算复杂、难以扩展。LPP 是这种权衡的"甜点"——线性变换 + 局部保持。
3. **"谱方法"是流形学习的数学基础**。LE 通过图拉普拉斯的特征值分解实现流形展开，这种"构图 + 谱分解"的范式，不仅用于降维，也用于谱聚类、图神经网络、图嵌入。**理解 LE，就是理解图机器学习的源代码**。

**与工业深度学习的深刻联系**：

```
传统降维 → 深度表示学习:

PCA → 线性 AutoEncoder:
   隐藏层 = 1 的单层神经网络
   目标: 最小化重构误差
   等价于 PCA 
   
LPP → 图神经网络 (GNN):
   LPP 的邻接图 → GNN 的消息传递
   LPP 的局部保持 → GNN 的邻居聚合
   LPP 的线性投影 → GNN 的线性变换层
   
Kernel PCA → 深度核机器:
   核技巧 → 深度神经网络
   RKHS → 深度特征空间
   
LE → 图嵌入算法:
   LE → DeepWalk, Node2Vec, graph2vec
   谱方法 → 图神经网络的消息传递
   
降维 → 预训练:
   PCA/LPP 特征 → CNN/Transformer 的预训练特征
   降维作为表示学习的"史前时代"
   深度学习是降维的"现代化身"
```

> 💡 **终极洞见**：第13章看似在讲一组"传统降维算法"，实则在讲**表示学习的第一性原理**。PCA 是线性表示学习，LPP 是局部保持的线性表示学习，Kernel PCA 是非线性表示学习，LE 是谱流形学习。**今天所有的深度学习表示学习——从 AutoEncoder 到 BERT——都是这些思想的延续和深化**。
> 
> 特别是：
> 
> - **AutoEncoder**​ = 非线性的 PCA
> - **GraphSAGE/GAT**​ = 邻居聚合版的 LPP/LE
> - **BERT 的预训练**​ = 大规模非线性表示学习
> - **CLIP/对比学习**​ = 保持"语义近邻"的现代 LPP
> 
> **理解第13章，就是理解从传统降维到现代表示学习的完整演进史**。当你看懂 LPP 如何通过邻接图保持局部结构，你就能看懂 GraphSAGE 如何通过邻居采样聚合特征；当你看懂 LE 的谱分解，你就能看懂 GNN 的 message passing。

## 英文补充视角（Beyond the Book）

**1. PCA 的理论基础**：

- **Pearson (1901)**: PCA 最早提出，作为"主轴线"拟合
- **Hotelling (1933)**: 正式提出 PCA 作为多元统计方法
- **Jolliffe (2002)**: 《Principal Component Analysis》— PCA 的权威教程

**2. 流形学习的理论突破**：

- **ISOMAP (Tenenbaum et al. 2000)**: 保持测地线距离的全局流形学习
- **LLE (Roweis & Saul 2000)**: 局部线性嵌入
- **LE (Belkin & Niyogi 2003)**: 拉普拉斯特征映射，提出图拉普拉斯的谱方法
- **MDS**: 多维尺度分析，PCA 的推广

**3. LPP 的原始论文**：

- **He & Niyogi (2003)**: 《Locality Preserving Projections》— LPP 的奠基论文
- **核心贡献**: LPP 是 LE 的线性近似，可直接投影新样本

**4. Kernel PCA 的理论**：

- **Schölkopf et al. (1998)**: 《Nonlinear Component Analysis as a Kernel Eigenvalue Problem》
- 核技巧 + PCA = 非线性降维
- 与 SVM 的核技巧同源

**5. 谱图理论**：

- **Chung (1997)**: 《Spectral Graph Theory》— 图拉普拉斯的理论基础
- LE 是谱图理论在降维中的应用

**6. 现代发展**：

- **AutoEncoder (Hinton & Salakhutdinov 2006)**: 神经网络版的 PCA
- **t-SNE (van der Maaten & Hinton 2008)**: 非线性可视化降维
- **UMAP (McInnes et al. 2018)**: 基于黎曼几何的降维
- **DeepWalk (Perozzi et al. 2014)**: LE 思想在图嵌入中的应用
- **GraphSAGE (Hamilton et al. 2017)**: LPP 思想在 GNN 中的应用

**7. 工业级实现**：

- **scikit-learn**: PCA, KernelPCA, LocalityPreservingProjection, SpectralEmbedding
- **PCA 的 SVD 实现**: 数值稳定的标准方法
- **大规模 PCA**: 随机 SVD (Randomized SVD)

**8. 降维方法的比较研究**：

- **软件学报综述**​ : PCA 快速但异常点敏感，LPP 保持近邻，流形学习方法表达力强但计算复杂、难以适用于新增数据

> 💡 **工业实践建议**：在实际项目中，降维的选型通常遵循以下路径：
> 
> 1. **先试 PCA**：快速、稳定、可解释，作为基线
> 2. **如果数据呈流形结构且需要线性投影**​ → LPP
> 3. **如果需要非线性降维且数据规模小**​ → Kernel PCA 或 LE
> 4. **如果数据规模大且需要非线性降维**​ → AutoEncoder 或 GNN
> 5. **如果是为了可视化**​ → t-SNE 或 UMAP（专门为此设计）
