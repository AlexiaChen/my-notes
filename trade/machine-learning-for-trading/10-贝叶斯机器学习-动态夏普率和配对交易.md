

本章将介绍机器学习（ML）中的贝叶斯方法，以及它们对不确定性的独特视角如何为开发和评估交易策略增添价值。

**贝叶斯统计学**允许我们量化未来事件的不确定性，并以一种有原则的方式随着新信息的到来而精炼我们的估计。这种动态方法能很好地适应金融市场不断演变的性质。当相关数据较少，且需要系统地整合先验知识或假设时，贝叶斯方法尤其有用。

我们将看到，贝叶斯机器学习方法能够对统计指标、参数估计和预测的不确定性提供更丰富的洞察。其应用范围从更细致的风险管理到结合市场环境变化而动态更新的预测模型。Black-Litterman 资产配置方法（参见第五章，“投资组合优化和绩效评估”）可以被解读为一个贝叶斯模型。它通过对市场均衡和投资者观点进行加权，并根据每项资产的波动性、跨资产相关性和对每个预测的信心来计算资产的预期回报。

#### 贝叶斯机器学习的工作原理

- **区别于频率论方法**：
    - **经典统计学**（频率论方法）将概率解释为事件在长期（即观察大量试验后）发生的相对频率。
    - **贝叶斯统计学**则将概率视为对事件发生置信度或信念的度量。因此，贝叶斯视角比频率论解释为更主观的观点和意见差异留下了空间。对于那些不经常发生以至于无法获得客观的长期频率度量的事件，这种差异最为显著。
- **数据和参数的视角**：
    - 频率论统计学假设数据是从总体中随机抽取的样本，旨在识别生成数据的固定参数。
    - 贝叶斯统计学则将数据视为已知，并将参数视为具有可从数据推断出分布的随机变量。
    - 因此，频率论方法需要至少与要估计的参数一样多的数据点。而贝叶斯方法则兼容较小的数据集，并且非常适合一次一个样本的在线学习。
- **更新信念**：
    - 贝叶斯观点对于许多现实世界中罕见或独特的事件非常有用，例如下次选举的结果或市场是否会在三个月内崩溃。
    - 贝叶斯定理规定了当相关新信息到来时，概率或信念应如何改变。它通过将先验假设与新的经验证据相结合来“结晶”更新信念的概念。
- **贝叶斯统计推断**：
    - **共轭先验（Conjugate Priors）**：通过提供闭式解来简化更新过程，从而精确计算出解。当先验分布与似然函数共轭时，得到的后验分布与先验分布类型相同，只是参数不同。这避免了使用数值方法来近似后验分布。例如，`updating_conjugate_priors` 笔记本演示了如何使用共轭先验从 S&P 500 样本中更新价格变动估计。
    - **近似推断（Approximate Inference）**：当无法解析地推导出精确的后验分布时，需要使用近似推断。
        - **随机技术（Stochastic techniques）**：基于马尔可夫链蒙特卡洛（MCMC）采样，它们通常具有收敛到精确结果的特性。但在实践中，采样方法可能计算量大，通常限于小规模问题。
        - **确定性方法（Deterministic methods）**：称为变分推断（variational inference）或变分贝叶斯（variational Bayes），它们基于对后验分布的分析近似，并且可以很好地扩展到大型应用。它们会做出简化假设，例如后验分布以特定方式分解或具有特定的参数形式（如高斯分布）。因此，它们不会产生精确结果，可以作为采样方法的补充。

#### PyMC3 的概率编程

- **作用**：概率编程提供了一种描述和拟合概率分布的语言，以便设计、编码并自动估计和评估复杂模型。它旨在抽象化一些计算和分析的复杂性，使我们能够专注于贝叶斯推理更直接和直观的方面。
- **PyMC3**：于2017年1月发布，它将哈密顿蒙特卡洛（Hamiltonian MC）方法添加到了 PyMC2 (2012年发布) 中使用的 Metropolis-Hastings 采样器。PyMC3 使用 **Theano** 作为其计算后端，用于动态 C 编译和自动微分。未来的 PyMC4（计划于2019年发布）将改用 TensorFlow。
- **PyMC3 工作流程**：
    1. **编码概率模型**：定义先验分布（量化潜在变量的知识和不确定性）和似然函数（根据观察数据调整参数）。
    2. **分析后验**：
        - 使用 MAP 推断获得点估计。
        - 使用 MCMC 方法从后验中采样。
        - 使用变分贝叶斯近似后验。
    3. **检查模型**：使用各种诊断工具。
    4. **生成预测**。
- **代码示例**：`pymc3_workflow` 笔记本演示了 PyMC3 的工作流程，使用一个简单的逻辑回归来建模衰退预测。它使用了来自 FRED 服务的数据，包括长期国债收益率曲线利差、密歇根大学消费者信心指标、全国金融状况指数（NFCI）和 NFCI 非金融杠杆子指数等衰退预测指标。
- **贝叶斯逻辑回归**：与频率论方法不同，贝叶斯逻辑回归估计的是参数本身的后验分布。后验分布允许对每个参数的贝叶斯可信区间进行更稳健的估计，并提供模型不确定性方面更高的透明度。该笔记本演示了 MAP 推断、MCMC 估计（包括 Metropolis-Hastings 和 NUTS 采样器）、变分推断、模型诊断（能量图和森林图）、后验预测检查（PPD）和可信区间（CI）以及预测。

#### 贝叶斯机器学习在交易中的应用

- **贝叶斯夏普比率（Bayesian Sharpe Ratio）用于绩效比较**：
    - `bayesian_sharpe_ratio` 笔记本展示了如何使用 PyMC3 将夏普比率（SR）定义为一个概率模型，以及如何比较不同回报序列的后验分布。
    - 两个序列的贝叶斯估计提供了非常丰富的洞察力，因为它提供了效应大小、组夏普比率均值及其差异，以及标准差及其差异的完整可信值分布。
    - 相关用例包括分析替代策略之间的差异，或策略的样本内回报与其样本外回报之间的差异。
    - 贝叶斯夏普比率也是 pyfolio 的贝叶斯 tearsheet 的一部分。
- **贝叶斯滚动回归（Bayesian Rolling Regression）用于配对交易**：
    - 配对交易是一种依赖于两个或更多资产之间**协整（cointegration）**的流行交易策略。给定这样的资产，需要估计对冲比率以决定多头和空头头寸的相对大小。基本方法是使用线性回归。
    - `rolling_regression` 笔记本展示了贝叶斯线性回归如何跟踪两种资产之间关系随时间的变化。
- **随机波动率模型（Stochastic Volatility Models）**：
    - 资产价格具有时变波动性；在某些时期，回报高度波动，而在其他时期则非常稳定。
    - 随机波动率模型通过一个潜在的波动率变量来建模，该变量被建模为随机过程。No-U-Turn Sampler 就是使用这种模型引入的，`stochastic_volatility` 笔记本演示了此用例。

贝叶斯机器学习在金融领域的应用，就像一个经验丰富的侦探在调查案件：传统方法可能只根据大量证据提供一个“是”或“否”的结论，而贝叶斯方法则能整合侦探的初步直觉（先验知识），并随着新线索（数据）的出现，不断调整他对嫌疑犯（市场参数）的置信度，最终不仅给出可能性，还能提供这种可能性的不确定性范围，即使在线索不多时也能形成有价值的判断。
