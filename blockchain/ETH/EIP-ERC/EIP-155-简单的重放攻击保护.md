# EIP-155: 简单的重放攻击保护

**标准跟踪：核心**

| | |
| --- | --- |
| 作者 | Vitalik Buterin (@vbuterin) |
| 创建时间 | 2016-10-14 |

---

### 硬分叉

Spurious Dragon

### 参数

- `FORK_BLKNUM`: 2,675,000
- `CHAIN_ID`: 1（主网）

### 规范

如果 `block.number >= FORK_BLKNUM` 并且 `CHAIN_ID` 可用，那么在计算用于签名目的的交易哈希时，而不是仅哈希六个 rlp 编码的元素 `(nonce, gasprice, startgas, to, value, data)`，你**应该**哈希九个 rlp 编码的元素 `(nonce, gasprice, startgas, to, value, data, chainid, 0, 0)`。如果你这样做，则签名的 `v` **必须**设置为 `{0,1} + CHAIN_ID * 2 + 35`，其中 `{0,1}` 是 secp256k1 签名过程中 `r` 是 x 值的曲线点的 `y` 值的奇偶性。如果你选择只哈希 6 个值，那么 `v` 继续设置为 `{0,1} + 27`，就像以前一样。

如果 `block.number >= FORK_BLKNUM` 并且 `v = CHAIN_ID * 2 + 35` 或 `v = CHAIN_ID * 2 + 36`，那么在计算用于恢复目的的交易哈希时，而不是哈希六个 rlp 编码的元素 `(nonce, gasprice, startgas, to, value, data)`，哈希九个 rlp 编码的元素 `(nonce, gasprice, startgas, to, value, data, chainid, 0, 0)`。当前使用 `v = 27` 和 `v = 28` 的签名方案仍然有效，并继续按照以前的相同规则运行。

### 示例

考虑一个具有 `nonce = 9`、`gasprice = 20 * 10**9`、`startgas = 21000`、`to = 0x3535353535353535353535353535353535353535`、`value = 10**18`、data=''（空）的交易。

"签名数据"变为：

```
0xec098504a817c800825208943535353535353535353535353535353535353535880de0b6b3a764000080018080
```

"签名哈希"变为：

```
0xdaf5a779ae972f972197303d7b574746c7ef83eadac0f2791ad23db92e4c8e53
```

如果交易使用私钥 `0x4646464646464646464646464646464646464646464646464646464646464646` 签名，则 v,r,s 值变为：

### 基本原理

这将提供一种在以太坊上发送交易的方式，而不会在 ETC 或 Morden 测试网上工作。鼓励 ETC 采用此 EIP，但用不同的值替换 `CHAIN_ID`，所有未来的测试网、联盟链和替代以太坊都被鼓励采用此 EIP，用唯一值替换 `CHAIN_ID`。
