## 31.1 Typeable 和 Dynamic：静态类型中的动态逃逸

### Typeable：类型的运行时自省

`Data.Typeable` 模块提供了获取类型信息的方法 ：

```
typeOf :: forall a. Typeable a => a -> TypeRep
```

`TypeRep` 是类型的运行时表示。Haskell.org 的文档说明 ：

> _"data TypeRep -- abstract, instance of: Eq, Show, Typeable... Type constructors are represented by the abstract type, TyCon."_

**🔑 洞见二：Typeable 是自举的类型自省**

Kwang 的博客精辟描述 ：

> _"Data.Typeable is a way to implement dynamic (delayed) type checking in Haskell using a universal type... The Data.Typeable class is used primarily for generic programming in the 'Scrap Your Boilerplate (SYB)' style."_

GHC 7.10 后，`AutoDeriveTypeable` 自动打开 ，这意味着几乎所有标准库类型都自动是 `Typeable` 的实例。你也可以为自己的类型添加 `deriving (Typeable)`（需要 `-XDeriveDataTypeable`）。

### Dynamic：类型安全的动态类型

`Data.Dynamic` 模块的核心 API ：

```
data Dynamic  -- 抽象类型，封装了值和它的类型

toDyn :: Typeable a => a -> Dynamic
fromDyn :: Typeable a => Dynamic -> a -> a
fromDynamic :: Typeable a => Dynamic -> Maybe a
dynTypeRep :: Dynamic -> TypeRep
```

Haskell.org 文档明确说明 ：

> _"A value of type Dynamic is an object encapsulated together with its type. A Dynamic may only represent a monomorphic value; an attempt to create a value of type Dynamic from a polymorphically-typed expression will result in an ambiguity error."_

### 🔑 洞见三：Dynamic 是"单态值的万能容器"

Kwang 的博客给出了经典示例 ：

```
hlist :: [Dynamic]
hlist = [ toDyn ("string" :: String)
        , toDyn (7 :: Int)
        , toDyn (pi :: Double)
        , toDyn 'x'
        , toDyn (((), Just "foo") :: ((), Maybe String))
        ]

dyn :: Dynamic
dyn = hlist !! 1

v :: Int
v = case fromDynamic dyn of
      Nothing -> error "Type mismatch"
      Just x  -> x
```

**关键点**：

1. `[Dynamic]` 在 Haskell 类型系统看来是**同质列表**——所有元素都是 `Dynamic` 类型
    
2. 但每个 `Dynamic` 内部封装了**不同类型的单态值**
    
3. `fromDynamic` 在**运行时**检查类型是否匹配，返回 `Maybe a`
    
4. 这就是 Harper 教科书强调的"untyped means uni-typed" ——动态类型本质上是只有一种类型的静态类型
    

### 🔑 洞见四：Dynamic 不破坏静态类型安全

Brandon 的文章明确指出 ：

> _"The existence of Typeable and Dynamic do not in any way change haskell's static typing."_

如果你写 `cast 'a' :: (Typeable a) => Maybe a`，编译器会因为歧义报错 ——**动态类型逃逸始终被 `Typeable` 约束所包围**。

### 实际应用

```
{-# LANGUAGE DeriveDataTypeable #-}
import Data.Dynamic
import Data.Typeable
import Data.Maybe (fromMaybe)

-- 1. 异构列表
hlist :: [Dynamic]
hlist = [ toDyn (42 :: Int)
        , toDyn ("hello" :: String)
        , toDyn (3.14 :: Double)
        , toDyn True
        ]

-- 2. 安全提取
extractInt :: Dynamic -> Maybe Int
extractInt = fromDynamic

extractString :: Dynamic -> Maybe String
extractString = fromDynamic

-- 3. 类型安全的动态状态
-- Brandon 的动态状态单子
import Control.Monad.State
import Data.Dynamic

type DynamicState a = StateT Dynamic Maybe a

putD :: Typeable a => a -> DynamicState ()
putD = put . toDyn

getD :: Typeable a => DynamicState a
getD = get >>= lift . fromDynamic

-- 使用示例
compute :: DynamicState Int
compute = do
  putD (5 :: Int)           -- 放入 Int
  x <- getD :: DynamicState Int  -- 取出 Int
  putD ("x = " ++ show x)   -- 放入 String
  s <- getD :: DynamicState String  -- 取出 String
  return (length s)

-- 4. 动态类型检查
dynApply :: Dynamic -> Dynamic -> Maybe Dynamic
dynApply f x = dynApp f x  -- 来自 Data.Dynamic

-- 5. 自定义 Typeable 类型
data Shape = Circle Double | Rectangle Double Double
  deriving (Show, Typeable)

shapeArea :: Shape -> Double
shapeArea (Circle r) = pi * r * r
shapeArea (Rectangle w h) = w * h

-- 异构形状列表
shapes :: [Dynamic]
shapes = [toDyn (Circle 5.0), toDyn (Rectangle 3.0 4.0)]

totalArea :: [Dynamic] -> Double
totalArea = sum . mapMaybe (\d -> shapeArea <$> fromDynamic d)
```

## 31.2 存在类型：隐藏具体类型，保留约束证据

### 存在量化的本质

图灵社区原文给出了经典定义 ：

```
{-# LANGUAGE ExistentialQuantification #-}

data Dyn = forall a. Show a => Dyn a

instance Show Dyn where
  show (Dyn a) = "Dyn:" ++ show a
```

**🔑 洞见五：存在类型是"内联类型类词典"**

图灵社区原文精准描述 ：

> _"我们把上述在类型定义的右侧,显示地引入类型变量的类型叫做存在类型 内联类型类词典"_

Haskell Wikibook 给出了更形式化的解释 ：

> _"存在型別,或者簡稱為'存在',是一種將一組型別'壓縮'成一個單一型別的型別。"_

### 全称量化 vs 存在量化

Haskell 邮件列表的经典解释 ：

> _"In Haskell, 'f::a' means 'FOR EVERY type a, f can be that type'. This is universal quantification... Sometimes it's important to be clear about which type of quantification you're talking about. When you do, 'f :: a' would be written 'f :: forall a. a', and what you had in mind would be written 'f :: exists a. a'."_

**关键区别**：

- **全称量化（`forall a. a -> Int`）**：调用者选择具体类型 `a`
    
- **存在量化（`exists a. a -> Int`）**：定义者选择具体类型 `a`，调用者不知道是什么
    

### 🔑 洞见六：存在类型实现封装

Stack Overflow 的精辟总结 ：

> _"from the pragmatic perspective, existential types allow you to hide the underlying type in a data structure, forcing the programmer to only use the operations you have defined on it. It represents encapsulation."_

### 存在类型与 Typeable 的协同

图灵社区原文指出 ：

> _"但凡是Typeable类型类的数据,都可以和Dynamic相互转换"_

`sras.me` 的文章给出了一个精彩示例 ——用 `Typeable` 约束的存在类型，可以在运行时恢复被隐藏的类型信息：

```
-- 货币类型（类型级标记）
data Currency = INR | USD | AUD | YEN
data Money (currency :: Currency) = Money Int

-- 存在类型包装：隐藏具体货币类型
data MoneyEx = forall x. (Typeable x) => MoneyEx (Money x)

-- 现在可以创建异构货币列表
moneyList :: [MoneyEx]
moneyList = [MoneyEx (Money 100 :: Money 'INR),
             MoneyEx (Money 200 :: Money 'USD)]

-- 类型安全的加法：只有同种货币才能相加
moneyAdd :: Money c -> Money c -> Money c
moneyAdd (Money a) (Money b) = Money (a + b)

-- 用 Typeable 在运行时检查货币是否相同
moneyExAdd :: MoneyEx -> MoneyEx -> MoneyEx
moneyExAdd (MoneyEx a) (MoneyEx b) = 
  case cast a of
    Just a' -> MoneyEx $ moneyAdd a' b
    Nothing -> error "Currency mismatch"
```

**🔑 洞见七：Typeable 让存在类型"可逆"**

没有 `Typeable` 约束的存在类型完全隐藏了具体类型——你只能用类型类方法操作它。加上 `Typeable` 后，你可以在运行时尝试恢复类型信息 ，这使得存在类型既能封装，又能在必要时进行类型安全的动态检查。

### 实际应用

```
{-# LANGUAGE ExistentialQuantification #-}
import Data.Typeable

-- 1. 经典的存在类型：异构可显示列表
data ShowBox = forall a. Show a => ShowBox a

heteroList :: [ShowBox]
heteroList = [ShowBox 5, ShowBox "hello", ShowBox 3.14, ShowBox True]

printAll :: [ShowBox] -> IO ()
printAll = mapM_ (\(ShowBox x) -> putStrLn $ show x)

-- 2. 类型类词典的显式传递
data Comparable = forall a. (Ord a, Show a) => Comparable a

compareBoxes :: Comparable -> Comparable -> Ordering
compareBoxes (Comparable x) (Comparable y) = 
  -- 注意：无法直接比较不同具体类型的 x 和 y
  -- 存在类型的限制：你只能使用约束提供的方法
  error "Cannot compare different concrete types!"

-- 3. 插件系统
class Plugin a where
  name :: a -> String
  execute :: a -> IO ()

data AnyPlugin = forall a. Plugin a => AnyPlugin a

plugins :: [AnyPlugin]
plugins = [AnyPlugin pluginA, AnyPlugin pluginB]

runPlugins :: [AnyPlugin] -> IO ()
runPlugins = mapM_ (\(AnyPlugin p) -> do
  putStrLn $ "Running: " ++ name p
  execute p)

-- 4. 存在类型 + Typeable：可序列化的异构数据
data Serializable = forall a. (Typeable a, Show a) => Serializable a

serialize :: Serializable -> String
serialize (Serializable x) = show (typeOf x) ++ ":" ++ show x

deserialize :: Serializable -> (TypeRep, String)
deserialize (Serializable x) = (typeOf x, show x)
```

## 31.3 类型家族、数据家族和 GADT

### 31.3.1 类型家族：类型级函数

Serokell 的权威指南开宗明义 ：

> _"Type families are one of the most powerful type-level programming features in Haskell. You can think of them as type-level functions."_

**类型家族的定义**：

```
{-# LANGUAGE TypeFamilies #-}

type family Append (xs :: [a]) (ys :: [a]) :: [a] where
  Append '[] ys = ys
  Append (x ': xs) ys = x ': Append xs ys
```

Serokell 指南指出 ：

> _"Closed type families... At the type level, we define such computations using closed type families."_

**🔑 洞见八：类型家族是类型级的函数**

类型家族与项级函数高度相似 ：

|项级函数|类型家族|
|---|---|
|`append [] ys = ys`|`Append '[] ys = ys`|
|`append (x:xs) ys = x : append xs ys`|`Append (x ': xs) ys = x ': Append xs ys`|
|函数名小写|类型家族名大写|
|类型签名|种类签名（kind signature）|

### 开放 vs 封闭类型家族

Serokell 指南分类 ：

> _"Type families are further subdivided into closed and open, and open type families can be either top-level or associated with a class."_

```
-- 开放类型家族（可在多处扩展）
type family F a

-- 封闭类型家族（定义在一个地方）
type family G a where
  G Int = String
  G Bool = Char
  G a = a
```

**🔑 洞见九：开放类型家族支持模块化扩展**

封闭类型家族允许模式匹配重叠（按出现顺序匹配），而开放类型家族的实例必须满足"兼容性"规则。

### 关联类型家族

Serokell 指南 ：

> _"Type families... can be either top-level or associated with a class"_

```
class GMapKey k where
  data GMap k :: * -> *
  empty :: GMap k v
  lookup :: k -> GMap k v -> Maybe v
```

图灵社区原文给出了相同的示例 ：

> _"在定义类型类的同时定义数据家族 class GMapKey k where: data GMap k :: * ->_ empty :: GMap k v lookup :: ..."*

### 31.3.2 数据家族：开放的数据类型

图灵社区原文定义 ：

> _"数据家族:data关键字可以定义新的类型以及对应的构造函数 data family T a data instance T Int = T1 Int | T2 Bool newtype instance T Char = TC Bool"_

**🔑 洞见十：数据家族是"开放的数据类型"**

Serokell 指南 ：

> _"Data families are always open, but can also be either top-level or associated"_

```
-- 顶层数据家族
data family T a

data instance T Int = TInt Int | TInts [Int]
data instance T Char = TChar Char
newtype instance T Bool = TBool Bool

-- 关联数据家族（在类型类中）
class GMapKey k where
  data GMap k :: * -> *
```

**数据家族与普通数据类型的区别**：

- 普通数据类型：一处定义所有构造器
    
- 数据家族：分散在多个 `data instance` 中，可按需扩展
    

### 31.3.3 GADT：构造器携带类型证据

图灵社区原文定义 ：

> _"GADT Generalised Algebraic Datatype data T ... where C1 ... :: T ... C2 ... :: T ..."_

**经典示例：类型安全的表达式语言**

```
{-# LANGUAGE GADTs #-}

data Expr a where
  LitInt  :: Int -> Expr Int
  LitBool :: Bool -> Expr Bool
  Add     :: Expr Int -> Expr Int -> Expr Int
  If      :: Expr Bool -> Expr a -> Expr a -> Expr a
```

**🔑 洞见十一：GADT 让构造器的返回类型可精确指定**

Thinking with Types 一书指出 ：

> _"It is this ability to specify the return type that is of particular interest... we've reflected the typing rules of Expr in the type system of Haskell."_

这意味着：

```
evalExpr :: Expr a -> a
evalExpr (LitInt i) = i
evalExpr (LitBool b) = b
evalExpr (Add x y) = evalExpr x + evalExpr y
evalExpr (If b x y) = if evalExpr b then evalExpr x else evalExpr y
```

**编译器知道每个分支的 `a` 是什么**——在 `LitInt` 分支中 `a ~ Int`，在 `LitBool` 分支中 `a ~ Bool`。

### 🔑 洞见十二：GADT 本质是类型等式

Thinking with Types 揭示 ：

> _"The extension is poorly named—a more appropriate name might be '-XTypeEqualities'. In fact, GADTs are merely syntactic sugar over type equalities."_

```
-- GADT 语法
data Expr a where
  LitInt :: Int -> Expr Int

-- 等价于
data Expr a = (a ~ Int) => LitInt Int
```

**GADT 的威力在于**：当你模式匹配 `LitInt` 构造器时，编译器得知 `a ~ Int`——这个类型等式可以被后续代码使用。

### GADT 与存在类型的协同

高级类型编程文章指出 ：

> _"GADTs first refine expressions into different precise types, and then the existential wrapper SomeExpr unifies them so they can be placed in a list."_

```
{-# LANGUAGE GADTs, ExistentialQuantification #-}

data Expr t where
  LitInt  :: Int -> Expr 'TInt
  LitString :: String -> Expr 'TString
  Add     :: Expr 'TInt -> Expr 'TInt -> Expr 'TInt

-- 存在类型包装器
data SomeExpr where
  SomeExpr :: Expr t -> SomeExpr

-- 异构表达式列表
exprs :: [SomeExpr]
exprs = [ SomeExpr (LitInt 42)
        , SomeExpr (LitString "hello")
        , SomeExpr (Add (LitInt 1) (LitInt 2)) ]
```

### 实际应用

```
{-# LANGUAGE TypeFamilies #-}
{-# LANGUAGE GADTs #-}

-- 1. 类型家族：类型级自然数计算
type family Add (n :: Nat) (m :: Nat) :: Nat where
  Add 'Z m = m
  Add ('S n) m = 'S (Add n m)

type family Mul (n :: Nat) (m :: Nat) :: Nat where
  Mul 'Z m = 'Z
  Mul ('S n) m = Add m (Mul n m)

-- 2. 数据家族：类型安全的 JSON 编码
data family JsonRep a

data instance JsonRep Int = JsonInt Int
data instance JsonRep String = JsonString String
data instance JsonRep Bool = JsonBool Bool
data instance JsonRep a => JsonRep [a] = JsonArray [JsonRep a]

class ToJson a where
  toJson :: a -> JsonRep a

-- 3. GADT：类型安全的门状态机
data DoorState = Open | Closed

data Door (s :: DoorState) where
  OpenDoor :: Door 'Open
  ClosedDoor :: Door 'Closed

open :: Door 'Closed -> Door 'Open
open ClosedDoor = OpenDoor

close :: Door 'Open -> Door 'Closed
close OpenDoor = ClosedDoor

-- 4. GADT + 类型家族：类型安全的向量操作
data Nat = Z | S Nat

type family AddNat (n :: Nat) (m :: Nat) :: Nat where
  AddNat 'Z m = m
  AddNat ('S n) m = 'S (AddNat n m)

data Vector (n :: Nat) a where
  VNil :: Vector 'Z a
  VCons :: a -> Vector n a -> Vector ('S n) a

vhead :: Vector ('S n) a -> a
vhead (VCons x _) = x

vappend :: Vector n a -> Vector m a -> Vector (AddNat n m) a
vappend VNil ys = ys
vappend (VCons x xs) ys = VCons x (vappend xs ys)
```

## 31.4 数据类别 DataKinds：值构造器提升到类型层

### DataKinds 的核心机制

GHC 用户指南明确说明 ：

> _"With -XDataKinds, GHC automatically promotes every suitable datatype to be a kind, and its (value) constructors to be type constructors."_

```
{-# LANGUAGE DataKinds #-}

data Nat = Ze | Su Nat

-- DataKinds 自动生成：
--   Nat :: BOX (新的 kind)
--   'Ze :: Nat (类型构造器)
--   'Su :: Nat -> Nat (类型构造器)
```

**🔑 洞见十三：DataKinds 实现"类型提升"**

GHC 用户指南 ：

> *"We only promote datatypes whose kinds are of the form * -> ... -> * -> _."_

提升规则：

|值级|类型级（提升后）|
|---|---|
|`data Nat = Ze \\| Su Nat`|`Nat :: BOX`（`kind`）|
|值构造器 `Ze`|类型构造器 `'Ze :: Nat`|
|值构造器 `Su`|类型构造器 `'Su :: Nat -> Nat`|

### 类型提升的实际价值

GHC 用户指南给出了经典的长度索引向量示例 ：

```
-- 没有 DataKinds：Vec 的 kind 是 * -> * -> *
-- Vec Int Char 是良构的，但这不是我们想要的
data Vec :: * -> * -> *
  where Nil  :: Vec a Ze
        Cons :: a -> Vec a n -> Vec a (Su n)

-- 有了 DataKinds：可以约束长度参数的 kind
data Vec :: * -> Nat -> *
  where Nil  :: Vec a Ze
        Cons :: a -> Vec a n -> Vec a (Su n)

-- 现在 Vec Int Char 会因为 kind 不匹配而报错！
```

**🔑 洞见十四：DataKinds 让类型错误在编译期捕获**

没有 DataKinds 时，`Vec Int Char` 是良构的（因为 `Char` 的 kind 是 `*`）。有了 DataKinds 后，`Vec` 的第二个参数必须是 `Nat` kind，而 `Char` 的 kind 是 `*`，所以 `Vec Int Char` 会在编译期报错 。

### DataKinds 与 GADT 的协同

图灵社区原文给出了 `HList` 的经典示例 ：

> _"{-# LANGUAGE DataKinds, GADTs, KindSignatures, TypeOperators #-} data HList :: [_] -> * where HNil :: HList '[] HCons :: x -> HList xs -> HList (x ': xs)"*

**异构列表（HList）**：

```
{-# LANGUAGE DataKinds, GADTs, KindSignatures, TypeOperators #-}

data HList :: [*] -> * where
  HNil :: HList '[]
  HCons :: x -> HList xs -> HList (x ': xs)

-- 使用示例
hlist :: HList '[Int, String, Bool]
hlist = HCons 5 (HCons "hello" (HCons True HNil))
```

### 🔑 洞见十五：DataKinds + GADT = 编译期不变量

softwarepatternslexicon.com 的文章总结 ：

> _"Data Kinds elevate data types to the kind level, allowing you to use types as kinds. This feature enables more expressive type-level programming and enhances the ability to enforce invariants at the type level."_

典型应用：

1. **单位制检查**：`data Unit = Meter | Second`，确保 `Quantity 'Meter` 不能与 `Quantity 'Second` 混淆
    
2. **状态机**：门的状态 `'Open` 和 `'Closed` 在类型中编码
    
3. **向量长度**：向量的长度在类型中编码
    
4. **异构列表**：HList 的每个元素类型在类型中编码
    

### 实际应用

```
{-# LANGUAGE DataKinds #-}
{-# LANGUAGE GADTs #-}
{-# LANGUAGE KindSignatures #-}
{-# LANGUAGE TypeOperators #-}

-- 1. 单位制类型安全
data Unit = Meter | Second | Kilogram

data Quantity (u :: Unit) where
  Distance :: Double -> Quantity 'Meter
  Time :: Double -> Quantity 'Second
  Mass :: Double -> Quantity 'Kilogram

-- 类型安全的转换
convertToSeconds :: Quantity 'Meter -> Quantity 'Second
convertToSeconds (Distance d) = Time (d / 299792458.0)

-- 编译错误：不能将距离加到时间上
-- badAdd :: Quantity 'Meter -> Quantity 'Second -> Quantity 'Meter
-- badAdd (Distance d1) (Time t2) = Distance (d1 + t2)  -- 类型错误！

-- 2. 类型安全的状态机
data ConnectionState = Disconnected | Connected | Authenticated

data Connection (s :: ConnectionState) where
  DisconnectedConn :: Connection 'Disconnected
  ConnectedConn :: Connection 'Connected
  AuthenticatedConn :: Connection 'Authenticated

connect :: Connection 'Disconnected -> Connection 'Connected
connect DisconnectedConn = ConnectedConn

authenticate :: Connection 'Connected -> Connection 'Authenticated
authenticate ConnectedConn = AuthenticatedConn

-- 3. 长度索引向量（完整版）
data Nat = Z | S Nat

data Vector (n :: Nat) a where
  VNil :: Vector 'Z a
  VCons :: a -> Vector n a -> Vector ('S n) a

-- 类型安全的 head：只对非空向量有效
vhead :: Vector ('S n) a -> a
vhead (VCons x _) = x

-- 类型安全的 tail
vtail :: Vector ('S n) a -> Vector n a
vtail (VCons _ xs) = xs

-- 类型安全的长度
vlength :: Vector n a -> Int
vlength VNil = 0
vlength (VCons _ xs) = 1 + vlength xs

-- 4. 异构列表
data HList :: [*] -> * where
  HNil :: HList '[]
  HCons :: x -> HList xs -> HList (x ': xs)

-- 异构列表操作
hhead :: HList (x ': xs) -> x
hhead (HCons x _) = x

htail :: HList (x ': xs) -> HList xs
htail (HCons _ xs) = xs

-- 使用示例
hlist :: HList '[Int, String, Bool]
hlist = HCons 5 (HCons "hello" (HCons True HNil))

first :: Int
first = hhead hlist  -- 5

rest :: HList '[String, Bool]
rest = htail hlist
```

## 📝 本章核心洞见总结

> **洞见一：异类数据是高级类型编程的统一动机**。
> 
> 图灵社区原文："由不同类型元素组成的列表——异类表的相关问题" 。**异构列表、插件系统、序列化、嵌入式 DSL——这些场景推动了 Typeable、存在类型、类型家族、GADT、DataKinds 的发展**。

> **洞见二：Dynamic 是"单态值的万能容器"**。
> 
> Haskell.org："A value of type Dynamic is an object encapsulated together with its type. A Dynamic may only represent a monomorphic value" 。**`toDyn` 将任意 `Typeable` 值封装为 `Dynamic`，`fromDynamic` 在运行时类型检查后提取**​ 。

> **洞见三：Dynamic 不破坏静态类型安全**。
> 
> Brandon："The existence of Typeable and Dynamic do not in any way change haskell's static typing" 。**`cast 'a' :: (Typeable a) => Maybe a` 会因歧义报错**​ ——动态类型逃逸始终被 `Typeable` 约束包围。

> **洞见四：存在类型是"内联类型类词典"**。
> 
> 图灵社区原文："我们把上述在类型定义的右侧,显示地引入类型变量的类型叫做存在类型 内联类型类词典" 。**`forall a. Show a => Dyn a` 隐藏具体类型 `a`，但保留 `Show` 约束**​ 。

> **洞见五：存在类型 vs 全称量化**。
> 
> Haskell 邮件列表："In Haskell, 'f::a' means 'FOR EVERY type a, f can be that type'... what you had in mind would be written 'f :: exists a. a'" 。**全称量化：调用者选择类型；存在量化：定义者选择类型，调用者不知**。

> **洞见六：存在类型实现封装**。
> 
> Stack Overflow："existential types allow you to hide the underlying type in a data structure, forcing the programmer to only use the operations you have defined on it" 。**这是面向对象封装在 Haskell 中的对应物**。

> **洞见七：Typeable 让存在类型"可逆"**。
> 
> sras.me："data MoneyEx = forall x. (Typeable x) => MoneyEx (Money x)" 。**加上 `Typeable` 约束后，可在运行时用 `cast` 尝试恢复被隐藏的类型**。

> **洞见八：类型家族是类型级函数**。
> 
> Serokell："Type families are one of the most powerful type-level programming features in Haskell. You can think of them as type-level functions" 。**与项级函数高度相似：大写名称、种类签名、子句分组**​ 。

> **洞见九：类型家族分为开放和封闭**。
> 
> Serokell："Type families are further subdivided into closed and open" 。**封闭类型家族支持模式重叠（按顺序匹配），开放类型家族支持模块化扩展**。

> **洞见十：数据家族是"开放的数据类型"**。
> 
> 图灵社区原文："data family T a data instance T Int = T1 Int | T2 Bool" 。**普通数据类型在一处定义所有构造器，数据家族分散在多个 `data instance` 中**。

> **洞见十一：GADT 让构造器精确指定返回类型**。
> 
> Thinking with Types："It is this ability to specify the return type that is of particular interest... we've reflected the typing rules of Expr in the type system of Haskell" 。**`LitInt :: Int -> Expr Int` 明确告诉编译器：这个构造器产生 `Expr Int`**。

> **洞见十二：GADT 本质是类型等式**。
> 
> Thinking with Types："The extension is poorly named—a more appropriate name might be '-XTypeEqualities'. In fact, GADTs are merely syntactic sugar over type equalities" 。**模式匹配 GADT 构造器时，编译器得知类型等式（如 `a ~ Int`），可用于后续类型推断**。

> **洞见十三：DataKinds 实现"类型提升"**。
> 
> GHC 用户指南："With -XDataKinds, GHC automatically promotes every suitable datatype to be a kind, and its (value) constructors to be type constructors" 。**`data Nat = Ze | Su Nat` 提升后生成 `Nat :: BOX`、`'Ze :: Nat`、`'Su :: Nat -> Nat`**​ 。

> **洞见十四：DataKinds 让类型错误在编译期捕获**。
> 
> GHC 用户指南：没有 DataKinds 时 `Vec Int Char` 是良构的；有了 DataKinds 后 `Vec` 第二个参数必须是 `Nat` kind 。**`Vec Int Char` 因 kind 不匹配而编译失败**。

> **洞见十五：DataKinds + GADT = 编译期不变量**。
> 
> softwarepatternslexicon.com："Data Kinds... enhances the ability to enforce invariants at the type level" 。**单位制、状态机、向量长度、异构列表——这些不变量在类型中编码，非法状态无法构造**。

    ```
        d -> fromDynamic d
    
    -- 序列化/反序列化
    serialize :: Typeable a => a -> (TypeRep, String)
    serialize x = (typeOf x, show x)
    
    deserialize :: Typeable a => (TypeRep, String) -> Maybe a
    deserialize (tr, s) = 
      case reads s of
        [(x, "")] -> 
          if typeOf x == tr 
          then cast x 
          else Nothing
        _ -> Nothing
    ```

2. **存在类型的典型用法**：

    ```
      pluginName :: a -> String
      pluginRun :: a -> IO ()
    ```

3. **类型家族的类型级计算**：

    ```
    {-# LANGUAGE TypeFamilies #-}
    {-# LANGUAGE DataKinds #-}
    
    -- 类型级自然数
    type family Add (n :: Nat) (m :: Nat) :: Nat where
      Add 'Z m = m
      Add ('S n) m = 'S (Add n m)
    
    -- 类型级列表操作
    type family Reverse (xs :: [a]) :: [a] where
      Reverse '[] = '[]
      Reverse (x ': xs) = Append (Reverse xs) '[x]
    ```
    
4. **GADT 的类型安全 DSL**：
    
    ```
    {-# LANGUAGE GADTs #-}
    {-# LANGUAGE DataKinds #-}
    
    data Expr (t :: TypeTag) where
      LitInt  :: Int -> Expr 'TInt
      LitBool :: Bool -> Expr 'TBool
      Add     :: Expr 'TInt -> Expr 'TInt -> Expr 'TInt
      If      :: Expr 'TBool -> Expr t -> Expr t -> Expr t
    
    evalExpr :: Expr t -> EvalResult t
    evalExpr (LitInt n) = RInt n
    evalExpr (LitBool b) = RBool b
    evalExpr (Add e1 e2) = 
      case (evalExpr e1, evalExpr e2) of
        (RInt a, RInt b) -> RInt (a + b)
    ```

6. **综合应用：类型安全的嵌入式 DSL**：
    
    ```
    {-# LANGUAGE GADTs #-}
    {-# LANGUAGE DataKinds #-}
    {-# LANGUAGE TypeFamilies #-}
    {-# LANGUAGE ExistentialQuantification #-}
    
    -- 类型标签
    data TypeTag = TInt | TBool | TString
    
    -- GADT：类型安全的表达式
    data Expr (t :: TypeTag) where
      LitInt  :: Int -> Expr 'TInt
      LitBool :: Bool -> Expr 'TBool
      LitStr  :: String -> Expr 'TString
      Add     :: Expr 'TInt -> Expr 'TInt -> Expr 'TInt
      And     :: Expr 'TBool -> Expr 'TBool -> Expr 'TBool
      If      :: Expr 'TBool -> Expr t -> Expr t -> Expr t
    
    -- 类型家族：表达式求值结果类型
    type family EvalResult (t :: TypeTag) :: * where
      EvalResult 'TInt = Int
      EvalResult 'TBool = Bool
      EvalResult 'TString = String
    
    -- 类型安全的求值器
    evalExpr :: Expr t -> EvalResult t
    evalExpr (LitInt n) = n
    evalExpr (LitBool b) = b
    evalExpr (LitStr s) = s
    evalExpr (Add e1 e2) = evalExpr e1 + evalExpr e2
    evalExpr (And e1 e2) = evalExpr e1 && evalExpr e2
    evalExpr (If cond e1 e2) = 
      if evalExpr cond then evalExpr e1 else evalExpr e2
    
    -- 存在类型：异构表达式列表
    data SomeExpr where
      SomeExpr :: Expr t -> SomeExpr
    
    exprList :: [SomeExpr]
    exprList = [ SomeExpr (LitInt 42)
               , SomeExpr (LitBool True)
               , SomeExpr (Add (LitInt 1) (LitInt 2))
               , SomeExpr (If (LitBool True) (LitStr "yes") (LitStr "no"))
               ]
    ```
