## 01.01 网络的构成要素

这一节先做两件事：**把网络的硬件组件点一遍**，然后**复习 OSI 参考模型**。

**网络构成要素（要点提炼）**

```
一个网络 = 终端节点 + 转发设备 + 传输介质 + 协议
                │            │            │
                ▼            ▼            ▼
              PC/服务器    交换机/路由器   双绞线/光纤
              (数据的源/宿) (数据的搬运工) (数据的公路)
```

**OSI 七层模型复习（本节重点中的重点）**

作者把 OSI 模型重新拎出来不是凑篇幅，而是因为**后面每一章都在讲某一层对应的硬件**：

|OSI 层|本章对应的硬件 / 概念|后续哪章深讲|
|---|---|---|
|物理层 (L1)|双绞线、光纤、接口、信号转换器|第1章 01.05|
|数据链路层 (L2)|网卡、网桥、L2 交换机|**第2章**​|
|网络层 (L3)|路由器、L3 交换机|**第3章**​|
|L4–L7|防火墙、负载均衡等|后续章节|

> 💡 **读这一节的"连结意识"**：OSI 不是死记七层名字，而是本书的**目录索引**——每一层都对应后面若干章节要讲的硬件。看到 L2 就想第2章，看到 L3 就想第3章，整本书就串起来了。

## 01.02 LAN 和以太网

这一节讲清楚 **LAN 的标准化历史**​ 和 **以太网为何成为绝对主流**。

**核心脉络**

```
LAN 标准之争（早期）
  ├─ 以太网 (Ethernet)         ← 胜出，成为事实标准
  ├─ 令牌环 (Token Ring)
  └─ FDDI
        │
        ▼
   现代 LAN ≈ 以太网
   本书后面所有"交换机/路由器"默认都是以太网设备
```

**读书要点**

- **LAN 的标准**：了解 IEEE 802 系列标准的由来，明白"标准化"是硬件能互通的前提。
- **以太网**：理解它从总线型共享介质 → 交换式点对点的演进方向，**这个演进正是第2章"L2 交换机"诞生的根本动力**。
    

> 📌 这一节和第2章是直接因果关系：因为以太网赢了，所以我们要"彻底理解 L2 交换机"。

## 01.03 以太网标准的数据处理

这是本章**技术密度最高**的一节，作者按速率演进挨个拆解以太网标准：

```
以太网速率演进（本书 01.03 的小节顺序）

  10BASE-T        ── 1990 年代，10 Mbps，双绞线
       │
  100BASE-TX      ── 快速以太网，100 Mbps，双绞线（两对线）
       │
  1000BASE-T      ── 千兆以太网，双绞线（四对线全用）
  1000BASE-TX     ── 千兆以太网，双绞线（两对线，要求 Cat6）
       │
  1000BASE-SX     ── 千兆，多模光纤（短距）
  1000BASE-LX     ── 千兆，单模/多模光纤（长距）
```

**命名规则拆解**（这一节最重要的"读数能力"）：

```
XX BASE - YY
 │        │
 │        └─ 传输介质或编码方式
 │            T  = 双绞线 (Twisted pair)
 │            TX = 双绞线(100BASE-TX 是两对线)
 │            SX = 光纤，多模 (Short wavelength)
 │            LX = 光纤，单模/多模 (Long wavelength)
 └─ 速率: 10 = 10Mbps, 100 = 100Mbps, 1000 = 1Gbps
```

> 💡 **读这一节的"全局观"**：不要把每个标准当孤立知识点背。抓住一条主线——**速率从 10M → 100M → 1G 往上走，介质从同轴 → 双绞线 → 光纤演进，编码方式也在变**。后面看交换机端口时，看到的"10/100/1000 端口""SFP 光口"就是这个演进的结果。

**以太网帧结构**（01.03.01 以太网上的数据）：预习前导码、目的 MAC、源 MAC、类型、数据、FCS 这六个字段。**这个帧结构是第2章交换机"学习 MAC 地址""转发数据帧"的操作对象**——没有 01.03 的帧，就没有 02.01 的交换机。

## 01.04 网络设备的构成要素

这一节非常"硬件化"，作者把一台网络设备（交换机/路由器）拆开讲内部组件：

```
一台网络设备的内部构成（01.04 全景）

  ┌─────────────────────────────────────────┐
  │              网络设备                     │
  │                                           │
  │  ┌─────────┐  ┌─────────┐  ┌──────────┐  │
  │  │  CPU    │  │ 内存/存储│  │ 硬件芯片  │  │
  │  │(控制平面)│  │(RAM/ROM)│  │(ASIC/FPGA)│  │
  │  └─────────┘  └─────────┘  │(数据平面) │  │
  │                              └──────────┘  │
  │  ┌─────────────────────────────────────┐  │
  │  │  接口 (RJ-45 / SFP / Console)        │  │
  │  └─────────────────────────────────────┘  │
  │  ┌─────────┐  ┌─────────┐  ┌──────────┐  │
  │  │  电源   │  │  PSE认证 │  │  LED指示灯│  │
  │  └─────────┘  └─────────┘  └──────────┘  │
  │  ┌─────────┐  ┌─────────┐                 │
  │  │  UPS    │  │  风扇   │                 │
  │  └─────────┘  └─────────┘                 │
  │  └─ 操作系统(内核)：设备的"大脑"           │
  └─────────────────────────────────────────┘
```

**各小节要点提炼**

|小节|关键概念|为什么重要|
|---|---|---|
|01.04.01–02|通用服务器 vs 专用设备、设备分类|理解"为什么网络设备不用普通 PC"|
|01.04.03–06|CPU / 存储 / 内存 / HDD·SSD|控制平面靠 CPU+内存，数据平面靠硬件芯片|
|01.04.07|硬件芯片（ASIC 等）|**交换机/路由器"线速转发"的秘密**​|
|01.04.08–09|接口、信号转换器|光电转换、电电转换发生在哪里|
|01.04.10–11|LED、OS 内核|运维视角：怎么看设备状态|
|01.04.12–15|电源、PSE、UPS、风扇|**可靠性工程**：冗余电源、断电保护、散热|

> 📌 **这一节和第2/3章的连结**：第2章讲交换机"如何处理数据帧"时，背后就是 01.04.07 的硬件芯片在干活；第3章讲路由器"如何转发数据包"也是同理。**控制平面走 CPU，数据平面走 ASIC**——这是理解所有网络设备性能瓶颈的钥匙。

## 01.05 线缆与周边设备

最后一节回到物理层介质和机房周边：

```
线缆与周边（01.05 全景）

  双绞线缆 ──── 分两种:
                ├─ UTP (非屏蔽): 常规办公
                └─ STP (屏蔽):   抗干扰环境
                    │
                    ▼
                1000BASE-T 需要 4 对线全用
                100BASE-TX 只需 2 对线

  光纤 ──── 分两种:
                ├─ 多模 (MMF): 短距，配 1000BASE-SX
                └─ 单模 (SMF): 长距，配 1000BASE-LX
                    │
                    ▼
                数据中心、运营商骨干

  机架 ──── 19 英寸标准机架
                ↓
            所有设备"上架"的物理依托
```

**要点提炼**

- **双绞线**：UTP vs STP 的区别在于有无金属屏蔽层，直接影响抗干扰能力。
- **光纤**：多模/单模的选择本质是"距离+成本"的权衡。
- **机架**：机房布线的物理基础，理解机架单位 U 和 19 英寸标准。

> 💡 **和第3章及后续连结**：光纤 + SFP/SFP+ 光模块的组合，会在第3章以后讲路由器接口、数据中心互联时反复出现。01.05 是"认识介质"，后面是"用介质组网的工程实践"。
